  - "$100\\text{ [Hz]}$"

  - "$800\\text{ [Hz]}$"
explanation: |
  ■ 1단계: RC 시정수 계산
  • $R = 100\text{ k}\Omega, C = 1\text{ }\mu\text{F}$일 때 회로 시정수 $\tau$:
    $$\tau = RC = (100 \times 10^3\text{ }\Omega) \times (1 \times 10^{-6}\text{ F}) = 0.1\text{ s}$$

  ■ 2단계: 입력 주파수 $f$ 계산
  • 시정수 $\tau$가 주기 $T$의 20배가 되는 조건:
    $$\tau = 20T = \frac{20}{f} \implies f = \frac{20}{\tau} = \frac{20}{0.1} = 200\text{ Hz}$$

  ■ 최종 결과:
  • 입력 주파수는 200 [Hz] (③번)
