explanation: |
  ■ 1단계: 반전 적분기 시정수 및 전달 특성 확인
  • 반전 적분기 출력 전압 공식:
    $$v_o(t) = -\frac{1}{RC}\int v_i(t) dt$$
  • 시정수 계산 ($R = 10\text{ k}\Omega, C = 0.1\text{ }\mu\text{F}$):
    $$RC = 10^4\text{ }\Omega \times 10^{-7}\text{ F} = 10^{-3}\text{ s} = 1\text{ ms} \implies -\frac{1}{RC} = -1000\text{ s}^{-1}$$

  ■ 2단계: 주기별 출력 전압 파형 전개
  • $0 < t < 1\text{ ms}$ 구간 ($v_i = +6\text{ V}$):
    $$v_o(t) = -1000 \times 6t = -6000t$$
    $$t = 1\text{ ms} \implies v_o(1\text{ ms}) = -6\text{ V}$$
  • $1 < t < 2\text{ ms}$ 구간 ($v_i = -6\text{ V}$):
    $$v_o(t) \text{는 양의 기울기로 증가하여 } t = 2\text{ ms}\text{에서 } 0\text{ V}\text{에 도달}$$
  • 따라서 최솟값이 $-6\text{ V}$인 반전 삼각파가 됩니다.

  ■ 최종 결과:
  • 올바른 출력 파형은 ③번
