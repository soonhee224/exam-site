  - "고역 통과 필터(High Pass Filter)"
  - "전역 통과 필터(All Pass Filter)"
  - "대역 통과 필터(Band Pass Filter)"
explanation: |
  ■ 1단계: 주파수 극한 분석법을 통한 필터 판별
  • 주어진 수동 소자 R, L 회로망의 복소 전위 전달비를 구하기 위해 주파수 $f$가 극단적일 때의 거동을 확인합니다:
    - 인덕터의 유도성 리액턴스 크기 공식:
      $$X_L = \omega L = 2\pi f L$$
  • 주파수가 0일 때 (직류 상태, $f = 0$):
    - $X_L = 0 \implies$ 인덕터는 완전히 단락(Short) 상태가 됩니다.
    - 출력 포트 양단이 인덕터에 의해 단락되므로 출력 전압은 발생하지 않습니다:
      $$v_o(t) = 0 \implies H(j0) = 0$$
  • 주파수가 무한대로 갈 때 (고주파수 상태, $f \to \infty$):
    - $X_L \to \infty \implies$ 인덕터는 완전히 개방(Open) 상태가 됩니다.
    - 회로망은 입력 저항 $2\text{ k}\Omega$과 부하 저항 $4\text{ k}\Omega$만 남는 단순 전압분배 회로로 전치됩니다:
      $$v_o(t) = v_i(t) \cdot \frac{4\text{ k}\Omega}{2\text{ k}\Omega + 4\text{ k}\Omega} = \frac{2}{3} v_i(t) \neq 0$$

  ■ 2단계: 필터의 종류 결정
  • 저주파 대역의 신호는 차단하고 고주파 대역의 신호만 감쇠하여 통과시키는 특성을 가지므로, 본 회로는 고역 통과 필터(High Pass Filter)의 기능을 수행합니다.

  ■ 최종 결과:
  • 올바른 회로의 기능은 고역 통과 필터 입니다. (②번)
