  - "$A\\oplus B$"
  - "$AB$"
  - "$A+B$"
  - "$\\overline{A\\oplus B}$"
explanation: |
  ■ 1단계: 부울식 전개
  • $A \oplus B = \bar{A}B + A\bar{B}$ 대입:
    $$Y = (\bar{A}B + A\bar{B})(A + B)$$
  • 분배 법칙 적용:
    $$Y = \bar{A}BA + \bar{A}BB + A\bar{B}A + A\bar{B}B$$

  ■ 2단계: 소거 및 간략화
  • $\bar{A}A = 0, \bar{B}B = 0, BB = B, AA = A$ 대입:
    $$Y = 0 + \bar{A}B + A\bar{B} + 0 = \bar{A}B + A\bar{B} = A \oplus B$$

  ■ 최종 결과:
  • 간략화된 부울함수는 $A \oplus B$ (①번)
