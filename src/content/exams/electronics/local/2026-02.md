  - "$AB + \\bar{A}\\bar{C}$"
  - "$AB + \\bar{A}C$"
  - "$A\\bar{B} + \\bar{A}C$"
  - "$\\bar{A}B + \\bar{A}C$"
explanation: |
  ■ 1단계: 주어진 논리식 공통 인수 묶기
  • 간략화할 논리식:
    $$Y = AB + ABC + \bar{A}BC + \bar{A}C$$
  • 앞의 두 항에서 $AB$를 묶기:
    $$AB + ABC = AB(1 + C) = AB$$
  • 뒤의 두 항에서 $\bar{A}C$를 묶기:
    $$\bar{A}BC + \bar{A}C = \bar{A}C(B + 1) = \bar{A}C$$

  ■ 2단계: 최종 식 결합
  • 두 간략화 항을 결합:
    $$Y = AB + \bar{A}C$$

  ■ 최종 결과:
  • 올바른 간소화 식은 $AB + \bar{A}C$ (②번)
