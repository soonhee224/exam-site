options:
  - "$I_1 = 3\\text{ [A]}, \\quad I_2 = 3\\text{ [A]}, \\quad I_3 = 0\\text{ [A]}$"
  - "$I_1 = 3\\text{ [A]}, \\quad I_2 = 2\\text{ [A]}, \\quad I_3 = 1\\text{ [A]}$"
  - "$I_1 = 3\\text{ [A]}, \\quad I_2 = 1\\text{ [A]}, \\quad I_3 = 2\\text{ [A]}$"
  - "$I_1 = 3\\text{ [A]}, \\quad I_2 = 0\\text{ [A]}, \\quad I_3 = 3\\text{ [A]}$"
explanation: |
  ■ 1단계: 마디 전압 방정식을 이용한 노드 전압($V_x$) 계산
  • 상단 공통 노드 전압 $V_x$에 대해 KCL 적용:
    $$\frac{V_x - 12}{2} + \frac{V_x}{2} + \frac{V_x - 6}{4} = 0$$
  • 양변에 4를 곱하여 정리:
    $$2(V_x - 12) + 2V_x + (V_x - 6) = 0$$
    $$5V_x = 30 \implies V_x = 6\text{ V}$$

  ■ 2단계: 각 분기 전류 $I_1, I_2, I_3$ 계산
  • 각 전류 계산:
    - $I_1 = \frac{12 - V_x}{2} = \frac{12 - 6}{2} = 3\text{ A}$
    - $I_2 = \frac{V_x}{2} = \frac{6}{2} = 3\text{ A}$
    - $I_3 = \frac{V_x - 6}{4} = \frac{6 - 6}{4} = 0\text{ A}$

  ■ 최종 결과:
  • $I_1 = 3\text{ [A]}, I_2 = 3\text{ [A]}, I_3 = 0\text{ [A]}$ (①번)
