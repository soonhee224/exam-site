options:
  - "$\\sqrt{2}\\sin(1000t - 45^\\circ)\\text{ [A]}$"
  - "$\\frac{1000}{\\sqrt{2}}\\sin(1000t + 45^\\circ)\\text{ [A]}$"
  - "$\\frac{1000}{\\sqrt{2}}\\sin(1000t - 45^\\circ)\\text{ [A]}$"
  - "$\\frac{1}{\\sqrt{2}}\\sin(1000t + 45^\\circ)\\text{ [A]}$"
explanation: |
  ■ 1단계: 회로의 복소 임피던스($Z$) 계산
  • $\omega = 1000\text{ rad/s}, R = 1\text{ k}\Omega = 1000\text{ }\Omega, C = 1\text{ }\mu\text{F} = 10^{-6}\text{ F}$
  • 용량성 리액턴스:
    $$X_C = \frac{1}{\omega C} = \frac{1}{1000 \times 10^{-6}} = 1000\text{ }\Omega$$
  • 합성 임피던스:
    $$Z = R - jX_C = 1000 - j1000 = 1000\sqrt{2}\angle -45^\circ\text{ }\Omega$$

  ■ 2단계: 전류 $i(t)$ 계산
  • 전압 $v_s(t) = 1000\sin(1000t)\text{ V}$
  • 전류의 진폭 $I_m$:
    $$I_m = \frac{V_m}{|Z|} = \frac{1000}{1000\sqrt{2}} = \frac{1}{\sqrt{2}}\text{ A}$$
  • 전류의 위상은 용량성 회로이므로 전압보다 $45^\circ$ 앞섭니다:
    $$i(t) = \frac{1}{\sqrt{2}}\sin(1000t + 45^\circ)\text{ A}$$

  ■ 최종 결과:
  • 전류는 $\frac{1}{\sqrt{2}}\sin(1000t + 45^\circ)\text{ [A]}$ (④번)
