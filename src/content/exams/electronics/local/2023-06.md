  - "$(t_2 \\sim t_3): Q_1=1, Q_2=0 \\quad (t_7 \\sim t_8): Q_1=1, Q_2=1$"
  - "$(t_2 \\sim t_3): Q_1=0, Q_2=1 \\quad (t_7 \\sim t_8): Q_1=0, Q_2=0$"
  - "$(t_2 \\sim t_3): Q_1=1, Q_2=1 \\quad (t_7 \\sim t_8): Q_1=1, Q_2=0$"
explanation: |
  ■ 1단계: T 플립플롭 트리거 에지 확인
  • $Q_1$: 클럭의 상승 에지(Rising Edge)에서 동작
  • $Q_2$: 클럭에 NOT 게이트가 연결되어 있어 클럭의 하강 에지(Falling Edge)에서 동작
  • 동작 규칙: $T = 1$일 때 상태 반전(토글), $T = 0$일 때 상태 유지

  ■ 2단계: 시간별 상태 추적
  • $t_1$(상승): Input = 0 $\implies Q_1 = 0$ 유지
  • $t_2$(하강): Input = 1 $\implies Q_2$ 토글되어 $Q_2 = 1$
    - $(t_2 \sim t_3)$ 구간: $Q_1 = 0, Q_2 = 1$
  • $t_3$(상승): Input = 1 $\implies Q_1$ 토글되어 $Q_1 = 1$
  • $t_4$(하강): Input = 0 $\implies Q_2 = 1$ 유지
  • $t_5$(상승): Input = 0 $\implies Q_1 = 1$ 유지
  • $t_6$(하강): Input = 0 $\implies Q_2 = 1$ 유지
  • $t_7$(상승): Input = 1 $\implies Q_1$ 토글되어 $Q_1 = 0$
  • $t_8$(하강): Input = 1 $\implies Q_2$ 토글되어 $Q_2 = 0$
    - $(t_7 \sim t_8)$ 구간: $t_7$에서 $Q_1$이 0으로 변하고 $Q_2$는 1을 유지하므로 $Q_1 = 0, Q_2 = 1$

  ■ 최종 결과:
  • 올바른 구간 상태는 ①번
