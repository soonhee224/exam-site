  - "1"
  - "$\\frac{1}{\\sqrt{3}}$"
  - "$\\frac{1}{\\sqrt{2}}$"
explanation: |
  ■ 1단계: 용량성 리액턴스 및 합성 임피던스 계산
  • $\omega = 400\text{ rad/s}, R = 25\text{ k}\Omega, C = 0.1\text{ }\mu\text{F} = 10^{-7}\text{ F}$
  • 용량성 리액턴스:
    $$X_C = \frac{1}{\omega C} = \frac{1}{400 \times 10^{-7}} = 25000\text{ }\Omega = 25\text{ k}\Omega$$
  • 합성 임피던스 크기:
    $$|Z| = \sqrt{R^2 + X_C^2} = \sqrt{25^2 + 25^2}\text{ k}\Omega = 25\sqrt{2}\text{ k}\Omega$$

  ■ 2단계: 역률 계산
  • 역률 공식 적용:
    $$\cos\theta = \frac{R}{|Z|} = \frac{25\text{ k}\Omega}{25\sqrt{2}\text{ k}\Omega} = \frac{1}{\sqrt{2}}$$

  ■ 최종 결과:
  • 역률은 $\frac{1}{\sqrt{2}}$ (④번)
