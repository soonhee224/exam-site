  - "$S = \\bar{x}\\bar{y}\\bar{z} + \\bar{x}yz + x\\bar{y}z + xy\\bar{z}$, $C = xy + xz + yz$"
  - "$S = \\bar{x}yz + xyz + xy\\bar{z} + x\\bar{y}z$,  $C = xy + xz + yz$"
  - "$S = x\\bar{y}z + xy\\bar{z} + \\bar{x}\\bar{y}\\bar{z} + \\bar{x}yz$, $C = \\bar{x}y + \\bar{x}z + yz$"
  - "$S = \\bar{x}\\bar{y}z + \\bar{x}y\\bar{z} + x\\bar{y}\\bar{z} + xyz$, $C = xy + xz + yz$"
explanation: |
  ■ 1단계: 전가산기 합($S$) 부울함수 도출
  • 입력 $x, y, z$ 중 1의 개수가 홀수개일 때 $S = 1$이 됩니다:
    $$S = \bar{x}\bar{y}z + \bar{x}y\bar{z} + x\bar{y}\bar{z} + xyz$$

  ■ 2단계: 전가산기 캐리($C$) 부울함수 도출
  • 입력 $x, y, z$ 중 1이 2개 이상일 때 $C = 1$이 됩니다:
    $$C = xy + xz + yz$$

  ■ 최종 결과:
  • 올바른 부울함수 쌍은 ④번

세 개의 입력 비트들의 합을 계산하는 조합회로를 전가산기라 한다. 전가산기의 출력은 합에 해당하는 S와 캐리에 해당하는 C가 있다. 전가산기의 입력 x, y, z라 할 때 S와 C 각각의 부울함수로 옳은 것은?
