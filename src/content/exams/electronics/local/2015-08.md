answer: 4
options:
  - "$\\frac{Y}{R} = \\frac{abcd}{1 + be + cf + dg}$"
  - "$\\frac{Y}{R} = \\frac{abcd}{1 + be + cf + dg - bdeg}$"
  - "$\\frac{Y}{R} = \\frac{abcd}{1 - be - cf - dg + bdeg}$"
  - "$\\frac{Y}{R} = \\frac{abcd}{1 + be + cf + dg + bdeg}$"
explanation: |
  ■ 1단계: 전방 경로 및 루프 이득 산출
  • 전방 경로 이득: $P_1 = abcd$
  • 개별 루프 이득: $L_1 = -be, L_2 = -cf, L_3 = -dg$
  • 서로 겹치지 않는 루프 쌍의 곱: 루프 1($-be$)과 루프 3($-dg$)이 겹치지 않으므로:
    $$L_{13} = (-be)(-dg) = bdeg$$

  ■ 2단계: 메이슨 공식 적용
  • 시스템 행렬식 $\Delta$:
    $$\Delta = 1 - (L_1 + L_2 + L_3) + L_{13} = 1 - (-be - cf - dg) + bdeg = 1 + be + cf + dg + bdeg$$
  • 전달함수:
    $$\frac{Y}{R} = \frac{abcd}{1 + be + cf + dg + bdeg}$$

  ■ 최종 결과:
  • 이득은 $\frac{abcd}{1 + be + cf + dg + bdeg}$ (④번)
