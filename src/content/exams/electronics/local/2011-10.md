answer: 1
options:
  - "$F = A'B + A'C + BCD + AB'C'D'$"
  - "$F = A'B' + AC + BCD + AB'C'D'$"
  - "$F = A'B' + A'C + BC'D + AB'C'D'$"
  - "$F = A'B' + A'C' + BCD + AB'C'D'$"
explanation: |
  ■ 1단계: 8-to-1 MUX 출력식 전개
  • $D_0=0, D_1=1, D_2=1, D_3=1, D_4=D', D_5=0, D_6=0, D_7=D$ 대입:
    $$F = A'B'C + A'BC' + A'BC + AB'C'D' + ABCD$$

  ■ 2단계: 부울식 간소화
  • $A'B'C + A'BC' + A'BC = A'B(C' + C) + A'B'C = A'B + A'B'C = A'(B + C) = A'B + A'C$
  • $A'B + ABCD = B(A' + ACD) = B(A' + CD) = A'B + BCD$
  • 따라서 최종 정리된 식:
    $$F = A'B + A'C + BCD + AB'C'D'$$

  ■ 최종 결과:
  • 올바른 부울식은 ①번
