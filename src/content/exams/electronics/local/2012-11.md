explanation: |
  ■ 1단계: 2진 코드의 그레이 코드 변환 공식 수립
  • 4비트 2진수 $B_3B_2B_1B_0$을 그레이 코드 $G_3G_2G_1G_0$로 변환하는 관계식:
    - $G_3 = B_3$
    - $G_2 = B_3 \oplus B_2$
    - $G_1 = B_2 \oplus B_1$
    - $G_0 = B_1 \oplus B_0$

  ■ 2단계: 코드 A(0110) 변환
  • $B_3B_2B_1B_0 = 0110_2$ 대입:
    - $G_3 = 0$
    - $G_2 = 0 \oplus 1 = 1$
    - $G_1 = 1 \oplus 1 = 0$
    - $G_0 = 1 \oplus 0 = 1$
  • 그레이 코드 A: 0101

  ■ 3단계: 코드 B(1101) 변환
  • $B_3B_2B_1B_0 = 1101_2$ 대입:
    - $G_3 = 1$
    - $G_2 = 1 \oplus 1 = 0$
    - $G_1 = 1 \oplus 0 = 1$
    - $G_0 = 0 \oplus 1 = 1$
  • 그레이 코드 B: 1011

  ■ 최종 결과:
  • A: 0101, B: 1011 (②번)
