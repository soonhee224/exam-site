explanation: |
  ■ 1단계: 동기식 D 플립플롭의 동작 분석
  • 두 D 플립플롭은 클럭($CLK$)의 상승 에지(Rising Edge)마다 동작합니다.
  • 상태 전이 관계식:
    - $OUT1(t+1) = IN(t)$
    - $OUT2(t+1) = OUT1(t)$

  ■ 2단계: 클럭 상승 에지별 출력 추적
  • 1번째 상승 에지: $IN = 0 \\implies OUT1 = 0, OUT2 = 0$
  • 2번째 상승 에지: $IN = 1 \\implies OUT1 = 1, OUT2 = 0$
  • 3번째 상승 에지: $IN = 0 \\implies OUT1 = 0, OUT2 = 1$
  • 4번째 상승 에지: $IN = 0 \\implies OUT1 = 0, OUT2 = 0$
  • 5번째 상승 에지: $IN = 1 \\implies OUT1 = 1, OUT2 = 0$
  • 이 파형 변화를 바르게 나타낸 것은 ①번입니다.

  ■ 최종 결과:
  • 올바른 출력 파형은 ①번
