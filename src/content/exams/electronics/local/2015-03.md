  - "$V_{\\text{out1}} = 6.7\\text{ [V]}, \\quad V_{\\text{out2}} = 6\\text{ [V]}$"
  - "$V_{\\text{out1}} = 12\\text{ [V]}, \\quad V_{\\text{out2}} = 6\\text{ [V]}$"
  - "$V_{\\text{out1}} = 12.7\\text{ [V]}, \\quad V_{\\text{out2}} = 6.7\\text{ [V]}$"
  - "$V_{\\text{out1}} = 20\\text{ [V]}, \\quad V_{\\text{out2}} = 6.7\\text{ [V]}$"
explanation: |
  ■ 1단계: 다이오드 도통 상태 및 전압 강하 분석
  • 제너다이오드 $D_1, D_3$는 역방향 바이어스로 동작하여 각각 $6\text{ V}$의 항복 전압 강하를 갖습니다.
  • 일반 다이오드 $D_2$는 순방향 바이어스로 동작하여 문턱 전압 $0.7\text{ V}$의 전압 강하를 갖습니다.

  ■ 2단계: 출력 노드 전압 계산
  • $V_{\text{out2}}$는 $D_2$와 $D_3$의 직렬 연결 전압 강하이므로:
    $$V_{\text{out2}} = V_{D2} + V_{D3} = 0.7\text{ V} + 6\text{ V} = 6.7\text{ V}$$
  • $V_{\text{out1}}$은 $D_1, D_2, D_3$의 직렬 연결 전압 강하이므로:
    $$V_{\text{out1}} = V_{D1} + V_{D2} + V_{D3} = 6\text{ V} + 0.7\text{ V} + 6\text{ V} = 12.7\text{ V}$$

  ■ 최종 결과:
  • $V_{\text{out1}} = 12.7\text{ [V]}, V_{\text{out2}} = 6.7\text{ [V]}$ (③번)
