answer: 3
options:

  - "4 [V]"
  - "5 [V]"
  - "6 [V]"
explanation: |
  ■ 1단계: 가상 접지를 활용한 입력 전류 계산
  • 연산증폭기의 반전 단자는 가상 접지($0\text{ V}$) 상태입니다.
  • 두 입력 $v_1 = 2\text{ V}, v_2 = 1\text{ V}$에 의해 유입되는 전류의 합:
    $$I_{in} = \frac{v_1}{2\text{ k}\Omega} + \frac{v_2}{4\text{ k}\Omega} = \frac{2\text{ V}}{2\text{ k}\Omega} + \frac{1\text{ V}}{4\text{ k}\Omega} = 1\text{ mA} + 0.25\text{ mA} = 1.25\text{ mA}$$

  ■ 2단계: 출력 전압 $v_o$ 계산
  • 반전 가산 증폭기의 피드백 저항 $R_f = 4\text{ k}\Omega$을 통과할 때:
    $$v_o = -I_{in} R_f = -1.25\text{ mA} \times 4\text{ k}\Omega = -5\text{ V}$$
  • 전압의 크기는 $5\text{ V}$입니다.

  ■ 최종 결과:
  • 출력 전압의 크기는 5 [V] (③번)
