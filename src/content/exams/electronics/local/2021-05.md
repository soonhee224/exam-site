  - "200"
  - "1k"
  - "2k"
explanation: |
  ■ 1단계: 소스 저항 양단 전압 강하 및 입력 전류 계산
  • $V_s = 1.5\text{ mV}, V_i = 1.0\text{ mV}, R_s = 100\text{ }\Omega$
  • 저항 $R_s$ 양단 전압 강하:
    $$V_{Rs} = V_s - V_i = 1.5\text{ mV} - 1.0\text{ mV} = 0.5\text{ mV}$$
  • 입력 전류 $I_i$:
    $$I_i = \frac{V_{Rs}}{R_s} = \frac{0.5\text{ mV}}{100\text{ }\Omega} = 5\text{ }\mu\text{A}$$

  ■ 2단계: 입력 임피던스($Z_i$) 계산
  • 옴의 법칙 적용:
    $$Z_i = \frac{V_i}{I_i} = \frac{1.0\text{ mV}}{5\text{ }\mu\text{A}} = 200\text{ }\Omega$$

  ■ 최종 결과:
  • 입력 임피던스는 200 [$\Omega$] (②번)
