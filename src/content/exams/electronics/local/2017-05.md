explanation: |
  ■ 1단계: 각 보기를 10진수로 변환
  • ② $11001011_2 = 128 + 64 + 8 + 2 + 1 = 203_{10}$
  • ③ $313_8 = 3 \times 64 + 1 \times 8 + 3 = 192 + 8 + 3 = 203_{10}$
  • ④ $\text{CB}_{16} = 12 \times 16 + 11 = 192 + 11 = 203_{10}$

  ■ 2단계: 결과 비교
  • ②, ③, ④는 모두 10진수로 203이며, ①은 205입니다.

  ■ 최종 결과:
  • 크기가 다른 것은 $205_{10}$ (①번)
