title: "2018년 지방직 9급 전자공학개론 8번"
answer: 3
options:
  - "$\\bar{A}C + AB\\bar{C}$"
  - "$\\bar{A}D + AB\\bar{C}$"
  - "$\\bar{A}D + A\\bar{B}\\bar{C}$"
  - "$A\\bar{D} + A\\bar{B}\\bar{C}$"
explanation: |
  ■ 1단계: 진리표에서 출력 $Y = 1$인 항 묶기
  • $A = 0$ 영역에서 $Y = 1$인 최소항: $m_1, m_3, m_5, m_7$
    - 공통 인수 묶기:
      $$m_1 + m_3 + m_5 + m_7 = \bar{A}D(\bar{B}\bar{C} + \bar{B}C + B\bar{C} + BC) = \bar{A}D$$
  • $A = 1$ 영역에서 $Y = 1$인 최소항: $m_8, m_9$
    - 공통 인수 묶기:
      $$m_8 + m_9 = A\bar{B}\bar{C}\bar{D} + A\bar{B}\bar{C}D = A\bar{B}\bar{C}(\bar{D} + D) = A\bar{B}\bar{C}$$

  ■ 2단계: 최종 논리식 결합
  • 두 간략화 항을 합치면:
    $$Y = \bar{A}D + A\bar{B}\bar{C}$$

  ■ 최종 결과:
  • 올바른 논리식은 $\bar{A}D + A\bar{B}\bar{C}$ (③번)
