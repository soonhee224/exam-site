answer: 4
options:
  - "$AB' + AC'$"
  - "$AB' + BC'$"
  - "$A'B + BC'$"
  - "$A'B + AC'$"
explanation: |
  ■ 1단계: 카르노 맵 묶음 분석
  • 세로 2개 셀 묶음: $A = 0$이고 $B = 1$인 열에 걸쳐 1이 위치하므로 간략화 항은 $A'B$가 됩니다.
  • 가로 2개 셀 묶음: $A = 1$이고 $C = 0$인 행에 걸쳐 1이 위치하므로 간략화 항은 $AC'$가 됩니다.

  ■ 2단계: 최종 논리식 합산
  • 두 묶음을 합치면:
    $$F = A'B + AC'$$

  ■ 최종 결과:
  • 논리식은 $A'B + AC'$ (④번)
