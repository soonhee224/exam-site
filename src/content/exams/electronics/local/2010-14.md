explanation: |
  ■ 1단계: 각 부울 대수식의 정합성 검증
  • ㄱ. $(AB + C'D')' = (AB)'(C'D')' = (A' + B')(C + D)$ (참)
  • ㄴ. $AB + ABCD = AB(1 + CD) = AB$ (참)
  • ㄷ. $ABC' + ABD' = AB(C' + D')$이며, $AB + C'D'$와는 다르므로 거짓입니다.
  • ㄹ. $(A' + B(C' + D))' = A \cdot (B(C' + D))' = A(B' + CD') = AB' + ACD'$이며, 우변의 $AB' + AC'D$와 다르므로 거짓입니다.

  ■ 2단계: 옳지 않은 식 선별
  • 성립하지 않는 식은 ㄷ, ㄹ입니다.

  ■ 최종 결과:
  • 옳지 않은 것은 ㄷ, ㄹ (④번)

ㄱ. $(AB + C'D')' = (A' + B')(C + D)$
ㄴ. $AB + ABCD = AB$
ㄷ. $ABC' + ABD' = AB + C'D'$
ㄹ. $(A' + B(C' + D))' = AB' + AC'D$
