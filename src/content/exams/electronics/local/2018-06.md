  - "$G(s) = 1 + s$"
  - "$G(s) = 1 + 2s$"
  - "$G(s) = 2 + s$"
explanation: |
  ■ 1단계: 상단 및 하단 연산증폭기 출력 유도
  • 상단 반전 증폭기:
    $$V_{o1}(s) = -\frac{2\text{ k}\Omega}{1\text{ k}\Omega} U(s) = -2U(s)$$
  • 하단 반전 미분기 ($C = 1\text{ mF}, R = 1\text{ k}\Omega$):
    $$V_{o2}(s) = -sCR U(s) = -s(10^{-3}\text{ F} \times 10^3\text{ }\Omega) U(s) = -sU(s)$$

  ■ 2단계: 최종 반전 가산기 출력 유도
  • 출력 $Y(s)$:
    $$Y(s) = -(V_{o1}(s) + V_{o2}(s)) = -(-2U(s) - sU(s)) = (2 + s)U(s)$$
  • 전달함수:
    $$G(s) = \frac{Y(s)}{U(s)} = 2 + s$$

  ■ 최종 결과:
  • 전달함수는 $G(s) = 2 + s$ (④번)
