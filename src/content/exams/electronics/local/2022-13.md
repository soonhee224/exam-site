answer: 1
options:
  - "$V_1 + V_2$"
  - "$V_1 + 2V_2$"
  - "$2V_1 + V_2$"
  - "$V_1 \\times V_2$"
explanation: |
  ■ 1단계: 비반전(+) 입력 단자 전위 $V_+$ 계산
  • 비반전 단자 노드에서 KCL 적용:
    $$\frac{V_+ - V_1}{R} + \frac{V_+ - V_2}{R} + \frac{V_+ - 0}{R} = 0$$
    $$(V_+ - V_1) + (V_+ - V_2) + V_+ = 0 \implies 3V_+ = V_1 + V_2 \implies V_+ = \frac{V_1 + V_2}{3}$$

  ■ 2단계: 반전(-) 단자 전압 및 출력 전압 $V_{\text{out}}$ 유도
  • 비반전 증폭기 구성의 이득 공식 적용:
    $$V_{\text{out}} = \left(1 + \frac{2R}{R}\right)V_+ = 3V_+$$
  • $V_+$ 대입:
    $$V_{\text{out}} = 3 \times \left(\frac{V_1 + V_2}{3}\right) = V_1 + V_2$$

  ■ 최종 결과:
  • 출력전압은 $V_1 + V_2$ (①번)
