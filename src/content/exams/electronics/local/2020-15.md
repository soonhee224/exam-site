  - "$V_{out} = \\frac{R_3}{R_1}(V_1 - V_2)$"
  - "$V_{out} = \\frac{R_3}{R_1}(V_2 - V_1)$"
  - "$V_{out} = \\frac{R_1}{R_3}(V_1 - V_2)$"
  - "$V_{out} = \\frac{R_1}{R_3}(V_2 - V_1)$"
explanation: |
  ■ 1단계: 비반전 단자 전압($V_+$) 계산
  • 저항 $R_2, R_4$에 의한 전압 분배 ($R_2 = R_1, R_4 = R_3$):
    $$V_+ = \frac{R_4}{R_2 + R_4} V_2 = \frac{R_3}{R_1 + R_3} V_2$$

  ■ 2단계: 반전 단자 노드에서 KCL 적용 및 출력 전압 유도
  • 가상 단락($V_- = V_+$) 조건에서 KCL 적용:
    $$\frac{V_- - V_1}{R_1} + \frac{V_- - V_{out}}{R_3} = 0 \implies V_{out} = \left(1 + \frac{R_3}{R_1}\right)V_- - \frac{R_3}{R_1}V_1$$
  • $V_-$ 식 대입:
    $$V_{out} = \left(\frac{R_1 + R_3}{R_1}\right)\left(\frac{R_3}{R_1 + R_3}V_2\right) - \frac{R_3}{R_1}V_1 = \frac{R_3}{R_1}(V_2 - V_1)$$

  ■ 최종 결과:
  • 출력 전압 식은 $V_{out} = \frac{R_3}{R_1}(V_2 - V_1)$ (②번)
