answer: 1
options:
  - "$C = \\frac{1}{1/C_1 + 1/C_2 + 1/C_3}, \\quad A_V = \\frac{C_2}{C_1}$"
  - "$C = \\frac{1}{C_1} + \\frac{1}{C_2}, \\quad A_V = \\frac{C_3}{C_1 + C_2}$"
  - "$C = \\frac{1}{C_1} + \\frac{1}{C_2} + C_3 + C_4, \\quad A_V = \\frac{C_3}{C_1 + C_2} + C_4$"
  - "$C = \\frac{C_3 + C_4}{C_1 + C_2}, \\quad A_V = \\frac{C_3}{C_1 + C_2}$"
explanation: |
  ■ 1단계: 클랩 발진기의 등가 커패시턴스($C$) 유도
  • 클랩 발진기는 인덕터 $L$과 세 커패시터 $C_1, C_2, C_3$가 교류적으로 직렬 루프를 형성하므로:
    $$\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2} + \frac{1}{C_3} \implies C = \frac{1}{1/C_1 + 1/C_2 + 1/C_3}$$

  ■ 2단계: 발진 시동에 필요한 최소 전압 이득($A_v$) 도출
  • 귀환율 $\beta = \frac{C_1}{C_2}$이므로 바크하우젠 발진 개시 조건($A_v \beta \ge 1$)에 의해:
    $$A_v \ge \frac{1}{\\beta} = \frac{C_2}{C_1}$$

  ■ 최종 결과:
  • 올바른 식은 ①번
