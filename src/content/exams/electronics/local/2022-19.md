options:
  - "$A = 5.3, \\quad B = -5.3$"
  - "$A = 5.7, \\quad B = -5.7$"
  - "$A = 6.7, \\quad B = -6.7$"
  - "$A = 7.3, \\quad B = -7.3$"
explanation: |
  ■ 1단계: 양(+)의 리미터 전압 $A$ 계산
  • 입력 $V_{\text{in}}$이 상승하여 상단 다이오드 $D_1$이 도통될 때:
    $$V_{\text{in}} > 6\text{ V} + V_{D1} = 6\text{ V} + 0.7\text{ V} = 6.7\text{ V}$$
  • 따라서 출력 전압의 양의 최댓값 $A = 6.7\text{ V}$입니다.

  ■ 2단계: 음(-)의 리미터 전압 $B$ 계산
  • 입력 $V_{\text{in}}$이 하강하여 하단 다이오드 $D_2$가 도통될 때:
    $$V_{\text{in}} < -6\text{ V} - V_{D2} = -6\text{ V} - 0.7\text{ V} = -6.7\text{ V}$$
  • 따라서 출력 전압의 음의 최솟값 $B = -6.7\text{ V}$입니다.

  ■ 최종 결과:
  • $A = 6.7, B = -6.7$ (③번)
