explanation: |
  ■ 1단계: 게이티드 SR 플립플롭의 동작 특성 확인
  • clock=1일 때 입력 신호(SET, RESET)에 따라 출력을 갱신합니다.
  • clock=0일 때는 이전 상태의 출력 $Q$를 그대로 유지합니다.

  ■ 2단계: 각 지점별 출력 $Q$ 상태 분석
  • A 지점 (clock=1): SET=0, RESET=1이므로 리셋 동작이 수행되어 $Q = 0$이 됩니다.
  • B 지점 (clock=0): 클럭이 비활성화된 상태이므로 직전 상태인 $Q = 0$을 유지합니다.
  • C 지점 (clock=1): SET=1, RESET=0이므로 세트 동작이 수행되어 $Q = 1$이 됩니다.
  • D 지점 (clock=1): SET=0, RESET=1이므로 리셋 동작이 수행되어 $Q = 0$이 됩니다.
  • 따라서 A, B, C, D 지점의 출력 순서는 0, 0, 1, 0입니다.

  ■ 최종 결과:
  • 출력값은 0010 (①번)
