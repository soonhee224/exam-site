options:
  - "$\\frac{1}{2}$"
  - "$\\frac{1}{\\sqrt{3}}$"
  - "$\\frac{\\sqrt{3}}{2}$"
  - "$\\frac{1}{\\sqrt{2}}$"
explanation: |
  ■ 1단계: 용량성 리액턴스($X_C$) 및 합성 임피던스($Z$) 계산
  • 각주파수 $\omega = 100\text{ rad/s}, R = 100\text{ }\Omega, C = 100\text{ }\mu\text{F} = 10^{-4}\text{ F}$
  • 커패시터 리액턴스:
    $$X_C = \frac{1}{\omega C} = \frac{1}{100 \times 10^{-4}} = 100\text{ }\Omega$$
  • 합성 임피던스의 크기:
    $$|Z| = \sqrt{R^2 + X_C^2} = \sqrt{100^2 + 100^2} = 100\sqrt{2}\text{ }\Omega$$

  ■ 2단계: 역률(Power Factor) 계산
  • 역률 공식 적용:
    $$\cos\theta = \frac{R}{|Z|} = \frac{100}{100\sqrt{2}} = \frac{1}{\sqrt{2}}$$

  ■ 최종 결과:
  • 역률은 $\frac{1}{\sqrt{2}}$ (④번)
