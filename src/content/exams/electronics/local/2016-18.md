  - "$X = 0, \\quad Y = 0, \\quad Z = 1$"
  - "$X = 1, \\quad Y = 1, \\quad Z = 0$"
explanation: |
  ■ 1단계: 입력 조건 대입
  • $A = 0, B = 1, C = 1, D = 0$

  ■ 2단계: 게이트별 출력 순차 유도
  • 상단 NAND 게이트 출력 $X$:
    $$X = \overline{A \cdot B} = \overline{0 \cdot 1} = 1$$
  • 하단 OR 게이트 출력 $W$:
    $$W = C + D = 1 + 0 = 1$$
  • 중앙 XOR 게이트 출력 $Y$:
    $$Y = X \oplus W = 1 \oplus 1 = 0$$
  • 하단 XNOR 게이트 출력 $Z$ ($W$와 $0$ 입력):
    $$Z = \overline{W \oplus 0} = \overline{1 \oplus 0} = \bar{1} = 0$$

  ■ 최종 결과:
  • $X = 1, Y = 0, Z = 0$ (①번)
