options:
  - "$R_L = 3, \\quad P_L = 25/3$"
  - "$R_L = 3, \\quad P_L = 25/6$"
  - "$R_L = 6, \\quad P_L = 25/3$"
  - "$R_L = 6, \\quad P_L = 25/6$"
explanation: |
  ■ 1단계: 테브난 등가 저항($R_{th}$) 계산
  • 독립 전류원($2\text{ mA}$)을 개방, 독립 전압원($3\text{ V}$)을 단락 처리:
    $$R_{th} = 4\text{ k}\Omega + (3\text{ k}\Omega \parallel 6\text{ k}\Omega) = 4\text{ k}\Omega + 2\text{ k}\Omega = 6\text{ k}\Omega$$
  • 최대 전력 전달 조건: $R_L = R_{th} = 6\text{ k}\Omega$

  ■ 2단계: 테브난 등가 전압($V_{th}$) 계산
  • 병렬 노드 전압 $V$:
    $$-2\text{ mA} + \frac{V}{3\text{ k}\Omega} + \frac{V - 3\text{ V}}{6\text{ k}\Omega} = 0 \implies 3V = 15 \implies V = 5\text{ V}$$
  • $R_L$ 양단 개방 전압:
    $$V_{th} = (2\text{ mA} \times 4\text{ k}\Omega) + (V - 3\text{ V}) = 8\text{ V} + (5\text{ V} - 3\text{ V}) = 10\text{ V}$$

  ■ 3단계: 최대 전달 전력($P_L$) 계산
  • 최대 전력 공식 적용:
    $$P_L = \frac{V_{th}^2}{4R_{th}} = \frac{10^2}{4 \times 6\text{ k}\Omega} = \frac{100}{24}\text{ mW} = \frac{25}{6}\text{ mW}$$

  ■ 최종 결과:
  • $R_L = 6\text{ k}\Omega, P_L = \frac{25}{6}\text{ mW}$ (④번)
