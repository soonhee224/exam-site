  - "ㄱ, ㄴ"
  - "ㄴ, ㄷ"
  - "ㄷ, ㄹ"
  - "ㄴ, ㄹ"
explanation: |
  ■ 1단계: 각 프로토콜의 표준 계층 검토
  • ㄱ. FTP: 파일 전송 프로토콜로 응용 계층(Application Layer)에 속합니다. (옳은 연결)
  • ㄴ. PPP: 점대점 데이터 전송 프로토콜로 데이터링크 계층(Data Link Layer)에 속합니다. (옳지 않은 연결)
  • ㄷ. IP: 패킷 주소 지정 및 라우팅을 담당하며 네트워크 계층(Network Layer)에 속합니다. (옳지 않은 연결)
  • ㄹ. UDP: 비연결형 전송 프로토콜로 트랜스포트 계층(Transport Layer)에 속합니다. (옳은 연결)

  ■ 2단계: 옳지 않은 연결 선별
  • 잘못 매핑된 항목은 ㄴ, ㄷ입니다.

  ■ 최종 결과:
  • 옳지 않은 것으로만 묶인 것은 ㄴ, ㄷ (②번)

인터넷 프로토콜과 동작 계층에 대한 연결로 옳지 않은 것으로만 묶은 것은?

ㄱ. FTP - 응용 계층
ㄴ. PPP - 네트워크 계층
ㄷ. IP - 데이터링크 계층
ㄹ. UDP - 트랜스포트 계층
