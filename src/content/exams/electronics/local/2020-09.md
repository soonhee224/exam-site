answer: 4
options:
  - "$V_C(t) = \\frac{1}{RC} \\frac{dV_{in}(t)}{dt} + V_{in}(t)$"
  - "$V_C(t) = RC \\frac{dV_{in}(t)}{dt} + V_{in}(t)$"
  - "$V_{in}(t) = \\frac{1}{RC} \\frac{dV_C(t)}{dt} + V_C(t)$"
  - "$V_{in}(t) = RC \\frac{dV_C(t)}{dt} + V_C(t)$"
explanation: |
  ■ 1단계: RC 직렬 회로의 KVL 방정식 수립
  • 입력 전압과 각 소자 양단 전압의 합:
    $$V_{in}(t) = V_R(t) + V_C(t)$$

  ■ 2단계: 커패시터 전류 및 저항 전압 대입
  • 커패시터 전류 $i(t) = C \frac{dV_C(t)}{dt}$이므로 저항 양단 전압:
    $$V_R(t) = R i(t) = RC \frac{dV_C(t)}{dt}$$
  • KVL 식에 대입:
    $$V_{in}(t) = RC \frac{dV_C(t)}{dt} + V_C(t)$$

  ■ 최종 결과:
  • 올바른 관계식은 $V_{in}(t) = RC \frac{dV_C(t)}{dt} + V_C(t)$ (④번)
---

다음 R-C 회로에서 입력 전압이 $V_{in}(t)$로 주어질 때, 커패시터 $C$의 양단 전압 $V_C(t)$와 $V_{in}(t)$ 간의 관계식으로 가장 옳은 것은? (단, 회로에서 저항의 저항 값은 $R\text{ }[\Omega]$, 커패시터의 정전용량은 $C\text{ [F]}$이다.)
