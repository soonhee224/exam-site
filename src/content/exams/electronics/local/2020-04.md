answer: 3
options:
  - "$A + AB = A$"
  - "$A + A'B = A + B$"
  - "$A'B + AB' = A + B$"
  - "$(A + B) \\cdot (A + C) = A + BC$"
explanation: |
  ■ 1단계: 부울 대수 기본 정리 검토 (보기 ③ 판별)
  • 좌변 $A'B + AB'$는 배타적 논리합(XOR, $A \oplus B$) 연산식입니다.
  • $A = 1, B = 1$일 때 좌변은 $0 + 0 = 0$이지만 우변은 $1 + 1 = 1$이므로 등식이 성립하지 않습니다. (③번 옳지 않음)

  ■ 2단계: 기타 보기 검토
  • ①번: $A + AB = A(1 + B) = A$ (옳은 식)
  • ②번: $A + A'B = (A + A')(A + B) = 1(A + B) = A + B$ (옳은 식)
  • ④번: $(A + B)(A + C) = AA + AC + AB + BC = A + BC$ (옳은 식)

  ■ 최종 결과:
  • 가장 옳지 않은 것은 ③번
