  - "$r_1 = 10/6\\text{ [}\\Omega\\text{]}, r_2 = 5/6\\text{ [}\\Omega\\text{]}$"
  - "$r_1 = 5/6\\text{ [}\\Omega\\text{]}, r_2 = 10/6\\text{ [}\\Omega\\text{]}$"
explanation: |
  ■ 1단계: 전압 분배에 따른 각 저항 양단 전압 계산
  • $V_1 + V_2 = 10\text{ V}$이고 $V_1 = 2V_2$이므로:
    $$2V_2 + V_2 = 10\text{ V} \implies V_2 = \frac{10}{3}\text{ V}, \quad V_1 = \frac{20}{3}\text{ V}$$

  ■ 2단계: 옴의 법칙을 통한 저항값 계산
  • 직렬 전류 $I = 4\text{ A}$ 대입:
    $$r_1 = \frac{V_1}{I} = \frac{20/3\text{ V}}{4\text{ A}} = \frac{5}{3}\text{ }\Omega = \frac{10}{6}\text{ }\Omega$$
    $$r_2 = \frac{V_2}{I} = \frac{10/3\text{ V}}{4\text{ A}} = \frac{5}{6}\text{ }\Omega$$

  ■ 최종 결과:
  • $r_1 = 10/6\text{ }[\Omega], r_2 = 5/6\text{ }[\Omega]$ (③번)
