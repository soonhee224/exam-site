  - "③"
  - "④"
explanation: |
  ■ 1단계: 입력 전압별 다이오드 상태 분석
  • 입력 $v_{\text{in}} \le V_D$일 때:
    - 다이오드가 도통되지 않으므로 차단(OFF) 상태가 됩니다.
    - 저항으로 전류가 흐르지 않아 출력 전압은 $v_{\text{out}} = 0\text{ V}$가 됩니다.
  • 입력 $v_{\text{in}} > V_D$일 때:
    - 다이오드가 순방향 도통(ON)되어 $V_D$의 전압 강하가 발생합니다.
    - 출력 전압:
      $$v_{\text{out}} = v_{\text{in}} - V_D$$
    - 이는 $v_{\text{in}}$에 대해 기울기 1로 선형 증가하는 직선이 됩니다.

  ■ 2단계: 전달 특성 곡선 판별
  • $v_{\text{in}} \le V_D$에서는 0 V를 유지하다가 $v_{\text{in}} > V_D$에서 기울기 1로 상승하는 특성을 나타내는 그래프는 ②번입니다.

  ■ 최종 결과:
  • 올바른 전달특성은 ②번
