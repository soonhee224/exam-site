title: "2014년 지방직 9급 전자공학개론 2번"
answer: 5
options:
  - "$\\frac{1}{13}\\text{ [V]}$"
  - "$\\frac{5}{16}\\text{ [V]}$"
  - "$1\\text{ [V]}$"
  - "$\\frac{1}{2}\\text{ [V]}$"
  - "$\\frac{6}{13}\\text{ [V]}$"
explanation: |
  ■ 1단계: 전압계 미연결 시 실제 출력 전압($V_2$) 계산
  • 입력 전압 $V_1 = 9\text{ V}$, 전압 분배 저항 $R_1 = 10\text{ k}\Omega$, $R_2 = 20\text{ k}\Omega$
  • 전압 분배 법칙에 따른 $R_2$ 양단의 실제 전압 $V_2$:
    $$V_2 = \frac{R_2}{R_1 + R_2} \times V_1 = \frac{20\text{ k}\Omega}{10\text{ k}\Omega + 20\text{ k}\Omega} \times 9\text{ V} = 6\text{ V}$$

  ■ 2단계: 전압계 연결 시 측정 전압($V_3$) 계산
  • 내부 저항 $R_3 = 80\text{ k}\Omega$인 전압계가 저항 $R_2$에 병렬 연결될 때의 합성 등가 저항 $R_p$:
    $$R_p = R_2 \parallel R_3 = \frac{20\text{ k}\Omega \times 80\text{ k}\Omega}{20\text{ k}\Omega + 80\text{ k}\Omega} = 16\text{ k}\Omega$$
  • 전압계 연결 후 지시되는 측정 전압 $V_3$:
    $$V_3 = \frac{R_p}{R_1 + R_p} \times V_1 = \frac{16\text{ k}\Omega}{10\text{ k}\Omega + 16\text{ k}\Omega} \times 9\text{ V} = \frac{16}{26} \times 9 = \frac{72}{13}\text{ V}$$

  ■ 3단계: 측정 오차(실제치와 지시치 차이) 도출
  • 두 전압의 차이 계산:
    $$\Delta V = \left| V_2 - V_3 \right| = 6 - \frac{72}{13} = \frac{78}{13} - \frac{72}{13} = \frac{6}{13}\text{ V}$$

  ■ 최종 결과:
  • 측정 전압과 실제 전압의 차이는 $\frac{6}{13}$ [V] (⑤번)
