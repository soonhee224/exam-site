answer: 3
options:
  - "$\\frac{R_2}{R_1} = \\frac{L}{C}$"
  - "$R_1 L = \\frac{R_2}{C}$"
  - "$R_1 C = \\frac{L}{R_2}$"
  - "$R_1 R_2 = \\frac{L}{C}$"
explanation: |
  ■ 1단계: 교류 브리지 평형 조건 수립
  • 대각선 임피던스의 곱 평형식:
    $$Z_1 Z_4 = Z_2 Z_3$$
  • 각 가지의 임피던스 대입 ($Z_1 = R_1, Z_2 = j\omega L, Z_3 = R_2, Z_4 = \frac{1}{j\omega C}$):
    $$R_1 \left(\frac{1}{j\omega C}\right) = (j\omega L) R_2$$

  ■ 2단계: 평형식 정리
  • 양변을 정리하면:
    $$\frac{R_1}{C} = \frac{L}{R_2} \cdot \omega^2 \cdot (-1) \implies R_1 C = \frac{L}{R_2}$$

  ■ 최종 결과:
  • 브리지 평형조건은 $R_1 C = \frac{L}{R_2}$ (③번)
