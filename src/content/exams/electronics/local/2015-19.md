  - "$R_L = 4\\text{ [k}\\Omega\\text{]일 때, } P_L = 5\\text{ [mW]}$"
  - "$R_L = 5\\text{ [k}\\Omega\\text{]일 때, } P_L = 4\\text{ [mW]}$"
  - "$R_L = 5\\text{ [k}\\Omega\\text{]일 때, } P_L = 5\\text{ [mW]}$"
explanation: |
  ■ 1단계: 테브난 등가 저항($R_{th}$) 및 부하 저항($R_L$) 계산
  • $30\text{ V}$ 전압원을 단락 처리하고 부하 단자에서 바라본 테브난 등가 저항:
    $$R_{th} = 3\text{ k}\Omega + (6\text{ k}\Omega \parallel 3\text{ k}\Omega) = 3\text{ k}\Omega + 2\text{ k}\Omega = 5\text{ k}\Omega$$
  • 최대 전력 전달 조건에 따라:
    $$R_L = R_{th} = 5\text{ k}\Omega$$

  ■ 2단계: 테브난 등가 전압($V_{th}$) 및 최대 소비전력($P_L$) 계산
  • 부하 개방 시 분배 전압:
    $$V_{th} = 30\text{ V} \times \frac{3\text{ k}\Omega}{6\text{ k}\Omega + 3\text{ k}\Omega} = 10\text{ V}$$
  • 부하에 전달되는 최대 전력:
    $$P_L = \frac{V_{th}^2}{4R_L} = \frac{10^2}{4 \times 5\text{ k}\Omega} = \frac{100}{20\text{ k}\Omega} = 5\text{ mW}$$

  ■ 최종 결과:
  • $R_L = 5\text{ [k}\Omega\text{]일 때, } P_L = 5\text{ [mW]}$ (④번)
