answer: 1
options:
  - "(가) $Y = A + B + C$,  (나) $Y = ABC$"
  - "(가) $Y = ABC$,  (나) $Y = A + B + C$"
  - "(가) $Y = A + B + C$,  (나) $Y = \\overline{ABC}$"
  - "(가) $Y = \\overline{ABC}$,  (나) $Y = A + B + C$"
explanation: |
  ■ 1단계: 회로 (가) 분석 (다이오드 OR 게이트)
  • 입력 $A, B, C$ 중 하나라도 High($V_{CC}$)가 되면 해당 다이오드가 순방향 도통되어 출력 $Y$에 High 전위가 나타납니다.
  • 모든 입력이 Low일 때만 출력이 Low가 되므로 회로 (가)는 OR 게이트로 동작합니다:
    $$Y = A + B + C$$

  ■ 2단계: 회로 (나) 분석 (다이오드 AND 게이트)
  • 풀업 저항 구조에서 입력 $A, B, C$ 중 하나라도 Low(0V)가 되면 해당 다이오드가 도통하여 출력이 0V로 끌어내려집니다.
  • 모든 입력이 High일 때만 모든 다이오드가 차단되어 출력이 High가 되므로 회로 (나)는 AND 게이트로 동작합니다:
    $$Y = ABC$$

  ■ 최종 결과:
  • (가) $Y = A + B + C$, (나) $Y = ABC$ (①번)
