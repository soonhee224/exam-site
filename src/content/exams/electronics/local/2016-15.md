options:
  - "$F = C + \\bar{A}BC$"
  - "$F = C + \\bar{A}B$"
  - "$F = C + B$"
  - "$F = C + \\bar{A}$"
explanation: |
  ■ 1단계: 부울 대수식 묶기
  • 주어진 식:
    $$F = \bar{A}C + \bar{A}B + A\bar{B}C + BC$$
  • 변수 $C$가 포함된 항들을 공통 인수로 묶음:
    $$F = C(\bar{A} + A\bar{B} + B) + \bar{A}B$$

  ■ 2단계: 괄호 내부 간략화
  • 분배 법칙 적용 ($A\bar{B} + B = A + B$):
    $$\bar{A} + A\bar{B} + B = \bar{A} + A + B = 1 + B = 1$$
  • 따라서:
    $$F = C(1) + \bar{A}B = C + \bar{A}B$$

  ■ 최종 결과:
  • 간소화된 식은 $F = C + \bar{A}B$ (②번)
