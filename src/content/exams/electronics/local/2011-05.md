options:
  - "$V_{TH} = 8\\text{ [V]}, \\quad R_{TH} = 9\\text{ [}\\Omega\\text{]}$"
  - "$V_{TH} = 8\\text{ [V]}, \\quad R_{TH} = 16\\text{ [}\\Omega\\text{]}$"
  - "$V_{TH} = 12\\text{ [V]}, \\quad R_{TH} = 9\\text{ [}\\Omega\\text{]}$"
  - "$V_{TH} = 12\\text{ [V]}, \\quad R_{TH} = 16\\text{ [}\\Omega\\text{]}$"
explanation: |
  ■ 1단계: 테브난 등가저항($R_{TH}$) 계산
  • 전압원을 단락 처리하고 부하 단자에서 바라본 합성 저항:
    $$R_{TH} = (3\text{ }\Omega \parallel 6\text{ }\Omega) + 7\text{ }\Omega = 2\text{ }\Omega + 7\text{ }\Omega = 9\text{ }\Omega$$

  ■ 2단계: 테브난 등가전압($V_{TH}$) 계산
  • 부하 개방 시 $7\text{ }\Omega$ 저항에는 전류가 흐르지 않으므로 $6\text{ }\Omega$ 저항 양단 전압이 테브난 전압이 됩니다:
    $$V_{TH} = 12\text{ V} \times \frac{6\text{ }\Omega}{3\text{ }\Omega + 6\text{ }\Omega} = 8\text{ V}$$

  ■ 최종 결과:
  • $V_{TH} = 8\text{ [V]}, R_{TH} = 9\text{ }[\Omega]$ (①번)
