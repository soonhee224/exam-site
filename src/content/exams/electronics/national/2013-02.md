options:
  - "$Y_{11} = 2, \\quad Y_{22} = 3$"
  - "$Y_{11} = 6, \\quad Y_{22} = 10$"
  - "$Y_{11} = 8, \\quad Y_{22} = 10$"
  - "$Y_{11} = 8, \\quad Y_{22} = 12$"
explanation: |
  ■ 1단계: Y-파라미터의 정의식 수립
  • 4단자 $\pi$형 회로망의 Y-파라미터 정의식:
    $$Y_{11} = \left.\frac{I_1}{V_1}\right|_{V_2 = 0}, \quad Y_{22} = \left.\frac{I_2}{V_2}\right|_{V_1 = 0}$$

  ■ 2단계: 단락 입력 어드미턴스($Y_{11}$) 계산
  • 출력 단자를 단락($V_2 = 0$)하면 $Y_c$는 단락되어 제거되고, $Y_b$의 오른쪽 단자가 접지에 연결됩니다.
  • 따라서 입력 포트에서 바라본 합성 어드미턴스는 $Y_a$와 $Y_b$의 병렬 합입니다:
    $$Y_{11} = Y_a + Y_b = 2\text{ }\Omega^{-1} + 4\text{ }\Omega^{-1} = 6\text{ }\Omega^{-1}$$

  ■ 3단계: 단락 출력 어드미턴스($Y_{22}$) 계산
  • 입력 단자를 단락($V_1 = 0$)하면 $Y_a$는 단락되어 제거되고, $Y_b$의 왼쪽 단자가 접지에 연결됩니다.
  • 따라서 출력 포트에서 바라본 합성 어드미턴스는 $Y_b$와 $Y_c$의 병렬 합입니다:
    $$Y_{22} = Y_b + Y_c = 4\text{ }\Omega^{-1} + 6\text{ }\Omega^{-1} = 10\text{ }\Omega^{-1}$$

  ■ 최종 결과:
  • $Y_{11} = 6, \quad Y_{22} = 10$ (②번)
