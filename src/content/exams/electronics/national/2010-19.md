options:
  - "“?”가 D플립-플롭인 경우에, a는 0의 값을 갖는다."
  - "“?”가 D플립-플롭인 경우에, b는 0의 값을 갖는다."
  - "“?”가 T플립-플롭인 경우에, c는 1의 값을 갖는다."
  - "“?”가 T플립-플롭인 경우에, d는 1의 값을 갖는다."
explanation: |
  ■ 1단계: 플립플롭별 특성 방정식 확인
  • D 플립플롭: $Q(t+1) = D$
  • T 플립플롭: $Q(t+1) = T \oplus Q(t)$

  ■ 2단계: 각 변수 $a, b, c, d$ 값 판별
  • D 플립플롭인 경우:
    - ? = 0, Q(t) = 0 일 때: $a = D = 0$ (①번 옳은 설명)
    - ? = 0, Q(t) = 1 일 때: $b = D = 0$ (②번 옳은 설명)
  • T 플립플롭인 경우:
    - ? = 1, Q(t) = 0 일 때: $c = 1 \oplus 0 = 1$ (③번 옳은 설명)
    - ? = 1, Q(t) = 1 일 때: $d = 1 \oplus 1 = 0$ (④번 옳지 않음)

  ■ 최종 결과:
  • 옳지 않은 설명은 ④번
