answer: 2
options:
  - "$V_P = 2$, $g_m = 2$"
  - "$V_P = 2$, $g_m = 5$"
  - "$V_P = 8$, $g_m = 2$"
  - "$V_P = 8$, $g_m = 5$"
explanation: |
  ■ 1단계: 드레인 특성곡선에서 핀치오프 전압($V_P$) 확인
  • $V_{GS} = 0\text{ V}$ 곡선에서 드레인 전류 $I_D$가 상승하다가 포화되기 시작하는 경계 지점의 전압이 핀치오프 전압 $V_P$입니다.
  • 그래프에서 전류가 일정해지기 시작하는 수평 영역 진입 전압은 $V_{DS} = 2\text{ V}$이므로 $V_P = 2\text{ V}$입니다.

  ■ 2단계: 동작점에서 순방향 전달 컨덕턴스($g_m$) 계산
  • 전달 컨덕턴스 정의식:
    $$g_m = \frac{\Delta I_D}{\Delta V_{GS}}\bigg|_{V_{DS} = 10\text{ V}}$$
  • $V_{DS} = 10\text{ V}$ 포화 영역에서 두 곡선의 값을 추출:
    - $V_{GS} = 0\text{ V}$ 일 때: $I_D \approx 6.0\text{ mA}$
    - $V_{GS} = -0.4\text{ V}$ 일 때: $I_D \approx 4.0\text{ mA}$
  • 수치 대입 및 계산:
    $$\Delta V_{GS} = 0 - (-0.4) = 0.4\text{ V}$$
    $$\Delta I_D = 6.0 - 4.0 = 2.0\text{ mA}$$
    $$g_m = \frac{2.0\text{ mA}}{0.4\text{ V}} = 5\text{ mS}$$

  ■ 최종 결과:
  • $V_P = 2\text{ V}, \quad g_m = 5\text{ mS}$ (②번)
