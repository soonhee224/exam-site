  - "ㄱ, ㄴ, ㄷ, ㄹ"
explanation: |
  ■ 1단계: 각 논리회로(ㄱ~ㄹ)의 출력 논리식($Y$) 유도
  • ㄱ (기본 XOR 회로 구조):
    $$Y = A\bar{B} + \bar{A}B = A \oplus B$$
  • ㄴ (XNOR 반전 회로 구조):
    $$Y = \overline{AB + \bar{A}\bar{B}} = \overline{AB} \cdot \overline{\bar{A}\bar{B}} = (\bar{A} + \bar{B})(A + B)$$
    $$Y = \bar{A}A + \bar{A}B + A\bar{B} + \bar{B}B = A\bar{B} + \bar{A}B = A \oplus B$$
  • ㄷ (NOR 기반 회로망):
    $$Y = \overline{(A + B)(\bar{A} + \bar{B})} = \overline{A + B} + \overline{\bar{A} + \bar{B}} = \bar{A}\bar{B} + AB$$
    - 최종 출력을 반전 처리하여 정리하면:
    $$Y = \overline{AB + \bar{A}\bar{B}} = A\bar{B} + \bar{A}B = A \oplus B$$
  • ㄹ (NAND 게이트 4개로 구성된 2입력 XOR 회로망):
    - 4개의 2입력 NAND 게이트로 구성된 표준 배타적 논리합(XOR) 구현 구조:
    $$Y = A \oplus B = A\bar{B} + \bar{A}B$$

  ■ 2단계: 결과 비교 및 판별
  • 유도 결과 ㄱ, ㄴ, ㄷ, ㄹ의 모든 회로가 동일한 2입력 XOR 논리식($Y = A\bar{B} + \bar{A}B$)을 출력합니다.
  • 따라서 출력 논리식이 같은 회로는 'ㄱ, ㄴ, ㄷ, ㄹ' 전체입니다.

  ■ 최종 결과:
  • 옳은 조합은 ④번
