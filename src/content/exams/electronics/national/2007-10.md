answer: 4
options:
  - "$F(A,B,C,D) = A'D + AC'D' + A'BC + ACD'$"
  - "$F(A,B,C,D) = (A'+D')(A+C+D)(A+B+D)$"
  - "$F(A,B,C,D) = A \\oplus D + A'BC$"
  - "$F(A,B,C,D) = A'D + AD' + BC$"
explanation: |
  ■ 1단계: 카르노 맵 데이터 분석
  • $A'D$는 열 $D=1, A=0$인 4개 셀을 포괄합니다.
  • $AD'$는 열 $D=0, A=1$인 4개 셀을 포괄합니다.
  • 남은 1의 셀($m_6 = 0110$)을 묶으면 $A'BC$가 됩니다.
  • 따라서 올바른 간략화 식은 $F = A'D + AD' + A'BC = A \oplus D + A'BC$입니다.

  ■ 2단계: 보기 ④번 오류 검증
  • 보기 ④번의 항 $BC$는 $(A,B,C,D) = (1,1,1,1)$ 셀을 포함합니다.
  • 카르노 맵 상에서 $(1,1,1,1)$ 셀의 실제 값은 0이므로, $BC$를 포함한 논리식은 원 카르노 맵과 일치하지 않습니다. (④번 옳지 않음)

  ■ 최종 결과:
  • 잘못된 표현식은 ④번
