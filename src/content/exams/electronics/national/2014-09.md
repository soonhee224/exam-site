answer: 1
options:
  - "$D_A = X + B$"
  - "$D_A = A'X + A'B + BX$"
  - "$D_A = A'X + AB + AB'X$"
  - "$D_A = X + AB'$"
explanation: |
  ■ 1단계: 플립플롭 A의 입력 $D_A$ 진리표 추출
  • D-플립플롭의 입력은 다음 상태 출력과 동일합니다 ($D_A = A(t+1)$).
  • 상태표로부터 $A(t+1) = 1$인 민텀을 추출:
    - $(A, B, X) = (0, 0, 1) \implies m_1$
    - $(A, B, X) = (0, 1, 0) \implies m_2$
    - $(A, B, X) = (0, 1, 1) \implies m_3$
    - $(A, B, X) = (1, 0, 1) \implies m_5$
  • 상태표에 정의되지 않은 $AB = 11$ 상태는 Don't Care($d$)로 처리:
    - $(A, B, X) = (1, 1, 0), (1, 1, 1) \implies d_6, d_7$

  ■ 2단계: 카르노 맵 간략화
  • 민텀 및 Don't Care 배치: $\sum m(1, 2, 3, 5) + d(6, 7)$
  • 4칸 묶음 구성:
    - $m(1, 3, 5, 7)$ 묶음 $\implies X$
    - $m(2, 3, 6, 7)$ 묶음 $\implies B$
  • 논리합으로 결합:
    $$D_A = X + B$$

  ■ 최종 결과:
  • $D_A$에 대한 논리식은 $D_A = X + B$ (①번)
