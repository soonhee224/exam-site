options:
  - "차동증폭기는 두 개의 입력에 함께 작용하는 잡음 성분을 제거하는 효과가 있다."
  - "이상적인 차동 증폭기의 동상모드제거비(CMRR)는 $\\infty$이다."
  - "차동증폭기는 두 개의 입력 차이에 상관없이 출력을 일정하게 만들 수 있는 증폭기이다."
  - "차동증폭기는 2개의 트랜지스터를 대칭적으로 구성하여 회로를 설계한다."
explanation: |
  ■ 1단계: 차동 증폭기(Differential Amplifier)의 동작 원리
  • 차동 증폭기는 두 입력 신호의 차이($v_d = v_1 - v_2$)를 증폭하여 출력하는 회로입니다:
    $$v_o = A_d (v_1 - v_2) + A_c \left(\frac{v_1 + v_2}{2}\right)$$
  • 두 입력의 차이 전압($v_d$)에 비례하여 출력이 변동하므로, "두 입력 차이에 상관없이 출력을 일정하게 만든다"는 설명은 증폭기의 기본 동작 특성에 위배됩니다. (③번 옳지 않음)

  ■ 2단계: 보기별 특성 검토
  • ①번: 두 입력 단자에 동일하게 인가되는 공통 모드 잡음(Common-mode noise)은 차동 구조에 의해 상쇄 제거됩니다. (옳은 설명)
  • ②번: 이상적인 차동 증폭기는 공통 모드 이득이 $A_c = 0$이므로, 동상신호제거비(CMRR)는 무한대입니다:
    $$\text{CMRR} = \left|\frac{A_d}{A_c}\right| = \frac{A_d}{0} \to \infty$$
    (옳은 설명)
  • ④번: 두 입력 간의 오프셋을 최소화하고 높은 CMRR을 얻기 위해 특성이 동일한 2개의 트랜지스터를 대칭 구조로 배치합니다. (옳은 설명)

  ■ 최종 결과:
  • 옳지 않은 설명은 ③번
