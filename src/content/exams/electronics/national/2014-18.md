answer: 2
options:
  - "AB"
  - "B"
  - "AB + C'"
  - "A + BC'"
explanation: |
  ■ 1단계: 공통 변수 $B$ 묶기
  • 주어진 논리식:
    $$F = A'B(D' + C'D) + B(A + A'CD)$$
  • 공통 변수 $B$로 묶어 정리:
    $$F = B \left[ A'(D' + C'D) + A + A'CD \right]$$

  ■ 2단계: 불 대수 공식을 이용한 식 간략화
  • $X + X'Y = X + Y$ 공식 적용:
    - $D' + C'D = D' + C'$
    - $A + A'CD = A + CD$
  • 대괄호 식에 대입:
    $$F = B \left[ A'(D' + C') + A + CD \right]$$
  • 괄호 전개 및 재배열:
    $$A'D' + A'C' + A + CD = (A + A'D') + A'C' + CD = A + D' + A'C' + CD$$
  • $A + A'C' = A + C'$ 및 $D' + CD = D' + C$ 적용:
    $$(A + C') + (D' + C) = A + D' + (C' + C) = A + D' + 1 = 1$$
  • 따라서:
    $$F = B \cdot 1 = B$$

  ■ 최종 결과:
  • 간략화된 식은 B (②번)
