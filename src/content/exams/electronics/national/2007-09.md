options:
  - "$V_o = (V_Z + V_{BE2})\\left(1 + \\frac{R_1}{R_2}\\right)$"
  - "$V_o = (V_Z - V_{BE2})\\left(1 + \\frac{R_1}{R_2}\\right)$"
  - "$V_o = (V_Z - V_{BE1})\\left(1 + \\frac{R_2}{R_1}\\right)$"
  - "$V_o = (V_Z + V_{BE1})\\left(1 + \\frac{R_2}{R_1}\\right)$"
explanation: |
  ■ 1단계: 트랜지스터 $Q_2$의 베이스 전압($V_{B2}$) 표현
  • 출력 전압 $V_o$가 저항 $R_1, R_2$에 의해 분배되어 $Q_2$의 베이스로 인가됩니다:
    $$V_{B2} = \frac{R_2}{R_1 + R_2} V_o$$

  ■ 2단계: 루프 관계식 수립
  • $Q_2$의 이미터가 제너 다이오드 전압 $V_Z$로 고정되어 있으므로:
    $$V_{B2} = V_{E2} + V_{BE2} = V_Z + V_{BE2}$$

  ■ 3단계: 출력 전압($V_o$) 수식 유도
  • 두 식을 연립하여 $V_o$에 대해 정리:
    $$\frac{R_2}{R_1 + R_2} V_o = V_Z + V_{BE2}$$
    $$V_o = \left(\frac{R_1 + R_2}{R_2}\right)(V_Z + V_{BE2}) = (V_Z + V_{BE2})\left(1 + \frac{R_1}{R_2}\right)$$

  ■ 최종 결과:
  • 출력 전압 식은 $V_o = (V_Z + V_{BE2})\left(1 + \frac{R_1}{R_2}\right)$ (①번)
