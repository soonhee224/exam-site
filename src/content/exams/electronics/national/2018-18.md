options:
  - "$Z + XY$"
  - "$Y + \\bar{X}\\bar{Z}$"
  - "$X + Y\\bar{Z}$"
  - "$Y + XZ$"
explanation: |
  ■ 1단계: 주어진 논리식 전개
  • 문제의 부울 대수식:
    $$F = XYZ + \bar{X}Y\bar{Z} + \bar{X}YZ + X\bar{Y}Z + XY\bar{Z}$$

  ■ 2단계: 공통 인수를 이용한 항 결합 및 간소화
  • $Y$를 포함하는 항들을 묶어 간소화:
    - $XYZ + XY\bar{Z} = XY(Z + \bar{Z}) = XY(1) = XY$
    - $\bar{X}YZ + \bar{X}Y\bar{Z} = \bar{X}Y(Z + \bar{Z}) = \bar{X}Y(1) = \bar{X}Y$
  • 결합된 식을 대입하여 다시 정리:
    $$F = XY + \bar{X}Y + X\bar{Y}Z = Y(X + \bar{X}) + X\bar{Y}Z = Y + X\bar{Y}Z$$
  • 흡수 법칙($A + \bar{A}B = A + B$) 적용:
    $$F = Y + XZ$$

  ■ 최종 결과:
  • 동일한 논리식은 $Y + XZ$ (④번)
