options:
  - "$V_{UTP} = +1$, $V_{LTP} = -1$"
  - "$V_{UTP} = +1$, $V_{LTP} = -3$"
  - "$V_{UTP} = +3$, $V_{LTP} = -1$"
  - "$V_{UTP} = +3$, $V_{LTP} = -3$"
explanation: |
  ■ 1단계: 슈미트 트리거 회로의 비반전 단자 기준 전압식 유도
  • 출력 전압 $V_{\text{out}}$이 저항 $R_A, R_B$에 의해 분배되어 비반전 단자($V_+$)로 양귀환됩니다:
    $$V_+ = V_{\text{out}} \times \frac{R_A}{R_A + R_B}$$
  • $R_B = 3R_A$ 조건을 대입하여 정리:
    $$V_+ = V_{\text{out}} \times \frac{R_A}{R_A + 3R_A} = \frac{1}{4}V_{\text{out}}$$

  ■ 2단계: 상측 트리거 전압($V_{UTP}$) 및 하측 트리거 전압($V_{LTP}$) 계산
  • 상측 트리거 전압 ($V_{\text{out}} = +V_{\text{out(max)}} = +4\text{ V}$):
    $$V_{UTP} = \frac{1}{4} \times (+4\text{ V}) = +1\text{ V}$$
  • 하측 트리거 전압 ($V_{\text{out}} = -V_{\text{out(max)}} = -4\text{ V}$):
    $$V_{LTP} = \frac{1}{4} \times (-4\text{ V}) = -1\text{ V}$$

  ■ 최종 결과:
  • $V_{UTP} = +1\text{ V}, \quad V_{LTP} = -1\text{ V}$ (①번)
