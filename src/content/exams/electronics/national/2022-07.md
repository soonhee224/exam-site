options:
  - "공통모드 입력 차동증폭기이다."
  - "이미터신호 $V_e$는 입력신호 $V_{in}$과 동위상이다."
  - "출력신호 $V_{out1}$은 입력신호 $V_{in}$과 동위상이다."
  - "출력신호 $V_{out2}$는 입력신호 $V_{in}$과 역위상이다."
explanation: |
  ■ 1단계: 단일 입력 차동증폭기의 구조 및 동작 원리
  • $Q_1$의 베이스에 단일 입력 $V_{in}$이 인가되고, $Q_2$의 베이스는 접지(AC 접지)되어 있는 단일 입력(Single-ended Input) 차동증폭기입니다.
  • $Q_1$ 관점:
    - 베이스 입력 - 이미터 출력 구성은 이미터 팔로워(공통 컬렉터) 증폭기로 동작하므로, 공통 이미터 노드의 전압 $V_e$는 입력 $V_{in}$과 '동위상'을 유지합니다.
    - 베이스 입력 - 컬렉터 출력 구성은 공통 이미터(CE) 증폭기로 동작하므로, 출력 $V_{out1}$은 입력 $V_{in}$과 '$180^\circ$ 역위상'이 됩니다.
  • $Q_2$ 관점:
    - 베이스가 접지된 상태에서 이미터 노드($V_e$)로 신호가 인가되어 컬렉터로 출력되는 공통 베이스(CB) 증폭기로 동작합니다.
    - 공통 베이스는 입력과 출력이 동위상이므로, 출력 $V_{out2}$는 이미터 신호 $V_e$ 및 입력 $V_{in}$과 '동위상'이 됩니다.

  ■ 2단계: 보기별 정오 판별

  • ①번 (오답):
    두 베이스에 동일한 신호가 들어가는 공통 모드가 아니라, 한쪽에만 신호가 입력되는 단일 입력(차동 모드 신호 포함) 구성입니다.

  • ②번 (옳은 설명):
    $Q_1$의 이미터 팔로워 동작에 의해 공통 이미터 신호 $V_e$는 입력 $V_{in}$과 동위상입니다.

  • ③번 (오답):
    $Q_1$의 공통 이미터 증폭 작용에 의해 $V_{out1}$은 $V_{in}$과 $180^\circ$ 역위상입니다.

  • ④번 (오답):
    $Q_2$의 공통 베이스 증폭 작용에 의해 $V_{out2}$는 $V_{in}$과 동위상입니다.

  ■ 최종 결과:
  • 옳은 설명은 ②번
