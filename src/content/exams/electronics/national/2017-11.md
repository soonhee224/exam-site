explanation: |
  ■ 1단계: 주어진 부울 대수식의 간소화
  • 주어진 논리식을 공통 인수로 묶어 간략화합니다:
    $$F(W, X, Y) = \bar{W}XY + W\bar{X} + WXY$$
    $$F = (\bar{W}XY + WXY) + W\bar{X}$$
    $$F = (\bar{W} + W)XY + W\bar{X}$$
  • 보수 법칙($\bar{W} + W = 1$)을 적용:
    $$F = XY + W\bar{X}$$

  ■ 2단계: 출력이 1($F = 1$)이 되는 입력 조합 분석
  • $XY = 1$ 조건: $X = 1, Y = 1$인 경우 ($W$는 0 또는 1)
    - $(W, X, Y) = (0, 1, 1), (1, 1, 1)$ 일 때 $F = 1$
  • $W\bar{X} = 1$ 조건: $W = 1, X = 0$인 경우 ($Y$는 0 또는 1)
    - $(W, X, Y) = (1, 0, 0), (1, 0, 1)$ 일 때 $F = 1$

  ■ 3단계: 진리표 값 비교
  • 입력 조합별 출력 $F$ 값:
    - $(0, 0, 0) \to 0$
    - $(0, 0, 1) \to 0$
    - $(0, 1, 0) \to 0$
    - $(0, 1, 1) \to 1$
    - $(1, 0, 0) \to 1$
    - $(1, 0, 1) \to 1$
    - $(1, 1, 0) \to 0$
    - $(1, 1, 1) \to 1$
  • 이 출력을 만족하는 것은 ①번 진리표입니다.

  ■ 최종 결과:
  • 올바른 진리표는 ①번
