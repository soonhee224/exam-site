title: "2016년 국가직 9급 전자공학개론 1번"
answer: 4
options:
  - "$\\bar{A} \\cdot \\bar{B} + A \\cdot B$"
  - "$\\overline{A \\oplus B}$"
  - "$(\\bar{A} + B) \\cdot (A + \\bar{B})$"
  - "$A \\cdot \\bar{B} + \\bar{A} \\cdot B$"
explanation: |
  ■ 1단계: 각 보기의 논리식 전개 및 연산 특성 분석
  • ①번 식: $\bar{A}\bar{B} + AB$
    - 두 입력의 상태가 서로 일치할 때 출력이 1이 되는 대표적인 XNOR(배타적 부정 논리합) 식입니다.
  • ②번 식: $\overline{A \oplus B}$
    - XOR 연산의 부정으로, XNOR 연산의 기본 표현식입니다.
  • ③번 식: $(\bar{A} + B)(A + \bar{B})$
    - 분배 법칙을 적용하여 전개:
      $$(\bar{A} + B)(A + \bar{B}) = \bar{A}A + \bar{A}\bar{B} + BA + B\bar{B}$$
    - 동일 변수와 보수의 곱은 0이므로 ($\bar{A}A = 0$, $B\bar{B} = 0$):
      $$(\bar{A} + B)(A + \bar{B}) = \bar{A}\bar{B} + AB$$
    - 이는 XNOR 연산과 동일합니다.
  • ④번 식: $A\bar{B} + \bar{A}B$
    - 두 입력의 상태가 서로 다를 때 출력이 1이 되는 XOR(배타적 논리합) 식입니다 ($A \oplus B$).

  ■ 2단계: 최종 판별
  • ①, ②, ③번 식은 모두 동일한 XNOR 논리식을 나타내며, ④번 식만 유일하게 XOR 논리식입니다.

  ■ 최종 결과:
  • 나머지 셋과 다른 논리식은 ④번
