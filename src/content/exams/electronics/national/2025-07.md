explanation: |
  ■ 1단계: 비반전 슈미트 트리거 동작 조건 분석
  • 출력이 연산증폭기의 비반전(+) 단자로 귀환되는 비반전 슈미트 트리거(Non-Inverting Schmitt Trigger) 회로입니다.
  • 주어진 조건:
    포화 전압: $V_{OH} = +12\text{ V},\ V_{OL} = -12\text{ V}$
    저항: $R_1 = 500\ \Omega,\ R_2 = 1.5\text{ k}\Omega = 1{,}500\ \Omega$
  • 비반전 단자 전압($v_+$):
    $v_+ = \frac{R_2 v_{in} + R_1 v_{out}}{R_1 + R_2}$

  ■ 2단계: 문턱전압($V_{TL}, V_{TH}$) 계산
  • 출력이 상태 반전(전이)하는 조건은 반전(-) 단자 기준 전압인 $0\text{ V}$를 넘는 순간($v_+ = 0$)입니다.
    $R_2 v_{in} + R_1 v_{out} = 0 \quad \rightarrow \quad v_{in} = -\frac{R_1}{R_2} v_{out} = -\frac{500}{1{,}500} v_{out} = -\frac{1}{3} v_{out}$
  • 하한 문턱전압($V_{TL}$, 출력 $v_{out} = +12\text{ V}$ 상태에서):
    $V_{TL} = -\frac{1}{3} \times (+12\text{ V}) = -4\text{ V}$
  • 상한 문턱전압($V_{TH}$, 출력 $v_{out} = -12\text{ V}$ 상태에서):
    $V_{TH} = -\frac{1}{3} \times (-12\text{ V}) = +4\text{ V}$

  ■ 3단계: 전달특성 곡선 판단
  • 비반전형 특성에 따라 $v_{in} > +4\text{ V}$ 일 때 출력은 $+12\text{ V}$가 되고, $v_{in} < -4\text{ V}$ 일 때 출력은 $-12\text{ V}$가 됩니다.
  • 따라서 $-4\text{ V} \sim +4\text{ V}$ 구간에서 히스테리시스를 갖는 전달특성 곡선은 그래프 ①번입니다.

  ■ 최종 결과:
  • 옳은 것은 ①번
