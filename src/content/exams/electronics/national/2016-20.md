explanation: |
  ■ 1단계: 다이오드 도통(ON) 상태에서의 출력 상한값(클리핑 레벨) 분석
  • 입력 전압 $v_{in}$이 상승하여 다이오드 $D_1$이 켜지는 조건에서의 출력 상한값 $v_{out,\text{max}}$:
    $$v_{out,\text{max}} = V_{CC} + V_{D,\text{on}} = 5\text{ V} + 0.7\text{ V} = 5.7\text{ V}$$
  • 따라서 $v_{out}$이 $5.7\text{ V}$에 도달하면 다이오드가 도통되어 전압이 $5.7\text{ V}$로 클리핑(제한)됩니다.

  ■ 2단계: 다이오드 차단(OFF) 상태에서의 전압 분배 계산
  • 다이오드가 꺼져 있을 때, 저항 $R_1 = 1\text{ k}\Omega$과 $R_2 = 1\text{ k}\Omega$ 사이의 전압 분배식:
    $$v_{out} = \frac{R_2}{R_1 + R_2}v_{in} + \frac{R_1}{R_1 + R_2}V_{EE} = \frac{1}{2}v_{in} + \frac{1}{2}(-5\text{ V}) = \frac{v_{in} - 5}{2}$$

  ■ 3단계: 음의 피크 지점에서의 최솟값 및 파형 매칭
  • $v_{in} = -20\text{ V}$일 때의 전압:
    $$v_{out} = \frac{-20 - 5}{2} = -12.5\text{ V}$$
  • 보기의 파형 그래프 중 상한 클리핑 레벨 $5.7\text{ V}$와 음의 전압 변동 폭을 만족하는 것은 ③번입니다.

  ■ 최종 결과:
  • 올바른 출력 전압 파형은 ③번
