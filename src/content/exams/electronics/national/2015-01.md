explanation: |
  ■ 1단계: 2진수-그레이 코드(Gray Code) 변환 규칙
  • 최상위 비트(MSB)는 2진수 값을 그대로 가져옵니다:
    $$G_n = B_n$$
  • 그 다음 비트부터는 인접한 2진수 비트 간 XOR 연산을 수행합니다:
    $$G_i = B_{i+1} \oplus B_i$$

  ■ 2단계: 2진수 $11000111_2$의 비트별 변환
  • $B_7 B_6 B_5 B_4 B_3 B_2 B_1 B_0 = 1 1 0 0 0 1 1 1$
  • $G_7 = B_7 = 1$
  • $G_6 = B_7 \oplus B_6 = 1 \oplus 1 = 0$
  • $G_5 = B_6 \oplus B_5 = 1 \oplus 0 = 1$
  • $G_4 = B_5 \oplus B_4 = 0 \oplus 0 = 0$
  • $G_3 = B_4 \oplus B_3 = 0 \oplus 0 = 0$
  • $G_2 = B_3 \oplus B_2 = 0 \oplus 1 = 1$
  • $G_1 = B_2 \oplus B_1 = 1 \oplus 1 = 0$
  • $G_0 = B_1 \oplus B_0 = 1 \oplus 1 = 0$
  • 변환된 그레이 코드는 $10100100_2$입니다.

  ■ 최종 결과:
  • 올바른 그레이 코드는 10100100 (②번)
