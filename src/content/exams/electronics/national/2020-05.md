answer: 3
options:
  - "$V_{OUT} = 5.1\\text{ V}$, $I_L = 70\\text{ mA}$"
  - "$V_{OUT} = 5.1\\text{ V}$, $I_L = 140\\text{ mA}$"
  - "$V_{OUT} = 10.2\\text{ V}$, $I_L = 70\\text{ mA}$"
  - "$V_{OUT} = 10.2\\text{ V}$, $I_L = 140\\text{ mA}$"
explanation: |
  ■ 1단계: 정전압 출력 전압($V_{OUT}$) 계산
  • 이상적인 연산증폭기의 가상 단락(Virtual Short)에 의해 반전(-) 단자와 비반전(+) 단자의 전위가 같아집니다 ($V_+ = V_-$).
  • 비반전 단자는 제너 다이오드에 의해 기준 전압으로 고정됩니다:
    $$V_+ = V_Z = 5.1\text{ V}$$
  • 반전 단자는 출력 저항 분배 회로($R_1, R_2$)에 연결되어 있으므로:
    $$V_- = V_{OUT} \left(\frac{R_2}{R_1 + R_2}\right) = V_Z$$
    $$V_{OUT} = V_Z \left(1 + \frac{R_1}{R_2}\right) = 5.1\text{ V} \times \left(1 + \frac{10\text{ k}\Omega}{10\text{ k}\Omega}\right) = 5.1 \times 2 = 10.2\text{ V}$$

  ■ 2단계: 최대 부하 전류($I_L$) 계산 (전류 제한 회로 동작)
  • 감지 저항($R_S = 10\text{ }\Omega$)과 트랜지스터 $Q_2$는 **과전류 보호(Current Limiting)** 회로를 구성합니다.
  • 부하 전류 $I_L$이 증가하여 감지 저항 양단의 전압 강하가 $Q_2$의 베이스-이미터 도통 전압($V_{BE} = 0.7\text{ V}$)에 도달하면 $Q_2$가 턴온(ON)되어 $Q_1$의 베이스 전류를 차단·제한합니다:
    $$I_{L,\text{max}} \times R_S = V_{BE}$$
    $$I_{L,\text{max}} = \frac{V_{BE}}{R_S} = \frac{0.7\text{ V}}{10\text{ }\Omega} = 0.07\text{ A} = 70\text{ mA}$$

  ■ 최종 결과:
  • $V_{OUT} = 10.2\text{ V}$, $I_L = 70\text{ mA}$ (③번)
---
