explanation: |
  ■ 1단계: 상단 및 하단 증폭단 출력 분석
  • 상단 반전 증폭단 출력 ($V_{\text{top}}$):
    $$V_{\text{top}} = -2V_1$$
  • 하단 다이오드 정류 버퍼단 출력 ($V_{\text{bottom}}$):
    - $V_2 > 0$ (양의 반주기): 다이오드 도통으로 $V_{\text{bottom}} = V_2$
    - $V_2 < 0$ (음의 반주기): 다이오드 차단으로 $V_{\text{bottom}} = 0\text{ V}$

  ■ 2단계: 최종 반전 가산기 출력($V_o$) 계산
  • 최종 출력 관계식:
    $$V_o = -\left(\frac{R}{R}V_{\text{top}} + \frac{R}{R/2}V_{\text{bottom}}\right) = -(V_{\text{top}} + 2V_{\text{bottom}})$$
  • 입력이 양수 구간일 때 ($V_1 = V_2 = 1\text{ V}$):
    - $V_{\text{top}} = -2\text{ V}, \quad V_{\text{bottom}} = 1\text{ V}$
    - $V_o = -(-2\text{ V} + 2(1\text{ V})) = 0\text{ V}$
  • 입력이 음수 구간일 때 ($V_1 = V_2 = -1\text{ V}$):
    - $V_{\text{top}} = 2\text{ V}, \quad V_{\text{bottom}} = 0\text{ V}$
    - $V_o = -(2\text{ V} + 2(0\text{ V})) = -2\text{ V}$

  ■ 최종 결과:
  • 양의 주기에서는 0 V, 음의 주기에서는 -2 V가 출력되는 ②번 파형이 정답입니다.
