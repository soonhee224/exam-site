options:
  - "$x = \\bar{A}B + AC$"
  - "$x = \\bar{A}C + ABC$"
  - "$x = \\bar{A}C + AB$"
  - "$x = \\bar{B}C + BC$"
explanation: |
  ■ 1단계: 공통 인수 묶기
  • 주어진 논리식:
    $$x = \bar{A}B + A\bar{B}C + ACD + ABCD'$$
  • 뒤의 세 항에서 공통 인수 $AC$를 묶어 정리:
    $$A\bar{B}C + ACD + ABCD' = AC(\bar{B} + D + BD')$$

  ■ 2단계: 괄호 내부 불 대수 간소화
  • 분배 법칙 적용 ($\bar{B} + BD' = \bar{B} + D'$):
    $$\bar{B} + D + BD' = (\bar{B} + D') + D = \bar{B} + (D' + D) = \bar{B} + 1 = 1$$
  • 따라서 $AC(\bar{B} + D + BD') = AC$가 됩니다.

  ■ 3단계: 최종 식 정리
  • 원래 식에 대입:
    $$x = \bar{A}B + AC$$

  ■ 최종 결과:
  • 간소화된 논리식은 $\bar{A}B + AC$ (①번)
