answer: 2
options:
  - "$C = X + Y,  S = X \\oplus Y$"
  - "$C = X \\cdot Y,  S = X \\oplus Y$"
  - "$C = X \\oplus Y,  S = X + Y$"
  - "$C = X \\oplus Y,  S = X \\cdot Y$"
explanation: |
  ■ 1단계: 반가산기(Half Adder)의 진리표 작성
  • 반가산기는 1비트 2진수 2개($X, Y$)를 입력받아 합($S$, Sum)과 자리올림수($C$, Carry)를 출력하는 조합논리회로입니다.
  • 입력에 따른 덧셈 진리표:
    - $X = 0, Y = 0 \rightarrow S = 0, C = 0$
    - $X = 0, Y = 1 \rightarrow S = 1, C = 0$
    - $X = 1, Y = 0 \rightarrow S = 1, C = 0$
    - $X = 1, Y = 1 \rightarrow S = 0, C = 1$

  ■ 2단계: 출력별 불 대수식(Boolean Expression) 도출
  • 합($S$): 두 입력의 값이 서로 다를 때만 1이 되므로 XOR(배타적 논리합) 연산입니다.
    $S = X \oplus Y = \overline{X}Y + X\overline{Y}$
  • 자리올림수($C$): 두 입력이 모두 1일 때만 1이 되므로 AND(논리곱) 연산입니다.
    $C = X \cdot Y$

  ■ 최종 결과:
  • 논리식은 $C = X \cdot Y, S = X \oplus Y$ (②번)
