options:
  - "$Y = \\overline{A+C}$"
  - "$Y = \\overline{B+C}$"
  - "$Y = \\overline{A+D}$"
  - "$Y = \\overline{B+D}$"
explanation: |
  ■ 1단계: 주어진 논리식의 공통 인수 묶기
  • 원래 부울식:
    $$Y = \bar{A}\bar{B}\bar{C}\bar{D} + A\bar{B}\bar{C}\bar{D} + \bar{A}\bar{B}C\bar{D} + A\bar{B}C\bar{D}$$
  • 공통 항 묶기:
    $$Y = (\bar{A} + A)\bar{B}\bar{C}\bar{D} + (\bar{A} + A)\bar{B}C\bar{D}$$

  ■ 2단계: 불 대수 법칙을 통한 간략화
  • $\bar{A} + A = 1$ 대입:
    $$Y = \bar{B}\bar{C}\bar{D} + \bar{B}C\bar{D}$$
  • $\bar{B}\bar{D}$를 공통 인수로 묶기:
    $$Y = \bar{B}\bar{D}(\bar{C} + C) = \bar{B}\bar{D}$$

  ■ 3단계: 드모르간 법칙 적용
  • 드모르간 법칙에 의해:
    $$Y = \bar{B}\bar{D} = \overline{B + D}$$

  ■ 최종 결과:
  • 간략히 한 결과식은 $\overline{B+D}$ (④번)
