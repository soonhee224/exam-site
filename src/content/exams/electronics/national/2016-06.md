title: "2016년 국가직 9급 전자공학개론 6번"
answer: 1
options:
  - "$\\bar{A}B + B\\bar{C} + BD + \\bar{C}D$"
  - "$\\bar{A}B + \\bar{C}D + BD + A\\bar{C}\\bar{D}$"
  - "$\\bar{A}B + \\bar{C}D + BD + A\\bar{C}$"
  - "$\\bar{A}B + \\bar{C}D + BD + AB$"
explanation: |
  ■ 1단계: 카르노맵의 1의 분포에 따른 4칸 묶음 구성
  • 2행 전체(가로 4칸 묶음): $AB = 01$ 영역이므로 $\bar{A}B$
  • 2열 전체(세로 4칸 묶음): $CD = 01$ 영역이므로 $\bar{C}D$
  • 중앙 2x2 정사각형 4칸 묶음: $B = 1, D = 1$이 공통이므로 $BD$
  • 행(01, 11)과 열(00, 01)에 걸친 4칸 묶음: $B = 1, C = 0$이 공통이므로 $B\bar{C}$

  ■ 2단계: 필수 주항 결합을 통한 논리식 도출
  • 위에서 추출한 4개의 주항을 OR 연산으로 묶어 식을 완성합니다:
    $$F = \bar{A}B + \bar{C}D + BD + B\bar{C} = \bar{A}B + B\bar{C} + BD + \bar{C}D$$

  ■ 최종 결과:
  • 올바르게 간략화된 논리식은 ①번
