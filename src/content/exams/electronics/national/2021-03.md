explanation: |
  ■ 1단계: 반전 증폭기 전달함수($H(s)$) 유도
  • 입력 임피던스는 $Z_1 = R_1$이며, 피드백 임피던스 $Z_2$는 저항 $R_2$와 커패시터 $C_2$의 병렬 조합입니다:
    $$Z_2 = R_2 \parallel \frac{1}{sC_2} = \frac{R_2}{1 + sR_2C_2}$$
  • 반전 증폭기 전압 이득(전달함수) 수식:
    $$H(s) = \frac{V_o(s)}{V_i(s)} = -\frac{Z_2}{Z_1} = -\frac{R_2}{R_1(1 + sR_2C_2)}$$
  • 주파수 응답 크기 식 ($s = j\omega = j2\pi f$):
    $$|H(j\omega)| = \left|\frac{V_o}{V_i}\right| = \frac{R_2 / R_1}{\sqrt{1 + (\omega R_2 C_2)^2}} = \frac{R_2 / R_1}{\sqrt{1 + (2\pi f R_2 C_2)^2}}$$

  ■ 2단계: 주파수 대역별 동작 특성 분석
  • 직류 및 저주파 대역 ($f \to 0$):
    - 커패시터 $C_2$는 개방(Open) 상태가 됩니다.
    - 전압 이득의 크기는 $|H(0)| = \frac{R_2}{R_1}$로 일정하게 신호를 통과시킵니다.
  • 고주파 대역 ($f \to \infty$):
    - 커패시터 $C_2$는 단락(Short) 상태가 되어 피드백 임피던스가 $0$이 됩니다.
    - 전압 이득 크기는 $|H(\infty)| \to 0$으로 급격히 감쇠합니다.

  ■ 3단계: 필터 종류 판별
  • 저주파 신호는 통과시키고 고주파 신호는 차단하므로 1차 **능동 저역통과필터(Active LPF)**로 동작합니다.

  ■ 최종 결과:
  • 올바른 주파수 응답 특성 곡선은 ①번 (LPF 특성 곡선)
