explanation: |
  ■ 1단계: 주어진 입력 조건 확인
  • 입력 변수 값: $X = 0, \quad Y = 1$

  ■ 2단계: 각 보기별 회로의 출력($Z$) 계산
  • ①번 회로:
    - AND 게이트 출력: $X \cdot Y = 0 \cdot 1 = 0$
    - XNOR 게이트 출력: $Z = \overline{0 \oplus Y} = \overline{0 \oplus 1} = \overline{1} = 0$
  • ②번 회로 (NOR 게이트):
    - 출력: $Z = \overline{X + Y} = \overline{0 + 1} = \overline{1} = 0$
  • ③번 회로 (XNOR 게이트):
    - 출력: $Z = \overline{X \oplus Y} = \overline{0 \oplus 1} = \overline{1} = 0$
  • ④번 회로:
    - 1단 XNOR(또는 XOR+NOT) 출력: $\overline{X \oplus Y} = \overline{0 \oplus 1} = 0$
    - 2단 XOR 게이트 최종 출력: $Z = 0 \oplus Y = 0 \oplus 1 = 1$

  ■ 최종 결과:
  • 출력 $Z = 1$을 만족하는 회로는 ④번
