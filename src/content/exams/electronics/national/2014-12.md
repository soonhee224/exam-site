explanation: |
  ■ 1단계: 각 회로의 출력 논리식 유도
  • 회로 ①번:
    $$Y = A\\bar{B} + \\bar{A}B = A \\oplus B$$
    (XOR 게이트 회로)
  • 회로 ②번:
    - 상단 NOR 게이트 출력: $W_1 = \\overline{A + B} = \\bar{A}\\bar{B}$
    - 하단 NAND 게이트 출력: $W_2 = \\overline{AB} = \\bar{A} + \\bar{B}$
    - 최종 2단 NAND 게이트 출력:
      $$Y = \\overline{W_1 \\cdot W_2} = \\overline{\\bar{A}\\bar{B}(\\bar{A} + \\bar{B})} = \\overline{\\bar{A}\\bar{B}} = A + B$$
    - XOR이 아닌 OR 연산 결과를 출력합니다.
  • 회로 ③번:
    $$Y = \\overline{AB + \\bar{A}\\bar{B}} = A \\oplus B$$
    (XNOR의 부정으로 XOR 동작)
  • 회로 ④번:
    - 4개의 NAND 게이트로 구성된 표준 XOR 구현 회로로 $Y = A \\oplus B$를 출력합니다.

  ■ 2단계: 결과 비교
  • ①, ③, ④번 회로는 모두 XOR 연산을 수행하지만, ②번 회로만 유일하게 OR($A+B$) 연산을 수행합니다.

  ■ 최종 결과:
  • 출력이 나머지 셋과 다른 것은 ②번
