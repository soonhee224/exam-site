answer: 1
options:
  - "$AB + B\\overline{C} + A\\overline{C}$"
  - "$AB + \\overline{B}C + A\\overline{C}$"
  - "$AB + B\\overline{C} + \\overline{A}C$"
  - "$\\overline{A}B + \\overline{B}\\overline{C} + A\\overline{C}$"
explanation: |
  ■ 1단계: 진리표에서 출력이 1인 최소항(Minterm) 추출
  • 진리표에서 출력 $F = 1$인 입력 조건 $(A, B, C)$:
    - $m_2\ (0, 1, 0) \rightarrow \overline{A}B\overline{C}$
    - $m_4\ (1, 0, 0) \rightarrow A\overline{B}\overline{C}$
    - $m_6\ (1, 1, 0) \rightarrow AB\overline{C}$
    - $m_7\ (1, 1, 1) \rightarrow ABC$
  • 곱들의 합(SOP) 논리식:
    $F = \sum m(2, 4, 6, 7) = \overline{A}B\overline{C} + A\overline{B}\overline{C} + AB\overline{C} + ABC$

  ■ 2단계: 불 대수(Boolean Algebra) 및 카르노 맵을 통한 식 간소화
  • 공통 인수를 활용하여 항을 묶어 전개:
    $F = (AB\overline{C} + ABC) + (A\overline{B}\overline{C} + AB\overline{C}) + (\overline{A}B\overline{C} + AB\overline{C})$
  • 각 항 간소화:
    - $AB(\overline{C} + C) = AB$
    - $A\overline{C}(\overline{B} + B) = A\overline{C}$
    - $B\overline{C}(\overline{A} + A) = B\overline{C}$
  • 최종 결합 식:
    $F = AB + B\overline{C} + A\overline{C}$

  ■ 최종 결과:
  • $F = AB + B\overline{C} + A\overline{C}$ (①번)
