options:
  - "AB' + A'B"
  - "AB + A'B'"
  - "0"
  - "1"
explanation: |
  ■ 1단계: 괄호별 불 대수 분배 법칙 적용
  • 앞의 두 항 전개 ($B\bar{B} = 0$ 적용):
    $$(A + B)(A + \bar{B}) = A + B\bar{B} = A + 0 = A$$
  • 뒤의 두 항 전개 ($B\bar{B} = 0$ 적용):
    $$(\bar{A} + B)(\bar{A} + \bar{B}) = \bar{A} + B\bar{B} = \bar{A} + 0 = \bar{A}$$

  ■ 2단계: 최종 곱 연산 수행
  • 두 중간 결과를 곱하여 정리:
    $$F = A \cdot \bar{A} = 0$$

  ■ 최종 결과:
  • 간략화한 결과는 0 (③번)
