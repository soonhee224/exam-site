options:
  - "공통 컬렉터 회로의 입력 신호와 출력 신호는 동일한 위상을 가진다."
  - "공통 베이스 회로의 입력 신호와 출력 신호는 180°의 위상차를 가진다."
  - "공통 이미터 회로의 입력 신호와 출력 신호는 180°의 위상차를 가진다."
  - "증폭기로 동작하기 위해서는 베이스-이미터 접합은 순방향 바이어스, 베이스-컬렉터 접합은 역방향 바이어스가 걸려야 한다."
explanation: |
  ■ 1단계: BJT 3가지 증폭기 구성의 입출력 위상 관계 비교
  • 공통 이미터(CE, Common Emitter) 증폭기:
    베이스 입력 - 컬렉터 출력 구조로, 입력과 출력 전압 신호 사이에 $180^\circ$ 위상차가 발생(위상 반전)합니다. (③번 옳은 설명)
  • 공통 컬렉터(CC, Common Collector / 이미터 팔로워) 증폭기:
    베이스 입력 - 이미터 출력 구조로, 입력과 출력 전압 신호가 동위상($0^\circ$ 위상차)을 가집니다. (①번 옳은 설명)
  • 공통 베이스(CB, Common Base) 증폭기:
    이미터 입력 - 컬렉터 출력 구조로, 입력과 출력 전압 신호가 동위상($0^\circ$ 위상차)을 가집니다. (②번 설명은 $180^\circ$ 위상차를 갖는다고 하였으므로 틀림)

  ■ 2단계: BJT 선형 증폭기(활성 영역)의 바이어스 조건 검토
  • BJT가 왜곡 없는 선형 증폭기로 동작하기 위한 활성 영역(Active Region) 바이어스 조건:
    - 베이스-이미터(B-E) 접합: 순방향 바이어스
    - 베이스-컬렉터(B-C) 접합: 역방향 바이어스
    (④번 옳은 설명)

  ■ 최종 결과:
  • 옳지 않은 것은 ②번
