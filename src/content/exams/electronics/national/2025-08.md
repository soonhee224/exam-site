answer: 3
options:
  - "출력전압의 주파수는 60 [Hz]이다."
  - "출력전압의 평균값은 $\\frac{V_m}{\\pi}\\text{ [V]}$이다."
  - "출력전압의 실효값(RMS)은 $\\frac{V_m}{\\sqrt{2}}\\text{ [V]}$이다."
  - "다이오드에 인가되는 역방향 최대전압은 $2V_m\\text{ [V]}$이다."
explanation: |
  ■ 1단계: 입력 신호 기본 분석
  • 입력 전압: $v_s(t) = V_m \sin(120\pi t)\text{ V}$
  • 각주파수 $\omega = 120\pi = 2\pi f$ 이므로 입력 기본 주파수는:
    $f = \frac{120\pi}{2\pi} = 60\text{ Hz}$

  ■ 2단계: 보기별 정오 판별 (전파 브리지 정류회로)

  • ①번 (오답 분석):
    전파 정류기의 출력 파형은 주기가 절반($T/2$)으로 줄어들므로 주파수는 2배가 됩니다.
    $f_{out} = 2f = 2 \times 60\text{ Hz} = 120\text{ Hz}$ (60 Hz 설명은 틀림)

  • ②번 (오답 분석):
    전파 정류기의 출력전압 직류 평균값:
    $V_{avg} = \frac{2V_m}{\pi}\text{ V}$
    (선지의 $\frac{V_m}{\pi}$는 반파 정류기의 평균값이므로 틀림)

  • ③번 (옳은 설명):
    정현파 신호를 전파 정류하면 음의 반주기가 위로 접혀 올라갈 뿐 파형의 제곱 평균에는 변화가 없으므로 실효값(RMS)은 원래 입력 정현파와 동일합니다.
    $V_{rms} = \frac{V_m}{\sqrt{2}}\text{ V}$

  • ④번 (오답 분석):
    브리지 정류회로에서 다이오드 하나에 걸리는 최대 역방향 전압(PIV, Peak Inverse Voltage)은 $V_m$ 입니다.
    ($2V_m$은 중간탭 전파 정류회로의 특성이므로 틀림)

  ■ 최종 결과:
  • 옳은 것은 ③번
