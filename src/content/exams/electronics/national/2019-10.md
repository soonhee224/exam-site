  - "1110"
  - "1101"
explanation: |
  ■ 1단계: 멀티플렉서(MUX) 회로의 출력 논리식($Y$) 전개
  • 4개의 AND 게이트와 1개의 OR 게이트로 구성된 $4 \times 1$ 멀티플렉서의 출력 논리식:
    $$Y = \bar{A}\bar{B}P_0 + \bar{A}BP_1 + A\bar{B}P_2 + ABP_3$$

  ■ 2단계: 목표 논리식 $Y = A + B$의 최소항(Minterm) 전개 및 계수 비교
  • 부울 대수의 기본 성질을 이용하여 $A + B$를 최소항의 합(SOP) 형식으로 전개합니다:
    $$A + B = A(B + \bar{B}) + (A + \bar{A})B = AB + A\bar{B} + \bar{A}B$$
  • 1단계의 출력식과 항별 계수를 비교 매핑합니다:
    $$Y = \bar{A}\bar{B}(0) + \bar{A}B(1) + A\bar{B}(1) + AB(1)$$
  • 따라서 각 입력단의 값은 다음과 같습니다:
    $$P_0 = 0, \quad P_1 = 1, \quad P_2 = 1, \quad P_3 = 1$$

  ■ 3단계: $P_3, P_2, P_1, P_0$ 수열 구성
  • 요구하는 순서대로 나열하면:
    $$P_3 P_2 P_1 P_0 = 1 1 1 0$$

  ■ 최종 결과:
  • 올바른 입력값 조합은 $1110$ (③번)
---
