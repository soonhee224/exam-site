options:
  - "$AB + \\bar{A}C$"
  - "$\\bar{A}B + AC$"
  - "$AB + AC$"
  - "$\\bar{A}B + \\bar{A}C$"
explanation: |
  ■ 1단계: 주어진 논리식 정리
  • 원래 논리식:
    $$F = \bar{A}B\bar{C} + ABC + \bar{A}BC + AB\bar{C}$$

  ■ 2단계: 공통 인수를 이용한 식 묶기
  • $\bar{A}B$와 $AC$를 각각 공통 인수로 묶어 정리:
    $$F = \bar{A}B(\bar{C} + C) + AC(B + \bar{B})$$
  • $\bar{C} + C = 1$ 및 $B + \bar{B} = 1$ 적용:
    $$F = \bar{A}B(1) + AC(1) = \bar{A}B + AC$$

  ■ 최종 결과:
  • 동일한 함수는 $\bar{A}B + AC$ (②번)
