explanation: |
  ■ 1단계: 문제의 입출력 조건 수립 (XNOR / 일치 회로)
  • 두 입력 $A, B$가 같을 때 1을 출력하고 서로 다를 때 0을 출력하는 회로는 배타적 부정(XNOR) 게이트입니다:
    $$Y = AB + \bar{A}\bar{B} = \overline{A \oplus B}$$

  ■ 2단계: 보기 ②번 회로의 부울 대수식 유도
  • 상단 2입력 NAND 게이트 출력:
    $$X_1 = \overline{AB}$$
  • 하단 2입력 NAND 게이트 출력:
    $$X_2 = \overline{\bar{A}\bar{B}} = A + B$$
  • 최종 출력 NAND 게이트의 동작:
    $$Y = \overline{X_1 \cdot X_2} = \overline{\overline{AB} \cdot (A + B)} = \overline{(\bar{A} + \bar{B})(A + B)} = \overline{\bar{A}B + A\bar{B}} = \overline{A \oplus B} = AB + \bar{A}\bar{B}$$

  ■ 3단계: 일치 여부 확인
  • 보기 ②번 회로의 출력이 XNOR 논리식 $AB + \bar{A}\bar{B}$와 정확히 일치합니다.

  ■ 최종 결과:
  • 입력 $A$와 $B$가 같을 때 1을 출력하는 회로는 ②번
