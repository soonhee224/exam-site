title: "2017년 국가직 9급 전자공학개론 20번"
answer: 4
options:
  - "$\\frac{j\\omega R_1}{R_1 + R_2 + j\\omega R_1 R_2 C}$"
  - "$\\frac{j\\omega R_2}{R_1 + R_2 + j\\omega R_1 R_2 C}$"
  - "$\\frac{R_1}{R_1 + R_2 + j\\omega R_1 R_2 C}$"
  - "$\\frac{R_2}{R_1 + R_2 + j\\omega R_1 R_2 C}$"
explanation: |
  ■ 1단계: 출력단 병렬 임피던스($Z_p$) 계산
  • 출력단에 병렬 연결된 저항 $R_2$와 커패시터 $C$의 합성 임피던스:
    $$Z_p = R_2 \parallel \frac{1}{j\omega C} = \frac{R_2 \cdot \frac{1}{j\omega C}}{R_2 + \frac{1}{j\omega C}} = \frac{R_2}{1 + j\omega R_2 C}$$

  ■ 2단계: 전압 분배 법칙을 통한 주파수 전달함수 유도
  • 입력 전압 $V_i$와 출력 전압 $V_o$의 관계:
    $$\frac{V_o}{V_i}(\omega) = \frac{Z_p}{R_1 + Z_p}$$
  • 구한 $Z_p$를 대입:
    $$\frac{V_o}{V_i}(\omega) = \frac{\frac{R_2}{1 + j\omega R_2 C}}{R_1 + \frac{R_2}{1 + j\omega R_2 C}}$$

  ■ 3단계: 전달함수 식 정리
  • 분모와 분자에 $(1 + j\omega R_2 C)$를 곱하여 정리:
    $$\frac{V_o}{V_i}(\omega) = \frac{R_2}{R_1(1 + j\omega R_2 C) + R_2} = \frac{R_2}{R_1 + R_2 + j\omega R_1 R_2 C}$$

  ■ 최종 결과:
  • 주파수 전달함수는 $\frac{R_2}{R_1 + R_2 + j\omega R_1 R_2 C}$ (④번)
