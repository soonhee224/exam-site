answer: 4
options:
  - "$Y = A + B$"
  - "$Y = AB$"
  - "$Y = AB + A'B'$"
  - "$Y = AB' + A'B$"
explanation: |
  ■ 1단계: 각 분기 게이트의 출력식 유도
  • 상단 2입력 OR 게이트의 출력:
    $$G_1 = A + B$$
  • 하단 2입력 NAND 게이트의 출력:
    $$G_2 = \overline{AB} = \bar{A} + \bar{B}$$

  ■ 2단계: 최종 AND 게이트의 출력식($Y$) 정리
  • 두 출력이 2입력 AND 게이트로 입력되므로:
    $$Y = G_1 \cdot G_2 = (A + B)(\bar{A} + \bar{B})$$
  • 괄호 전개:
    $$Y = A\bar{A} + A\bar{B} + \bar{A}B + B\bar{B}$$
  • $A\bar{A} = 0, B\bar{B} = 0$ 적용:
    $$Y = A\bar{B} + \bar{A}B = A \oplus B$$

  ■ 최종 결과:
  • 출력 $Y = AB' + A'B$ (④번)
