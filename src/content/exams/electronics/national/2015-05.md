  - "$\\bar{Z} = (A + B) \\cdot (C + \\bar{D})$"
  - "$Z = (A + B) \\cdot (C + \\bar{D})$"
  - "$\\bar{Z} = (\\bar{A} + \\bar{B}) \\cdot (\\bar{C} + D)$"
  - "$Z = (\\bar{A} + \\bar{B}) \\cdot (\\bar{C} + D)$"
explanation: |
  ■ 1단계: 주어진 논리 함수 확인
  • 원래의 함수식:
    $$Z = AB + C\bar{D}$$

  ■ 2단계: 드모르간 법칙을 적용한 부정식($\bar{Z}$) 전개
  • $Z$의 전체 부정을 취합니다:
    $$\bar{Z} = \overline{AB + C\bar{D}}$$
  • 드모르간 법칙($\overline{X + Y} = \bar{X} \cdot \bar{Y}$) 적용:
    $$\bar{Z} = (\overline{AB}) \cdot (\overline{C\bar{D}})$$
  • 각 항에 드모르간 법칙 재적용:
    $$\overline{AB} = \bar{A} + \bar{B}$$
    $$\overline{C\bar{D}} = \bar{C} + \bar{\bar{D}} = \bar{C} + D$$
  • 정리된 부정 논리식:
    $$\bar{Z} = (\bar{A} + \bar{B}) \cdot (\bar{C} + D)$$

  ■ 최종 결과:
  • 동일한 함수를 나타낸 것은 ③번
