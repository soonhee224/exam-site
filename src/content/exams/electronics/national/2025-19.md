answer: 4
options:
  - "$AB\\overline{C} + BC + \\overline{D}$"
  - "$A\\overline{B}C + B\\overline{C} + D$"
  - "$A\\overline{B}C + B\\overline{C} + \\overline{D}$"
  - "$\\overline{A}\\overline{B}C + B\\overline{C} + \\overline{D}$"
explanation: |
  ■ 1단계: 4변수 카르노 맵 그룹화(Grouping)
  • 4변수($A, B, C, D$) 카르노 맵에서 인접한 1들을 $2^n$ 단위로 최대한 크게 묶어 간소화합니다.

  ■ 2단계: 그룹별 주항(Prime Implicant) 유도
  • 묶음 1 (8칸 그룹):
    첫 번째 열($CD = 00$)과 네 번째 열($CD = 10$) 전체를 좌우로 감싸서 8칸을 묶습니다.
    변수 $A, B, C$는 모든 상태(0과 1)로 변하여 소거되고, 공통적으로 $D = 0$ 상태를 유지합니다.
    $\rightarrow\ \overline{D}$
  • 묶음 2 (4칸 그룹):
    행 $AB = 01, 11$ ($B = 1$)과 열 $CD = 00, 01$ ($C = 0$)이 교차하는 4칸을 묶습니다.
    공통 성분은 $B = 1, C = 0$ 입니다.
    $\rightarrow\ B\overline{C}$
  • 묶음 3 (2칸 그룹):
    $(AB = 00, CD = 11)$ 위치의 1을 인접한 $(AB = 00, CD = 10)$과 함께 2칸으로 묶습니다.
    공통 성분은 $A = 0, B = 0, C = 1$ 입니다.
    $\rightarrow\ \overline{A}\overline{B}C$

  ■ 3단계: 간소화된 논리식 합(OR) 결합
  • $F = \overline{A}\overline{B}C + B\overline{C} + \overline{D}$

  ■ 최종 결과:
  • $F = \overline{A}\overline{B}C + B\overline{C} + \overline{D}$ (④번)
