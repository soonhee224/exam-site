options:
  - "5: 0110, 10: 1101"
  - "5: 0111, 10: 1111"
  - "5: 0101, 10: 1110"
  - "5: 0100, 10: 1111"
explanation: |
  ■ 1단계: 10진수 5의 그레이 코드 변환
  • 10진수 5의 2진수 4비트 표현: $B_3 B_2 B_1 B_0 = 0101_2$
  • 2진수에서 그레이 코드 변환 ($G_3 = B_3, G_i = B_{i+1} \oplus B_i$):
    - $G_3 = B_3 = 0$
    - $G_2 = B_3 \oplus B_2 = 0 \oplus 1 = 1$
    - $G_1 = B_2 \oplus B_1 = 1 \oplus 0 = 1$
    - $G_0 = B_1 \oplus B_0 = 0 \oplus 1 = 1$
  • 변환 결과: $0111$

  ■ 2단계: 10진수 10의 그레이 코드 변환
  • 10진수 10의 2진수 4비트 표현: $B_3 B_2 B_1 B_0 = 1010_2$
  • 2진수에서 그레이 코드 변환:
    - $G_3 = B_3 = 1$
    - $G_2 = B_3 \oplus B_2 = 1 \oplus 0 = 1$
    - $G_1 = B_2 \oplus B_1 = 0 \oplus 1 = 1$
    - $G_0 = B_1 \oplus B_0 = 1 \oplus 0 = 1$
  • 변환 결과: $1111$

  ■ 최종 결과:
  • 그레이 코드 쌍은 0111, 1111 (②번)
