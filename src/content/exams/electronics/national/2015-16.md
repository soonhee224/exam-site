options:
  - "A는 $Q_{n-1}$로 이전 값이 그대로 유지된다."
  - "B는 1 값을 갖는다."
  - "C는 0 값을 갖는다."
  - "D는 1 값을 갖는다."
explanation: |
  ■ 1단계: 클럭 SR 플립플롭의 동작 특성 분석
  • 클럭 신호(CLK)가 0일 때는 입력 S, R에 관계없이 이전 상태 $Q_{n-1}$을 유지합니다 ($A = Q_{n-1}$). (①번 옳은 설명)
  • 클럭 신호가 1일 때의 동작:
    - $S = 0, R = 0$: 이전 상태 유지 ($Q_n = Q_{n-1}$)
    - $S = 0, R = 1$: 리셋(Reset) 동작으로 출력은 0이 됩니다 ($C = 0$). (③번 옳은 설명)
    - $S = 1, R = 0$: 세트(Set) 동작으로 출력은 1이 됩니다 ($B = 1$). (②번 옳은 설명)
    - $S = 1, R = 1$: SR 플립플롭에서 출력 상태를 예측할 수 없는 부정(불확정, Indeterminate) 상태입니다. (④번 옳지 않음)

  ■ 최종 결과:
  • 옳지 않은 설명은 ④번
