  1단계: 해밍 거리(Hamming Distance) 개념 적용
  • 해밍 거리는 길이가 같은 두 이진 비트열에서 서로 다른 비트 위치의 개수를 의미합니다.

  2단계: 비트열 비교
  • A = `0 0 1 1 1 0 1 0 0 0`
  • B = `0 1 0 1 0 1 1 0 1 0`
  • 비트 차이 위치: 2번째(0vs1), 3번째(1vs0), 5번째(1vs0), 6번째(0vs1), 9번째(0vs1) 총 5개 위치에서 다릅니다.

  최종 결과:
  • 두 벡터 사이의 해밍 거리는 ③번(5)입니다.
