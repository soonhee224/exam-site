answer: 5
options:
  - "출력 신호의 에너지는 입력 신호의 에너지와 같다."
  - "최적 임계값은 입력 신호 에너지의 반과 같다."
  - "출력 신호는 입력 신호와 필터의 임펄스 응답을 콘벌루션(convolution)하여 얻는다."
  - "정합 필터는 잡음 성분 대비 신호 성분을 향상시킬 목적으로 사용된다."
  - "정합 필터는 비동기 검파기로 널리 사용된다."
explanation: |
  1단계: 정합 필터(Matched Filter)의 특성 분석
  • 정합 필터는 AWGN 채널 환경에서 특정 샘플링 시점 $t = T$에 신호대잡음비(SNR)를 최대화하도록 설계된 선형 필터입니다.
  • 송신 신호의 정확한 파형, 심볼 타이밍, 반송파 위상 정보를 기반으로 수신 신호와 상관 연산을 수행하는 대표적인 동기 검파기(Coherent Detector)입니다.
  • 따라서 위상 정보 없이 검출하는 비동기 검파기로 널리 사용된다고 기술한 ⑤번 설명은 틀렸습니다.

  2단계: 기타 보기 검토
  • ①, ②번: 임펄스 응답 $h(t) = s(T - t)$를 사용할 때 필터의 출력 피크 신호 크기 및 판정 임계값은 입력 신호의 에너지 $E$와 직접적인 상관관계를 갖습니다. (옳은 설명)
  • ③번: 선형 시불변 필터이므로 출력은 입력 신호와 임펄스 응답의 컨벌루션으로 구해집니다. (옳은 설명)
  • ④번: 출력단 SNR을 최대화하여 잡음 대비 신호 성분을 극대화합니다. (옳은 설명)

  최종 결과:
  • 틀린 설명은 ⑤번입니다.
