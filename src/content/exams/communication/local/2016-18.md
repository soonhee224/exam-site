explanation: |
  1단계: 개별 정현파 성분의 주파수 계산
  • 첫 번째 성분 $2\cos(4\pi t + \frac{\pi}{3})$:
    $$\omega_1 = 4\pi\text{ rad/s} \implies f_1 = \frac{4\pi}{2\pi} = 2\text{ Hz}$$
  • 두 번째 성분 $3\sin(6\pi t + \frac{\pi}{4})$:
    $$\omega_2 = 6\pi\text{ rad/s} \implies f_2 = \frac{6\pi}{2\pi} = 3\text{ Hz}$$

  2단계: 합성 주기 신호의 기본 주파수 산출
  • 복수 정현파의 합으로 이루어진 연속 시간 주기 신호의 기본 주파수 $f_0$는 각 정현파 주파수들의 최대공약수(GCD)입니다:
    $$f_0 = \gcd(f_1, f_2) = \gcd(2, 3) = 1\text{ Hz}$$
  • (또는 각 성분의 주기 $T_1 = 1/2\text{ s}$, $T_2 = 1/3\text{ s}$의 최소공배수인 기본 주기 $T_0 = 1\text{ s}$로부터 $f_0 = 1/T_0 = 1\text{ Hz}$)

  최종 결과:
  • 기본 주파수는 ①번(1Hz)입니다.
