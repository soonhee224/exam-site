explanation: |
  1단계: 짝수 패리티(Even Parity) 검사 부호의 정의 확인
  • 짝수 패리티 검사 방식에서는 전체 부호어 내에 포함된 이진수 1의 총 개수가 항상 짝수(0, 2, 4, 6, 8개 등)를 유지해야 합니다.

  2단계: 보기별 1의 개수 검증
  • ①번 `00011101`: 1의 개수가 4개 $\implies$ 짝수 (적합)
  • ②번 `10101111`: 1의 개수가 6개 $\implies$ 짝수 (적합)
  • ③번 `11000100`: 1의 개수가 3개 $\implies$ 홀수 (부적합)
  • ④번 `00000000`: 1의 개수가 0개 $\implies$ 짝수 (적합)

  최종 결과:
  • 짝수 패리티 검사부호의 형태로 옳지 않은 것은 ③번(1 1 0 0 0 1 0 0)입니다.
