explanation: |
  1단계: 매체 접근 제어(MAC) 프로토콜 개념 확인
  • MAC(Media Access Control)은 데이터 링크 계층 하위에서 단일 공유 전송 매체에 여러 노드가 동시에 접근할 때 발생하는 충돌을 제어하거나 방지하는 기법입니다.
  • 대표적인 방식으로는 CSMA/CD, CSMA/CA, 토큰 패싱(Token Passing), ALOHA, 슬롯 ALOHA 등이 있습니다.

  2단계: 오답 보기 검토
  • 데이터그램(Datagram)은 네트워크 계층(IP 계층)에서 각 패킷을 독립적인 단위로 취급하여 목적지까지 전송하는 비연결형 패킷 교환 전달 방식의 명칭이며, 2계층의 매체 접근 제어 프로토콜이 아닙니다.

  최종 결과:
  • 매체 접근 제어 방식으로 옳지 않은 것은 ①번(DATAGRAM)입니다.
