explanation: |
  1단계: 두 비트열 간 비트 단위 비교(XOR 연산)
  • $s_1 = (1, 0, 1, 0, 1, 1)$
  • $s_2 = (0, 0, 1, 1, 0, 1)$
  • 비트 단위 XOR 연산 결과:
    $$s_1 \oplus s_2 = (1, 0, 0, 1, 1, 0)$$

  2단계: 서로 다른 비트 수(해밍 거리) 계산
  • 값이 서로 일치하지 않는(1인) 위치는 1번째, 4번째, 5번째 비트의 총 3개입니다.
  • 따라서 두 부호어 간의 해밍 거리는 3입니다.

  최종 결과:
  • 해밍 거리는 ②번(3)입니다.
