  - "Walsh 테이블의 임의의 서로 다른 두 개의 행은 항상 직교한다."
  - "$2^N$ 형태의 길이를 가진다."
  - "단말에서 기지국으로 전송할 때 사용한다."
  - "코드 중에는 절반을 기준으로 같은 값이 두 번 반복된 것과 반전된 값이 사용된 것이 함께 존재한다."
explanation: |
  1단계: Walsh 코드의 용도 검토
  • 동기식 CDMA 이동통신에서 월시(Walsh) 코드는 상호 완전 직교성을 가지므로, 기지국에서 다수의 단말로 동시에 전송하는 순방향 링크(Forward Link, 다운링크)에서 하위 채널들을 구분하기 위해 사용됩니다.
  • 단말에서 기지국으로 전송하는 역방향 링크(Reverse Link, 업링크)는 단말 간 동기를 완벽하게 맞추기 어려워 직교성이 유지되지 않으므로, 월시 코드 대신 의사잡음(PN) 코드를 사용하여 채널을 구분합니다. 따라서 ③번 설명은 옳지 않습니다.

  2단계: 기타 보기 검토
  • ①번: 하다마드 행렬로 구성된 월시 테이블의 서로 다른 두 행 간 내적은 항상 0으로 완벽히 직교합니다. (옳은 설명)
  • ②번: 하다마드 행렬의 특성상 부호 길이는 $2^N$ ($N = 1, 2, 3, \dots$) 형태를 갖습니다. (옳은 설명)
  • ④번: 행렬 생성 규칙상 $[H_N \ H_N]$ 형태와 $[H_N \ -H_N]$ 형태가 결합되어 앞뒤 절반이 반복되거나 반전된 구조를 갖습니다. (옳은 설명)

  최종 결과:
  • 가장 옳지 않은 설명은 ③번입니다.
