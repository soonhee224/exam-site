title: "2021년 지방직 9급 통신이론 5번"
answer: 3
options:
  - "$9,000$"
  - "$7,200$"
  - "$6,000$"
  - "$3,000$"
explanation: |
  1단계: 신호 대 잡음비(SNR) 산출
  • 신호 전력 $S = 504\text{ W}$, 잡음 전력 $N = 8\text{ W}$ 대입:
    $$\text{SNR} = \frac{S}{N} = \frac{504}{8} = 63$$

  2단계: 섀넌의 채널 용량 공식을 통한 대역폭 계산
  • 섀넌의 채널 용량 공식:
    $$C = B \log_2(1 + \text{SNR})$$
  • $C = 36,000\text{ bps}$, $\text{SNR} = 63$ 대입:
    $$36,000 = B \log_2(1 + 63) = B \log_2(64) = 6B$$
    $$B = \frac{36,000}{6} = 6,000\text{ Hz}$$

  최종 결과:
  • 필요한 대역폭은 ③번($6,000$)입니다.
