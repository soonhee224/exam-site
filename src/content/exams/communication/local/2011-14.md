explanation: |
  1단계: 표준 문자 코드 규격 분석
  • ASCII(American Standard Code for Information Interchange) 코드는 영문 알파벳, 숫자, 특수 기호 및 제어 문자를 나타내기 위해 7비트의 정보 비트를 기본 단위로 사용하는 국제 표준 문자 코드입니다 (총 $2^7 = 128$개 문자 표현).

  2단계: 기타 보기 검토
  • ①번 BCD 코드: 10진수 한 자리를 4비트 2진수로 표현하는 4비트 수치 코드입니다.
  • ③번 해밍 코드: 데이터 전송 시 에러를 검출하고 정정하기 위해 추가되는 채널 부호입니다.
  • ④번 Gray 코드: 연속된 수치 간에 오직 1개의 비트만 바뀌는 최소 변화 수치 코드입니다.

  최종 결과:
  • 7비트로 한 문자를 표현하는 표준 코드는 ②번(ASCII 코드)입니다.
