explanation: |
  1단계: 주파수 응답 크기 수식 계산
  • 주어진 주파수 응답 $H(f) = \frac{1}{1 + j(0.5f)}$의 크기 제곱은 다음과 같습니다:
    $$|H(f)|^2 = \frac{1}{1^2 + (0.5f)^2} = \frac{1}{1 + 0.25f^2}$$
  • $f = 0$에서 최대 전력 이득 $|H(0)|^2 = 1$을 갖습니다.

  2단계: 3 dB 차단 주파수 도출
  • 3 dB 대역폭은 전력 이득이 최대치의 절반($1/2$)으로 떨어지는 주파수 $f$입니다:
    $$\frac{1}{1 + 0.25f^2} = \frac{1}{2}$$
    $$1 + 0.25f^2 = 2 \implies 0.25f^2 = 1 \implies f^2 = 4 \implies f = 2\text{ [Hz]}$$

  최종 결과:
  • 필터의 3 dB 대역폭은 ③번(2)입니다.
