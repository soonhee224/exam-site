options:
  - "$P_B = Q(\\sqrt{2})$"
  - "$P_B = Q(\\sqrt{5})$"
  - "$P_B = Q(\\sqrt{10})$"
  - "$P_B = Q(\\sqrt{20})$"
explanation: |
  1단계: 비트 구간 $T_b$ 및 신호의 비트당 에너지 $E_b$ 계산
  • 비트율 $R_b = 1\text{ Mbits/s} = 10^6\text{ bps}$이므로 비트 지속 시간은 $T_b = \frac{1}{R_b} = 10^{-6}\text{ s}$입니다.
  • $1\text{ }\Omega$ 부하에 정규화된 정현파 반송파 신호의 평균 전력 $P$:
    $$P = \frac{A^2}{2} = \frac{(10 \times 10^{-3})^2}{2} = \frac{10^{-4}}{2} = 0.5 \times 10^{-4}\text{ [W]}$$
  • 비트당 에너지 $E_b$:
    $$E_b = P \times T_b = (0.5 \times 10^{-4}\text{ W}) \times 10^{-6}\text{ s} = 0.5 \times 10^{-10}\text{ [J]}$$

  2단계: BPSK 동기 검파 비트 오류 확률 $P_B$ 도출
  • 단측 잡음 전력 스펙트럼 밀도 $N_0 = 10^{-11}\text{ W/Hz}$
  • 동기식 정합 필터 BPSK 검파 오류 확률 공식에 대입:
    $$P_B = Q\left(\sqrt{\frac{2 E_b}{N_0}}\right) = Q\left(\sqrt{\frac{2 \times 0.5 \times 10^{-10}}{10^{-11}}}\right) = Q\left(\sqrt{\frac{10^{-10}}{10^{-11}}}\right) = Q(\sqrt{10})$$

  최종 결과:
  • 비트 오류 확률은 ③번($P_B = Q(\sqrt{10})$)입니다.
---

1Mbits/s의 비트율을 갖는 BPSK 시스템에 대한 비트 오류 확률 $P_B$로 가장 옳은 것은? (단, 수신된 파형들인 $s_1 = A \cos\omega_0 t$와 $s_2 = -A \cos\omega_0 t$는 정합 필터로 동기적으로 검출된다. 진폭 $A = 10\text{mV}$이고 단측 잡음 전력 스펙트럼 밀도 $N_0 = 10^{-11}\text{W/Hz}$이다. 신호 전력과 비트당 에너지는 $1\Omega$ 부하에 대해 정규화되었다. 그리고 $Q(x) = \frac{1}{\sqrt{2\pi}} \int_{x}^{\infty} e^{-z^2/2} dz$이다.)
