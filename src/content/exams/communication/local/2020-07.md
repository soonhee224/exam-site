explanation: |
  1단계: 구형 펄스 신호의 푸리에 변환
  • 폭이 1인 단위 사각 펄스 $\Pi(t)$의 푸리에 변환 $H(f)$는 Sinc 함수로 주어집니다:
    $$H(f) = \int_{-1/2}^{1/2} 1 \cdot e^{-j 2\pi f t} dt = \frac{e^{-j \pi f} - e^{j \pi f}}{-j 2\pi f} = \frac{\sin(\pi f)}{\pi f} = \text{sinc}(f)$$

  2단계: $H(f) = 0$이 되는 조건 산출
  • $H(f) = 0 \iff \sin(\pi f) = 0 \quad (f \neq 0)$
  • 양의 주파수 영역에서 $\sin(\pi f) = 0$을 만족하는 최소 주파수는 $\pi f = \pi \implies f = 1\text{ [Hz]}$ 입니다.

  최종 결과:
  • $H(f) = 0$이 되는 최소 주파수는 ②번(1)입니다.
---

$\Pi(t)$는 $|t| < \frac{1}{2}$일 때는 $1$의 값을 가지고 다른 $t$의 범위에서는 $0$의 값을 가지는 신호이다. 이 신호의 푸리에 변환을 $H(f)$라고 할 때, $H(f) = 0$이 되는 최소 주파수 $f$는?
