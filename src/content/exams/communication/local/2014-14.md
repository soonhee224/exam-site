explanation: |
  1단계: 다중접속 방식별 사용자 구분 기준 확인
  • FDMA(주파수분할 다중접속): 사용자마다 서로 다른 주파수 대역을 할당합니다.
  • TDMA(시간분할 다중접속): 사용자마다 서로 다른 시간슬롯(Time Slot)을 할당합니다.
  • CDMA(부호분할 다중접속): 모든 사용자가 동일한 주파수와 시간 영역을 공유하며, 사용자마다 상호 직교 또는 유사직교 성질을 갖는 고유한 부호(PN 코드, Walsh 부호 등)를 할당하여 신호를 분리합니다.

  최종 결과:
  • CDMA 시스템에서 사용자를 구별하기 위해 사용하는 것은 ⑤번(부호)입니다.
