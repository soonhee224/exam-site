answer: 3
options:
  - "$A\\tau \\text{Sa}\\left(\\frac{\\omega\\tau}{2}\\right) e^{+j\\omega t_0}$"
  - "$A\\tau \\text{Sinc}\\left(\\frac{\\omega\\tau}{2}\\right) e^{+j\\omega t_0}$"
  - "$A\\tau \\text{Sa}\\left(\\frac{\\omega\\tau}{2}\\right) e^{-j\\omega t_0}$"
  - "$A\\tau \\text{Sinc}\\left(\\frac{\\omega\\tau}{2}\\right) e^{-j\\omega t_0}$"
explanation: |
  1단계: 시간 영역 구형 펄스 함수 모델링
  • 중심이 원점 $t = 0$에 있고 폭이 $\tau$, 높이가 $A$인 구형 펄스를 $x_0(t) = A \text{rect}(t/\tau)$라 하면, 중심이 $t_0$에 위치한 신호는 다음과 같이 표현됩니다:
    $$x(t) = x_0(t - t_0) = A \text{rect}\left(\frac{t - t_0}{\tau}\right)$$

  2단계: 시간 이동 성질을 이용한 푸리에 변환
  • $x_0(t)$의 푸리에 변환:
    $$\mathcal{F}[x_0(t)] = A\tau \frac{\sin(\omega\tau / 2)}{\omega\tau / 2} = A\tau \text{Sa}\left(\frac{\omega\tau}{2}\right)$$
  • 푸리에 변환의 시간 지연 성질 $\mathcal{F}[x(t - t_0)] = X_0(\omega) e^{-j\omega t_0}$를 적용:
    $$X(\omega) = A\tau \text{Sa}\left(\frac{\omega\tau}{2}\right) e^{-j\omega t_0}$$

  최종 결과:
  • 올바른 푸리에 변환식은 ③번($A\tau \text{Sa}\left(\frac{\omega\tau}{2}\right) e^{-j\omega t_0}$)입니다.
---

폭이 $\tau$이고 높이가 $A$이며 중심이 $t_0$에 위치한 구형 펄스 파형의 푸리에 변환(Fourier Transform)으로 가장 옳은 것은? (단, $\text{Sa}(x) = \frac{\sin x}{x}$ 이고 $\text{Sinc}(x) = \frac{\sin \pi x}{\pi x}$ 이다.)
