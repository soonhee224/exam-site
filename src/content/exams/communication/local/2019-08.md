options:
  - "FDMA 방식은 각 사용자별로 다른 주파수를 할당하고, 각 사용자들은 할당된 주파수 자원을 사용하여 동시에 신호를 전송한다."
  - "TDMA 방식은 각 사용자별로 다른 시간 슬롯(time slot)을 할당하고, 각 사용자들은 할당된 시간 슬롯을 사용하여 신호를 전송한다. 이때, 다른 사용자가 동일한 주파수로 전송할 수 있다."
  - "CDMA 방식은 각 사용자별로 다른 코드를 할당하고, 각 사용자들은 할당된 코드를 사용하여 신호를 전송한다. 이때, 모든 사용자가 동일한 주파수와 시간 자원을 사용하여 신호를 전송할 수 있다."
  - "OFDMA 방식은 FDMA와 비슷한 방식이지만, FDMA와는 달리 사용자별로 다른 직교수열(Orthogonal Sequence)을 할당하여 사용자를 구분한다."
explanation: |
  1단계: OFDMA의 다중 접속 방식 분석
  • OFDMA(직교주파수분할 다중접속)는 다수의 직교 부반송파(subcarriers)들을 여러 서브채널(부반송파 그룹)로 묶어 서로 다른 사용자에게 분할 할당함으로써 사용자를 구분합니다.
  • 사용자별로 다른 직교 수열(확산 코드)을 할당하여 사용자를 구분하는 다중 접속 기술은 CDMA에 해당합니다. 따라서 ④번 설명은 옳지 않습니다.

  2단계: 기타 보기 검토
  • ①번 FDMA: 주파수 대역을 개별 채널로 나누어 사용자에게 할당합니다. (옳은 설명)
  • ②번 TDMA: 동일 주파수 대역을 시구간(타임 슬롯)으로 분할하여 번갈아 사용합니다. (옳은 설명)
  • ③번 CDMA: 고유 코드를 이용해 전체 주파수 및 시간 대역을 공유하며 접속합니다. (옳은 설명)

  최종 결과:
  • 가장 옳지 않은 설명은 ④번입니다.
