options:
  - "간섭 신호가 가우시안 잡음과 유사한 성질을 갖도록 설계한다."
  - "망 가장자리에 위치한 사용자가 다수의 기지국으로부터 신호를 전달받는 소프트 핸드오프가 가능하다."
  - "각 사용자가 서로 겹치는 시간 영역을 사용한다."
  - "각 사용자가 서로 겹치지 않는 주파수 영역을 사용한다."
explanation: |
  1단계: CDMA(코드분할 다중접속) 방식의 다중화 특성 분석
  • CDMA는 모든 사용자가 동일한 주파수 대역과 동일한 시간 슬롯을 완전히 공유하면서 동시에 전송하는 방식입니다.
  • 사용자 간 신호 구분은 주파수나 시간 분할이 아닌, 사용자마다 부여된 고유의 직교 또는 준직교 확산 코드(PN 코드)를 통해 수행됩니다.
  • 따라서 각 사용자가 서로 겹치지 않는 주파수 영역을 사용한다고 서술한 ④번 설명은 FDMA(주파수분할 다중접속)에 해당하므로 옳지 않습니다.

  2단계: 기타 보기 검토
  • ①번: 의사잡음(PN) 코드로 확산된 다수 사용자의 간섭 신호는 통계적으로 백색 가우시안 잡음(AWGN)과 유사한 특성을 갖게 됩니다. (옳은 설명)
  • ②번: 모든 셀이 동일 주파수를 사용하므로 통화 단절 없이 여러 기지국과 동시 연결을 유지하는 소프트 핸드오프가 가능합니다. (옳은 설명)
  • ③번: TDMA와 달리 모든 사용자가 동일한 시간 구간을 계속해서 사용합니다. (옳은 설명)

  최종 결과:
  • 가장 옳지 않은 설명은 ④번입니다.
