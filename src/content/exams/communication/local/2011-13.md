answer: 3
options:
  - "$xy + yz$"
  - "$x'z + yz$"
  - "$xy + x'z$"
  - "$xz + yz$"
explanation: |
  1단계: 불 대수의 합의 정리(Consensus Theorem) 적용
  • 불 대수 합의 정리에 따르면 두 항 $xy$와 $x'z$에서 변수 $x$와 $x'$가 상보 관계일 때, 나머지 인자들의 곱인 $yz$는 잉여 항(Redundant term)이 됩니다:
    $$xy + x'z + yz = xy + x'z$$

  2단계: 대수적 전개 및 증명
  • $yz$ 항에 $(x + x' = 1)$을 곱하여 식을 전개합니다:
    $$xy + x'z + yz = xy + x'z + yz(x + x') = xy + x'z + xyz + x'yz$$
  • 공통 인수로 묶어 정리합니다:
    $$xy(1 + z) + x'z(1 + y) = xy(1) + x'z(1) = xy + x'z$$

  최종 결과:
  • 간략화된 올바른 식은 ③번($xy + x'z$)입니다.
