explanation: |
  1단계: 최소 분산 허프만 부호화 트리 구성
  • 각 알파벳의 확률: D(0.4), B(0.3), C(0.2), A(0.1)
  • 최소 분산(부호어 길이의 편차 최소화)을 위해 확률이 가장 낮은 두 기호 A(0.1)와 C(0.2)를 먼저 결합하여 복합 노드 AC(0.3)를 만듭니다.
  • 결합 노드 AC(0.3)를 동일 확률의 기존 기호 B(0.3)보다 트리의 가능한 높은 쪽에 위치시킵니다.
  • 그 다음 B(0.3)와 AC(0.3)를 결합하여 BAC(0.6) 노드를 형성하고, 마지막으로 D(0.4)와 BAC(0.6)를 결합합니다.

  2단계: 비트 할당 수행
  • D(0.4)에 1, BAC(0.6)에 0을 할당하여 D의 코드가 1이 됩니다.
  • BAC(0.6)의 분기에서 B(0.3)에 1, AC(0.3)에 0을 할당하면 B = 01, AC = 00이 됩니다.
  • AC(0.3)의 분기에서 C(0.2)에 0, A(0.1)에 1을 할당하면 C = 000, A = 001이 됩니다.

  최종 결과:
  • A의 코드는 ①번(001)입니다.
