explanation: |
  1단계: LFSR 레지스터 천이 규칙 분석
  • 회로의 귀환 입력 신호는 $S_2$와 $S_3$의 배타적 논리합(XOR)으로 주어집니다:
    $$S_{1,\text{next}} = S_2 \oplus S_3$$
  • 쉬프트 동작에 따라 나머지 레지스터는 직전 단의 값을 전달받습니다:
    $$S_{2,\text{next}} = S_1, \quad S_{3,\text{next}} = S_2$$

  2단계: 초기 상태 $(1, 1, 1)$로부터 5회 클록 천이 추적
  • 초기상태 (Clock 0): $[1, 1, 1]$
  • Clock 1: $S_{1} = 1 \oplus 1 = 0 \implies [0, 1, 1]$
  • Clock 2: $S_{1} = 1 \oplus 1 = 0 \implies [0, 0, 1]$
  • Clock 3: $S_{1} = 0 \oplus 1 = 1 \implies [1, 0, 0]$
  • Clock 4: $S_{1} = 0 \oplus 0 = 0 \implies [0, 1, 0]$
  • Clock 5: $S_{1} = 1 \oplus 0 = 1 \implies [1, 0, 1]$

  최종 결과:
  • 5번째 클록 이후의 레지스터 상태는 ④번(1 0 1)입니다.
