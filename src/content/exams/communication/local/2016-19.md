explanation: |
  1단계: 균일분포(Uniform Distribution)의 분산 공식 적용
  • 구간 $[a, b] = [0, 3]$에서 정의된 연속 균일분포 확률변수 $X$의 분산 공식:
    $$\text{Var}(X) = \frac{(b - a)^2}{12}$$

  2단계: 수치 대입 및 계산
  • $a = 0, b = 3$ 대입:
    $$\text{Var}(X) = \frac{(3 - 0)^2}{12} = \frac{9}{12} = \frac{3}{4}$$

  최종 결과:
  • 분산의 값은 ①번(3/4)입니다.

확률변수 $X$의 확률밀도함수가 $f_X(x) = \begin{cases} \frac{1}{3}, & 0 \le x \le 3 \\ 0, & \text{otherwise} \end{cases}$ 일 때 확률변수 $X$의 분산의 값으로 옳은 것은?
