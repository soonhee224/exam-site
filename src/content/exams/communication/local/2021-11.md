options:
  - "EHF → SHF → UHF → VHF → LF"
  - "EHF → UHF → SHF → VHF → LF"
  - "UHF → SHF → EHF → LF → VHF"
  - "LF → VHF → UHF → SHF → EHF"
explanation: |
  1단계: 주파수 대역과 파장의 관계 확인
  • 전파의 전파 속도 $c$와 주파수 $f$, 파장 $\lambda$ 사이에는 $\lambda = c / f$의 반비례 관계가 성립합니다.
  • 따라서 파장이 짧은 순서대로 나열하는 것은 주파수가 높은 순서대로 나열하는 것과 같습니다.

  2단계: 각 주파수 대역의 주파수 범위 비교
  • EHF(Extremely High Frequency): 30 ~ 300 GHz
  • SHF(Super High Frequency): 3 ~ 30 GHz
  • UHF(Ultra High Frequency): 300 MHz ~ 3 GHz
  • VHF(Very High Frequency): 30 ~ 300 MHz
  • LF(Low Frequency): 30 ~ 300 kHz

  최종 결과:
  • 파장이 짧은 순서(주파수가 높은 순서)는 ①번(EHF → SHF → UHF → VHF → LF)입니다.
