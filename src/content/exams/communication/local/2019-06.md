explanation: |
  1단계: 각 메시지 벡터에 대한 부호어 계산
  • 부호어 생성 공식 $c = m G$를 적용합니다:
  • $m_1 = [1\ 0\ 0\ 0]$에 대응하는 부호어 $c_1$은 생성 행렬 $G$의 1행입니다:
    $$c_1 = [1\ 0\ 0\ 0\ 1\ 0\ 1]$$
  • $m_2 = [0\ 0\ 0\ 1]$에 대응하는 부호어 $c_2$는 생성 행렬 $G$의 4행입니다:
    $$c_2 = [0\ 0\ 0\ 1\ 0\ 1\ 1]$$

  2단계: 두 부호어 간 해밍 거리(Hamming Distance) 산출
  • 두 부호어 $c_1$과 $c_2$의 각 비트를 비교합니다:
    - 1번째 비트: 1 vs 0 (다름)
    - 2번째 비트: 0 vs 0 (같음)
    - 3번째 비트: 0 vs 0 (같음)
    - 4번째 비트: 0 vs 1 (다름)
    - 5번째 비트: 1 vs 0 (다름)
    - 6번째 비트: 0 vs 1 (다름)
    - 7번째 비트: 1 vs 1 (같음)
  • 서로 다른 비트의 개수는 총 4개입니다.

  최종 결과:
  • 두 부호어 사이의 해밍 거리는 ③번(4)입니다.
