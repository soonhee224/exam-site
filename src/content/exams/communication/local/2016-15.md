explanation: |
  1단계: QPSK 심벌 단위 송신 위상 도출
  • 비트열 '1100'을 2비트씩 묶어 QPSK 심벌로 전송합니다:
    - 첫 번째 심벌 '11' $\implies$ 위상 $\phi_1 = 3\pi/4$
    - 두 번째 심벌 '00' $\implies$ 위상 $\phi_2 = 7\pi/4$

  2단계: BPSK 수신기의 최적 결정 영역 분석
  • BPSK 신호 기준:
    - 비트 '1' ($b_1$): 위상 $0$ $\implies$ 판정 영역 $-\pi/2 < \theta < \pi/2$
    - 비트 '0' ($b_2$): 위상 $\pi$ $\implies$ 판정 영역 $\pi/2 < \theta < 3\pi/2$

  3단계: 수신된 위상별 판정
  • 첫 번째 수신 심벌 위상 $3\pi/4$: $\pi/2 < 3\pi/4 < 3\pi/2$에 속하므로 비트 '0'으로 판정
  • 두 번째 수신 심벌 위상 $7\pi/4 \equiv -\pi/4$: $-\pi/2 < -\pi/4 < \pi/2$에 속하므로 비트 '1'로 판정
  • 따라서 검출되는 출력 비트열은 '01'이 됩니다.

  최종 결과:
  • 출력 비트열은 ②번('01')입니다.

잡음이 없는 채널을 통하여 QPSK(Quadriphase-Shift Keying) 규격으로 비트열 '1100'을 전송한다. 만일, 수신기가 잘못하여 BPSK(Binary Phase-Shift Keying) 규격에 따라 비트를 검출할 경우, 출력 비트열은?
(단, QPSK와 BPSK의 심벌 전송률(symbol rate)은 동일하고, 동일한 반송파(carrier signal)를 사용하며, BPSK 수신기는 최적 동작을 수행한다.)

| 구분 | 심벌 | 비트열 | 위상 |
| :---: | :---: | :---: | :---: |
| QPSK | $a_1$ | 10 | $\pi/4$ |
| | $a_2$ | 11 | $3\pi/4$ |
| | $a_3$ | 01 | $5\pi/4$ |
| | $a_4$ | 00 | $7\pi/4$ |
| BPSK | $b_1$ | 1 | 0 |
| | $b_2$ | 0 | $\pi$ |
