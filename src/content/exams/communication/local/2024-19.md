explanation: |
  1단계: 총 OFDM 심벌 주기 계산
  • 유효 심벌 시간 $T_u = 8\text{ }\mu\text{s}$, 순환전치(CP) 시간 $T_{\text{cp}} = 2\text{ }\mu\text{s}$
  • 보호구간이 포함된 총 심벌 주기 $T_s$:
    $$T_s = T_u + T_{\text{cp}} = 8\text{ }\mu\text{s} + 2\text{ }\mu\text{s} = 10\text{ }\mu\text{s}$$
  
  2단계: 부반송파 개수 및 심벌당 전송 비트 수 산출
  • 직교 부반송파 간격 $\Delta f$:
    $$\Delta f = \frac{1}{T_u} = \frac{1}{8 \times 10^{-6}\text{ s}} = 125\text{ kHz}$$
  • 전체 대역폭 $W = 10\text{ MHz} = 10,000\text{ kHz}$ 내 사용 가능한 부반송파 수 $N_{\text{sc}}$:
    $$N_{\text{sc}} = \frac{W}{\Delta f} = \frac{10,000\text{ kHz}}{125\text{ kHz}} = 80\text{개}$$
  • 16-QAM은 부반송파당 4비트($\log_2 16 = 4$)를 전송하므로, 하나의 OFDM 심벌에 실리는 총 데이터 비트 수:
    $$80 \times 4 = 320\text{ 비트}$$
  
  3단계: 최대 데이터 전송속도 계산
  • 전송속도 $R$:
    $$R = \frac{320\text{ 비트}}{T_s} = \frac{320\text{ 비트}}{10 \times 10^{-6}\text{ s}} = 32 \times 10^6\text{ bps} = 32\text{ Mbps}$$
  
  최종 결과:
  • 최대 전송속도는 ②번($32\text{ Mbps}$)입니다.
---

부반송파들이 모두 16-QAM으로 변조된 OFDM(orthogonal frequency division multiplexing) 시스템에서 IDFT(inverse discrete Fourier transform)를 통해 생성된 OFDM 심벌의 길이는 $8\text{ }[\mu s]$이고 전체 대역폭은 $10\text{ [MHz]}$이다. 통신 채널의 최대 경로 시간 지연은 $2\text{ }[\mu s]$이고 OFDM 심벌 앞에 이 지연만큼의 순환전치(cyclic prefix)를 붙여서 전송할 때, 최대 전송속도$[\text{Mbps}]$는?
