answer: 2
options:
  - "$H(X, Y) = H(X) + H(Y | X)$"
  - "$H(X) < H(X | Y)$"
  - "$H(X)$는 0 이상의 값을 갖는다."
  - "$X, Y$가 서로 독립인 경우, $H(X, Y) = H(X) + H(Y)$이다."
explanation: |
  1단계: 조건부 엔트로피의 정보량 성질 분석
  • 정보이론에서 부가 정보 $Y$가 주어지면 대상 확률변수 $X$에 대한 불확실성은 줄어들거나 같아지므로, 항상 다음 부등식이 성립합니다:
    $$H(X | Y) \le H(X)$$
  • 조건이 주어졌을 때 엔트로피가 더 커진다고 표현한 ②번($H(X) < H(X | Y)$)은 옳지 않습니다.

  2단계: 기타 보기 검토
  • ①번: 결합 엔트로피의 연쇄 법칙 공식으로 올바릅니다.
  • ③번: 이산 확률변수의 엔트로피는 각 확률이 $0 \le P(x) \le 1$이므로 항상 0 이상의 비음수 값을 가집니다. (옳은 설명)
  • ④번: 두 확률변수가 서로 독립이면 $H(Y | X) = H(Y)$가 성립하므로 $H(X, Y) = H(X) + H(Y)$가 됩니다. (옳은 설명)

  최종 결과:
  • 옳지 않은 설명은 ②번입니다.

엔트로피(entropy)에 대한 설명으로 옳지 않은 것은? (단, $H(X), H(Y)$는 각각 확률 변수 $X$와 $Y$의 엔트로피이고, $H(X, Y)$는 결합 엔트로피, $H(X|Y)$는 조건부 엔트로피이다)
