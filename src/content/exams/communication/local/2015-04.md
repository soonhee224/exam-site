explanation: |
  1단계: 개별 심볼의 자체 정보량 계산
  • 확률이 $P(s_i)$인 심볼 $s_i$의 정보량 정의 $I(s_i) = -\log_2 P(s_i)$:
    $$I(s_1) = -\log_2(1/2) = 1\text{ [bits]}$$
    $$I(s_2) = -\log_2(1/4) = 2\text{ [bits]}$$
    $$I(s_3) = -\log_2(1/8) = 3\text{ [bits]}$$
    $$I(s_4) = -\log_2(1/8) = 3\text{ [bits]}$$

  2단계: 합성 메시지 $X$의 총 정보량 산출
  • 각 심볼이 상호 독립적으로 발생하므로 합성 메시지 $X = s_1 s_2 s_3 s_4$의 정보량은 개별 심볼 정보량들의 단순 합과 같습니다:
    $$I(X) = I(s_1) + I(s_2) + I(s_3) + I(s_4) = 1 + 2 + 3 + 3 = 9\text{ [bits]}$$

  최종 결과:
  • 합성 메시지의 정보량은 ①번(9[bits])입니다.

서로 독립인 심볼 $s_1, s_2, s_3, s_4$의 발생확률이 각각 $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \frac{1}{8}$이라고 한다. 심볼 네 개로 이루어진 합성 메시지 $X = s_1 s_2 s_3 s_4$의 정보량 $I(X)$는?
