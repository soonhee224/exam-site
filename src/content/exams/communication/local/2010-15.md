answer: 3
options:
  - "0"
  - "$A(T - t)$"
  - "$A^2 (2T - t)$"
  - "$A^2 t$"
explanation: |
  1단계: 정합 필터의 출력 수식 정의[cite: 178]
  • 입력 신호 $x(t)$에 대한 정합 필터의 임펄스 응답은 $h(t) = x(T - t)$입니다[cite: 178].
  • 신호 $x(t)$가 구간 $[0, T]$에서 높이 $A$인 구형 펄스이므로, 임펄스 응답 $h(t)$ 또한 구간 $[0, T]$에서 높이 $A$인 구형 펄스입니다[cite: 178].
  • 필터의 출력 $y(t)$는 $x(t)$와 $h(t)$의 컨벌루션으로 구해집니다[cite: 178]:
    $$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau) h(t - \tau) d\tau$$[cite: 178]

  2단계: $T \le t \le 2T$ 구간에서의 적분 수행[cite: 178]
  • $h(t - \tau)$는 $\tau$에 대해 $0 \le t - \tau \le T \implies t - T \le \tau \le t$ 범위에서 높이 $A$를 갖습니다[cite: 178].
  • $T \le t \le 2T$ 구간에서 $x(\tau)$와 $h(t - \tau)$가 겹치는 유효 적분 구간은 $[t - T, T]$입니다[cite: 178]:
    $$y(t) = \int_{t - T}^{T} A \cdot A \, d\tau = A^2 [T - (t - T)] = A^2 (2T - t)$$[cite: 178]

  최종 결과:[cite: 178]
  • 해당 구간에서의 출력 신호는 ③번($A^2 (2T - t)$)입니다[cite: 178].
---

구형 신호 $x(t)$($0 \le t \le T$ 구간에서 크기 $A$)가 이의 정합 필터(matched filter)에 인가되었을 때, $T \le t \le 2T$ 구간에서 출력 신호 $y(t)$는? (단, 정합 필터의 비례상수는 1이다)[cite: 178]
