  - "기지국과 단말기간의 거리와 전파환경 특성에 따른 전력제어가 필요하다."
  - "여러 사용자가 데이터를 전송하는 시간슬롯을 다르게 한다."
  - "인접 기지국의 사용자 부하가 적을수록 용량이 증가한다."
explanation: |
  1단계: CDMA 방식의 핵심 특성 분석
  • CDMA는 동일한 주파수 대역과 동일한 시간 자원을 모든 사용자가 동시에 공유하며, 상호 직교 또는 준직교 성질을 갖는 고유의 확산 부호(PN 코드, Walsh 부호)를 곱하여 사용자를 구분합니다.
  • 모든 사용자가 동일 주파수를 사용하므로 근거리 단말의 신호가 원거리 단말의 신호를 덮어쓰는 원근 문제를 해결하기 위해 정밀한 전력 제어(Power Control)가 필수적입니다.
  • 간섭에 의해 용량이 결정되는 간섭 제한 시스템이므로 인접 기지국의 간섭 부하가 적을수록 전체 통화 용량이 증가합니다.

  2단계: 오답 보기 검토
  • 사용자가 데이터를 전송하는 시간 슬롯을 나누어 서로 다르게 배정하는 방식은 TDMA(시분할 다중 접속)의 방식입니다.

  최종 결과:
  • 옳지 않은 설명은 ③번입니다.
