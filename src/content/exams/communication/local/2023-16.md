  1단계: 보기별 주파수 응답 $H(f)$ 유도 방법 검토
  • ㄱ: LTI 시스템의 주파수 응답 $H(f)$는 정의에 의해 시간 영역 임펄스 응답 $h(t)$를 푸리에 변환하여 구합니다. (옳음)
  • ㄴ: 컨벌루션 정리에 의해 주파수 영역 입출력 관계는 $Y(f) = X(f) H(f)$이므로, 양변을 $X(f)$로 나누면 $H(f) = \frac{Y(f)}{X(f)}$가 됩니다. (옳음)
  • ㄷ: 복소 지수 신호 $x(t) = e^{j 2\pi f t}$는 LTI 시스템의 고유함수(Eigenfunction)이므로 출력은 $y(t) = H(f) e^{j 2\pi f t} = H(f) x(t)$가 됩니다. 따라서 $\frac{y(t)}{x(t)} = H(f)$로 구해집니다. (옳음)

  최종 결과:
  • ㄱ, ㄴ, ㄷ 모두 옳으므로 정답은 ④번입니다.

임펄스 응답이 $h(t)$인 선형 시불변 시스템에 $x(t)$를 입력하여 출력 $y(t)$를 얻었을 때, 주파수 응답 $H(f)$를 구하는 방법으로 옳은 것만을 모두 고르면? (단, $X(f)$와 $Y(f)$는 각각 $x(t)$와 $y(t)$의 푸리에 변환이고, $X(f) \neq 0$이다.)

ㄱ. $h(t)$의 푸리에 변환을 구한다.

ㄴ. $\frac{Y(f)}{X(f)}$를 구한다.

ㄷ. 입력을 $x(t) = e^{j 2\pi f t}$로 하여 $\frac{y(t)}{x(t)}$를 구한다.
