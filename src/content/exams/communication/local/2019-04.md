options:
  - "IP(Internet Protocol)"
  - "UDP(User Datagram Protocol)"
  - "ARP(Address Resolution Protocol)"
  - "FTP(File Transfer Protocol)"
explanation: |
  1단계: 계층별 식별자 및 헤더 정보 분석
  • 호스트 내의 특정 프로세스(애플리케이션)를 식별하기 위해 사용하는 주소는 포트 번호(Port Number)이며, 이는 OSI 전송 계층(4계층) 프로토콜의 헤더에 포함됩니다.
  • TCP 및 UDP 프로토콜 헤더에는 발신지 포트(Source Port)와 목적지 포트(Destination Port) 필드가 포함되어 있습니다.

  2단계: 보기 검토
  • ①번 IP: 네트워크 계층 프로토콜로 IP 주소를 헤더에 포함합니다.
  • ②번 UDP: 전송 계층 프로토콜로 포트 번호를 헤더에 포함합니다. (옳은 설명)
  • ③번 ARP: 네트워크 계층에서 IP 주소를 하드웨어 MAC 주소로 매핑하는 프로토콜입니다.
  • ④번 FTP: 응용 계층의 파일 전송 프로토콜입니다.

  최종 결과:
  • 포트 번호를 패킷 헤더에 포함하는 프로토콜은 ②번(UDP)입니다.
