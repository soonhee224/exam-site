  - "200.1.2.249"
  - "200.1.2.149"
  - "200.1.2.159"
explanation: |
  1단계: 서브넷 마스크를 통한 호스트 비트 및 서브넷 크기 계산
  • 서브넷 마스크 255.255.255.224의 마지막 옥텟:
    $$224 = 11100000_{(2)}$$
  • 프리픽스 길이는 /27이며, 호스트를 위한 비트 수는 $32 - 27 = 5$비트입니다.
  • 각 서브넷에 할당되는 블록 크기는 $2^5 = 32$개 IP 주소입니다.

  2단계: 해당 서브네트워크의 IP 대역 및 브로드캐스트 주소 도출
  • 문제에서 서브네트워크 주소가 200.1.2.128로 주어졌으므로, 해당 서브넷의 주소 범위는 128부터 $128 + 31 = 159$까지입니다:
    - 서브네트워크 주소: 200.1.2.128
    - 사용 가능한 호스트 IP 범위: 200.1.2.129 ~ 200.1.2.158
    - 브로드캐스트 주소: 200.1.2.159

  최종 결과:
  • 브로드캐스트 IP 주소는 ④번(200.1.2.159)입니다.
---

서브네트워크 주소가 200.1.2.128인 LAN에 IP 주소가 200.1.2.141인 호스트가 연결되어 있고, 서브넷 마스크는 255.255.255.224이다. 이 호스트가 자신이 속한 서브네트워크에 패킷을 브로드캐스트(broadcast)하려고 한다. 브로드캐스트 IP 주소는 무엇인가?
