  - "$H = 0.4541 \\text{ bits/source output}$"
  - "$H = -0.766 \\text{ bits/source output}$"
  - "$H = 3.176 \\text{ bits/source output}$"
  - "$H = 1.432 \\text{ bits/source output}$"
explanation: |
  1단계: 엔트로피(평균 정보량) 공식 정의
  • 정보원 엔트로피 $H$는 각 사상의 발생 확률 $p_i$와 자체 정보량 $I(x_i) = -\log_2(p_i)$의 기댓값입니다:
    $$H = -\sum_{i=1}^3 p_i \log_2(p_i) = \sum_{i=1}^3 p_i [-\log_2(p_i)]\text{ [bits/source output]}$$

  2단계: 사상별 확률 및 정보량 계산
  • 승리 사건 ($p_1 = 0.19$, $\log_2 0.19 = -2.39$):
    $$p_1 [-\log_2 p_1] = 0.19 \times 2.39 = 0.4541$$
  • 패배 사건 ($p_2 = 0.55$, $\log_2 0.55 = -0.86$):
    $$p_2 [-\log_2 p_2] = 0.55 \times 0.86 = 0.4730$$
  • 무승부 사건 ($p_3 = 0.26$, $\log_2 0.26 = -1.94$):
    $$p_3 [-\log_2 p_3] = 0.26 \times 1.94 = 0.5044$$

  3단계: 총 엔트로피 합산
  • 전체 평균 정보량:
    $$H = 0.4541 + 0.4730 + 0.5044 = 1.4315 \approx 1.432\text{ bits/source output}$$

  최종 결과:
  • 올바른 엔트로피 값은 ④번($H = 1.432 \text{ bits/source output}$)입니다.
