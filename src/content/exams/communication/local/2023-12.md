  - '$X_1 = 1$이다.'
  - '$X_3 = 2j$이다.'
  - '$\sum_{n=-\infty}^{\infty} X_n = 0$이다.'
  - '모든 $n$에 대해 $X_n + X_{-n}$은 실수이다.'
explanation: |
  1단계: 오일러 공식을 이용한 복소 지수 푸리에 급수 전개
  • $x(t) = 2 \cos(2\pi f_0 t) - 4 \sin(6\pi f_0 t)$
  • 각 삼각함수를 복소 지수함수로 변환합니다:
    $$2 \cos(2\pi f_0 t) = e^{j 2\pi f_0 t} + e^{-j 2\pi f_0 t}$$
    $$-4 \sin(6\pi f_0 t) = -4 \cdot \frac{e^{j 6\pi f_0 t} - e^{-j 6\pi f_0 t}}{2j} = 2j e^{j 6\pi f_0 t} - 2j e^{-j 6\pi f_0 t}$$
  • 따라서 $x(t)$는 다음과 같이 전개됩니다:
    $$x(t) = e^{-j 2\pi f_0 t} + e^{j 2\pi f_0 t} - 2j e^{-j 6\pi f_0 t} + 2j e^{j 6\pi f_0 t}$$
  • 복소 푸리에 계수 도출:
    $$X_1 = 1, \quad X_{-1} = 1, \quad X_3 = 2j, \quad X_{-3} = -2j \quad (\text{나머지 } n\text{에 대해 } X_n = 0)$$

  2단계: 보기별 진위 검토
  • ①번: $X_1 = 1$입니다. (옳은 설명)
  • ②번: $X_3 = 2j$입니다. (옳은 설명)
  • ③번: 계수의 총합은 $\sum_{n=-\infty}^{\infty} X_n = 1 + 1 + 2j - 2j = 2 \neq 0$이므로 옳지 않습니다.
  • ④번: 실수 신호의 푸리에 계수는 $X_{-n} = X_n^*$ 관계를 만족하므로 $X_n + X_{-n} = 2\text{Re}(X_n)$으로 항상 실수입니다. (옳은 설명)

  최종 결과:
  • 옳지 않은 것은 ③번입니다.
