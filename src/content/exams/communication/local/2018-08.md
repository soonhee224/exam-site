explanation: |
  1단계: 변조 신호와 임펄스 열의 기본 주파수 산출
  • 변조 신호 $x(t) = 10\cos(200\pi t)$의 각주파수는 $\omega_m = 200\pi\text{ rad/s}$이므로 주파수는 $f_m = \frac{200\pi}{2\pi} = 100\text{ Hz}$입니다.
  • 주기적 임펄스 열 $p(t) = \sum_{n=-\infty}^{\infty} \delta(t - nT)$의 주기 $T = 1/1,000\text{ s}$이므로 표본화 기본 주파수는 $f_s = \frac{1}{T} = 1,000\text{ Hz}$입니다.

  2단계: 주파수 영역 곱셈(표본화) 스펙트럼 분석
  • 시간 영역에서의 곱셈 $x(t)p(t)$는 주파수 영역에서 컨벌루션으로 나타나며, 스펙트럼 $X(f)$가 $f_s$의 정수배($n f_s$)마다 복제되어 위치하게 됩니다:
    $$f = n f_s \pm f_m = 1000n \pm 100\text{ [Hz]} \quad (n = 0, \pm 1, \pm 2, \dots)$$

  최종 결과:
  • 나타나는 주파수 성분은 ①번($1000n \pm 100\text{ [Hz]}$)입니다.
