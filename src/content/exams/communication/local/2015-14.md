title: "2015년 지방직 9급 통신이론 14번"
answer: 2
options:
  - "0.58"
  - "0.73"
  - "0.81"
  - "0.88"
explanation: |
  1단계: 문제의 사전 확률 및 전이 확률 정리
  • 송신 신호를 $X$, 수신 신호를 $Y$라 할 때:
    - 사전 확률: $P(X = 0) = 0.4$, $P(X = 1) = 0.6$
    - 채널 전이 확률: $P(Y = 0 | X = 0) = 0.8$, $P(Y = 1 | X = 0) = 0.2$
    - $P(Y = 1 | X = 1) = 0.8$, $P(Y = 0 | X = 1) = 0.2$

  2단계: 수신 신호가 0일 전확률 $P(Y = 0)$ 계산
  • 전확률 정리를 적용합니다:
    $$P(Y = 0) = P(X = 0)P(Y = 0 | X = 0) + P(X = 1)P(Y = 0 | X = 1)$$
    $$P(Y = 0) = (0.4 \times 0.8) + (0.6 \times 0.2) = 0.32 + 0.12 = 0.44$$

  3단계: 베이즈 정리(Bayes' Rule)를 이용한 사후 확률 계산
  • 0을 수신했을 때 원래 0을 송신했을 확률:
    $$P(X = 0 | Y = 0) = \frac{P(X = 0)P(Y = 0 | X = 0)}{P(Y = 0)} = \frac{0.32}{0.44} = \frac{8}{11} \approx 0.727 \approx 0.73$$

  최종 결과:
  • 구하는 사후 확률은 약 ②번(0.73)입니다.
---

2진(binary) 대칭 채널에서 0을 수신했을 때 0이 송신되었을 확률은 약 얼마인가? (단, 0의 송신확률은 0.4이고, 0을 송신했을 때 0을 수신할 확률과 1을 송신했을 때 1을 수신할 확률이 0.8로 동일하다.)
