explanation: |
  1단계: /28 프리픽스 기반 서브넷 크기 산출
  • IPv4 전체 32비트 중 네트워크 프리픽스가 28비트이므로 호스트 비트 수는 $32 - 28 = 4$비트입니다.
  • 하나의 서브넷에 할당되는 블록 크기는 $2^4 = 16$개 IP 주소입니다.

  2단계: 주어진 호스트 IP가 속한 서브넷 범위 계산
  • 주어진 IP 주소는 197.213.45.235이며, 마지막 옥텟(235)을 16으로 나누어 네트워크 범위를 확인합니다:
    $$235 \div 16 = 14 \quad (\text{나머지 } 11)$$
  • 해당 서브넷의 시작 주소(네트워크 주소)의 마지막 옥텟은 $16 \times 14 = 224$입니다.
  • 이 서브넷의 IP 유효 범위는 197.213.45.224부터 197.213.45.239까지이며, 호스트 235는 이 범위에 속합니다.

  최종 결과:
  • 속한 네트워크의 주소는 ③번(197.213.45.224/28)입니다.
