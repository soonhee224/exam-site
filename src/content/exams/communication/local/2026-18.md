  - "$\\frac{1}{2} [\\delta(f - f_c - f_m) + \\delta(f + f_c + f_m)]$"
  - "$\\frac{1}{2} [\\delta(f - f_c + f_m) + \\delta(f + f_c - f_m)]$"
  - "$\\frac{1}{2} [\\delta(f + f_c + f_m) + \\delta(f + f_c - f_m)]$"
  - "$\\frac{1}{2} [\\delta(f - f_c - f_m) + \\delta(f + f_c - f_m)]$"
explanation: |
  1단계: 피변조 신호 전개 및 상측파대(USB) 신호 도출
  • DSB-SC 피변조 신호식:
    $$s(t) = m(t) \cdot c(t) = 2 \cos(2\pi f_m t) \cdot \cos(2\pi f_c t)$$
  • 삼각함수의 곱을 합으로 변환합니다:
    $$s(t) = \cos(2\pi(f_c + f_m)t) + \cos(2\pi(f_c - f_m)t)$$
  • 이 중 중심주파수보다 높은 상측파대(USB) 신호는 다음과 같습니다:
    $$s_{\text{USB}}(t) = \cos(2\pi(f_c + f_m)t)$$
  
  2단계: 상측파대 신호의 푸리에 변환 수행
  • 코사인 신호 $\cos(2\pi f_0 t)$의 푸리에 변환은 $\frac{1}{2}[\delta(f - f_0) + \delta(f + f_0)]$입니다.
  • $f_0 = f_c + f_m$을 대입합니다:
    $$S_{\text{USB}}(f) = \frac{1}{2}[\delta(f - (f_c + f_m)) + \delta(f + (f_c + f_m))] = \frac{1}{2}[\delta(f - f_c - f_m) + \delta(f + f_c + f_m)]$$
  
  최종 결과:
  • 올바른 스펙트럼식은 ①번입니다.
