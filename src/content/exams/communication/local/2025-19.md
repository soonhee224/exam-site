  - "$\\frac{3}{4}(4 - \\log_2 3)$"
  - "$\\frac{1}{4}(4 + \\log_2 3)$"
  - "$\\frac{3}{8}(4 - \\log_2 3)$"
  - "$\\frac{1}{8}(4 + \\log_2 3)$"
explanation: |
  1단계: 이산 랜덤변수 엔트로피 $H(X)$ 수식 전개
  • 정보원 엔트로피 정의식:
    $$H(X) = -\sum_{i=1}^4 P(x_i) \log_2 P(x_i)$$
  • 주어진 확률값($P_1 = 1/8$, $P_2 = 3/8$, $P_3 = 3/8$, $P_4 = 1/8$) 대입:
    $$H(X) = -\left[ 2 \times \frac{1}{8} \log_2\left(\frac{1}{8}\right) + 2 \times \frac{3}{8} \log_2\left(\frac{3}{8}\right) \right]$$
    $$H(X) = -\left[ \frac{1}{4} \log_2\left(\frac{1}{8}\right) + \frac{3}{4} \log_2\left(\frac{3}{8}\right) \right]$$

  2단계: 로그 성질을 이용한 식 정리
  • $\log_2(1/8) = -3$
  • $\log_2(3/8) = \log_2 3 - \log_2 8 = \log_2 3 - 3$
  • 대입 후 전개:
    $$H(X) = -\left[ \frac{1}{4}(-3) + \frac{3}{4}(\log_2 3 - 3) \right] = -\left[ -\frac{3}{4} + \frac{3}{4}\log_2 3 - \frac{9}{4} \right]$$
    $$H(X) = -\left[ -3 + \frac{3}{4}\log_2 3 \right] = 3 - \frac{3}{4}\log_2 3 = \frac{3}{4}(4 - \log_2 3)$$

  최종 결과:
  • 엔트로피는 ①번($\frac{3}{4}(4 - \log_2 3)$)입니다.
