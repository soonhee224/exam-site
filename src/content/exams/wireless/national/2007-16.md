options:
  - "WTLS(Wireless Transport Layer Security)"
  - "WAE(Wireless Application Environment)"
  - "Bearers"
  - "WML(Wireless Markup Language)"
explanation: |
  1단계: WAP(무선 응용 프로토콜) 계층 구조 분석
  • WAP 프로토콜 스택은 하위부터 상위까지 다음과 같은 계층으로 구성됩니다:
    - Bearers: SMS, USSD, CSD, GPRS 등의 하위 무선 데이터 베어러 전송 계층
    - WDP (Wireless Datagram Protocol): 전송 계층 프로토콜
    - WTLS (Wireless Transport Layer Security): 보안 프로토콜 계층
    - WTP (Wireless Transaction Protocol): 트랜잭션 프로토콜 계층
    - WSP (Wireless Session Protocol): 세션 프로토콜 계층
    - WAE (Wireless Application Environment): 최상위 응용 환경 프로토콜 계층

  2단계: WML의 정의 및 구분
  • WML(Wireless Markup Language)은 WAE 계층 환경에서 동작하는 무선 단말용 웹 페이지 작성 마크업 언어(문서 형식)이며, 네트워크 통신 규약을 정의하는 WAP 프로토콜 스택 계층 자체가 아닙니다.

  최종 결과:
  • WAP의 프로토콜 구조가 아닌 것은 ④번입니다.
