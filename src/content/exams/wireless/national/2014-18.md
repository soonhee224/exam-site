explanation: |
  1단계: ARQ(자동 재전송 요구) 방식별 메커니즘 구분
  • ㄱ (정지-대기 ARQ / Stop-and-Wait ARQ): 송신측에서 하나의 프레임을 전송한 후, 수신측으로부터 확인 응답(ACK)이 올 때까지 전송을 멈추고 기다렸다가 다음 프레임을 송신하는 방식입니다.
  • ㄴ (N 후진 ARQ / Go-Back-N ARQ): 윈도우 크기 내에서 확인 응답 없이 여러 프레임을 연속 전송하다가, 중간에 손상된 프레임이 발생하면(NAK 수신 또는 타임아웃) 오류가 난 프레임부터 이후에 이미 보낸 모든 프레임까지 N개를 전부 재전송하는 방식입니다.
  • ㄷ (선택적 ARQ / Selective-Repeat ARQ): 수신측에 버퍼를 두고 오류가 발생한 특정 프레임 하나만을 선별하여 재전송하는 가장 효율적인 방식입니다.

  2단계: 연결 조합 확인
  • ㄱ: 정지-대기 ARQ, ㄴ: N 후진 ARQ, ㄷ: 선택적 ARQ 조합은 ④번입니다.

  최종 결과:
  • 명칭이 바르게 연결된 것은 ④번입니다.
