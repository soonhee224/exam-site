  - "4 [W]"

explanation: |
  1단계: 반사계수($\Gamma$) 도출
  • 동축케이블의 특성 임피던스 $Z_0 = 50 \ \Omega$, 안테나 입력 임피던스 $Z_L = 30 \ \Omega$입니다.
  • 전압 반사계수 공식에 값을 대입합니다:
    $$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0} = \frac{30 - 50}{30 + 50} = \frac{-20}{80} = -\frac{1}{4}$$

  2단계: 반사 전력 계산
  • 반사전력 비율은 반사계수의 크기 제곱($|\Gamma|^2$)입니다:
    $$|\Gamma|^2 = \left( -\frac{1}{4} \right)^2 = \frac{1}{16}$$
  • 송신 전력 $P_{\text{in}} = 64 \text{ W}$이므로 반사 전력 $P_{\text{ref}}$는 다음과 같습니다:
    $$P_{\text{ref}} = |\Gamma|^2 \times P_{\text{in}} = \frac{1}{16} \times 64 = 4 \text{ W}$$

  최종 결과:
  • 반사되는 신호전력은 ②번입니다.

송신기의 출력단은 특성임피던스 50[Ω]인 무손실 동축케이블과 완벽하게 정합되어 있고, 동축케이블은 입력 임피던스가 30[Ω]인 안테나와 연결되어 있다. 송신기에서 안테나로 64 [W]의 신호전력을 전송할 때, 송신기로 반사되는 신호전력[W]은?
