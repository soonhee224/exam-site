explanation: |
  1단계: 양자화 비트 수($n$) 계산
  • 양자화 레벨 수가 $M = 256$이므로 표본당 할당되는 비트 수 $n$은 다음과 같습니다:
    $$2^n = 256 \implies n = \log_2(256) = 8\text{ bits/sample}$$

  2단계: PCM 전송 비트율($R$) 산출
  • 표본화 주파수 $f_s = 8\text{ kHz}$이므로 데이터 비트율은 다음과 같이 계산됩니다:
    $$R = f_s \times n = 8\text{ ksamples/s} \times 8\text{ bits/sample} = 64\text{ kbps}$$

  최종 결과:
  • 데이터의 비트율은 ②번(64 kbps)입니다.
