  - "최대 표본화주기: $\\frac{1}{80}$ [ms], 최소 데이터 전송속도: 640 [kbps]"
explanation: |
  1단계: 나이키스트 표본화 주기 도출
  • 신호의 최고 주파수 성분은 $f_{\max} = 40,000\text{ Hz} = 40\text{ kHz}$입니다.
  • 에일리어싱이 발생하지 않기 위한 최소 표본화 주파수 $f_s$는 다음과 같습니다:
    $$f_s \ge 2f_{\max} = 2 \times 40\text{ kHz} = 80\text{ kHz} = 80,000\text{ Hz}$$
  • 이에 대응하는 최대 표본화 주기 $T_s$는 다음과 같습니다:
    $$T_s = \frac{1}{f_s} = \frac{1}{80,000}\text{ s} = \frac{1}{80}\text{ ms}$$

  2단계: 최소 데이터 전송속도(비트율) 계산
  • 표본당 8비트($n = 8$)를 할당하므로 데이터 전송속도 $R$은 다음과 같습니다:
    $$R = f_s \times n = 80\text{ ksamples/s} \times 8\text{ bits/sample} = 640\text{ kbps}$$

  최종 결과:
  • 최대 표본화주기와 최소 데이터 전송속도가 옳게 묶인 것은 ④번입니다.
---
