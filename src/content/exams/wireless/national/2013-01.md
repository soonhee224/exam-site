answer: 4
options:
  - "4 : 1"
  - "9 : 1"
  - "16 : 1"
  - "25 : 1"
explanation: |
  1단계: 출력 전력의 와트[W] 단위 환산
  • 36 dBm 전력을 와트 단위로 변환합니다:
    $$36 = 10 \log_{10}\left(\frac{P_{\text{out}}}{1\text{ mW}}\right) \implies \log_{10}(P_{\text{out,mW}}) = 3.6$$
  • 상용로그 분해 연산 ($\log_{10} 2 = 0.3$):
    $$P_{\text{out,mW}} = 10^{3.6} = 10^3 \times 10^{0.6} = 1,000 \times (10^{0.3})^2 = 1,000 \times 2^2 = 4,000\text{ mW} = 4\text{ W}$$

  2단계: 입력 전력과 출력 전력의 비율 계산
  • 입력 전력 $P_{\text{in}} = 100\text{ W}$, 출력 전력 $P_{\text{out}} = 4\text{ W}$이므로 비율은 다음과 같습니다:
    $$P_{\text{in}} : P_{\text{out}} = 100 : 4 = 25 : 1$$

  최종 결과:
  • 입력 신호와 출력 신호의 전력비는 ④번입니다.

전력이 100[W]인 신호가 어떤 회로를 통과하여 전력이 36[dBm]이 되었다고 할 때, 입력 신호와 출력 신호의 전력비는? (단, $\log_{10} 2 = 0.3$, $\log_{10} 3 = 0.48$로 계산한다)
