title: "2014년 국가직 9급 무선공학개론 7번"
answer: 2
options:
  - "100"
  - "120"
  - "140"
  - "160"
explanation: |
  1단계: 나이키스트 최소 표본화 주파수 산출
  • 신호의 최고 주파수 $f_{\max} = 10\text{ kHz}$이므로 왜곡 없이 복원하기 위한 최소 표본화 주파수 $f_s$는 다음과 같습니다:
    $$f_s = 2 f_{\max} = 2 \times 10\text{ kHz} = 20\text{ ksamples/s}$$

  2단계: 표본당 비트 수 및 최소 데이터 전송률 계산
  • 50개의 양자화 레벨($M = 50$)을 표현하기 위해 필요한 비트 수 $n$은 다음 부등식을 만족해야 합니다:
    $$2^{n-1} < 50 \le 2^n \implies 2^5(32) < 50 \le 2^6(64) \implies n = 6\text{ bits/sample}$$
  • 따라서 최소 데이터 전송률 $R$은 다음과 같이 구해집니다:
    $$R = f_s \times n = 20\text{ ksamples/s} \times 6\text{ bits/sample} = 120\text{ kbps}$$

  최종 결과:
  • 요구되는 최소 데이터 전송률은 ②번(120 kbps)입니다.
