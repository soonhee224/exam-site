explanation: |
  1단계: 나이퀴스트 표본화 주파수($f_s$) 계산
  • 에일리어싱을 방지하기 위한 최소 표본화 주파수는 신호의 최대 주파수($f_m$)의 2배입니다:
    $$f_s = 2 f_m = 2 \times 5\text{ kHz} = 10\text{ kHz} = 10,000\text{ samples/s}$$

  2단계: 데이터 전송률(Bit Rate) 계산
  • 표본당 16비트로 변환하므로 초당 생성되는 비트 수는 다음과 같습니다:
    $$\text{Bit Rate} = 10,000 \times 16 = 160,000\text{ bps}$$

  3단계: 전체 연주 시간 동안의 데이터 용량 계산
  • 총 연주 시간: $3\text{분 } 20\text{초} = 200\text{초}$
  • 총 비트 수:
    $$\text{Total Bits} = 160,000\text{ bps} \times 200\text{ s} = 32,000,000\text{ bits}$$
  • 바이트(Byte) 환산 ($1\text{ Byte} = 8\text{ bits}$):
    $$\text{Total Bytes} = \frac{32,000,000}{8} = 4,000,000\text{ Bytes}$$
  • 메가바이트(MByte) 환산 ($1\text{ MByte} = 10^6\text{ Bytes}$):
    $$\text{Total MBytes} = \frac{4,000,000}{10^6} = 4\text{ MByte}$$

  최종 결과:
  • 필요한 최소 데이터 용량은 ②번입니다.
