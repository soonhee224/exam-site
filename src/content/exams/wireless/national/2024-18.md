answer: 3
options:
  - "1"
  - "1.5"
  - "2"
  - "2.5"
explanation: |
  1단계: 평균초과지연 공식 및 선형 전력 변환
  • 평균초과지연($\bar{\tau}$) 공식은 다음과 같습니다:
    $$\bar{\tau} = \frac{\sum \tau_i P(\tau_i)}{\sum P(\tau_i)}$$
  • 주어진 데시벨 전력을 선형 전력비로 변환합니다 ($\log_{10} 2 = 0.3$):
    - $\tau_1 = 1\text{ }\mu\text{s} \implies P(1) = -3\text{ dB} = 10^{-0.3} = 0.5$
    - $\tau_2 = 2\text{ }\mu\text{s} \implies P(2) = -3\text{ dB} = 10^{-0.3} = 0.5$
    - $\tau_3 = 4\text{ }\mu\text{s} \implies P(4) = -6\text{ dB} = 10^{-0.6} = 0.25$

  2단계: 평균초과지연 연산
  • 분자 계산:
    $$\sum \tau_i P(\tau_i) = (1 \times 0.5) + (2 \times 0.5) + (4 \times 0.25) = 0.5 + 1.0 + 1.0 = 2.5$$
  • 분모 계산:
    $$\sum P(\tau_i) = 0.5 + 0.5 + 0.25 = 1.25$$
  • 평균초과지연 도출:
    $$\bar{\tau} = \frac{2.5}{1.25} = 2\text{ }\mu\text{s}$$

  최종 결과:
  • 평균초과지연은 ③번입니다.
