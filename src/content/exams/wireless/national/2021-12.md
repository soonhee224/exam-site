  - "RF 증폭기 $\\rightarrow$ IF 증폭기 $\\rightarrow$ 포락선 검파기 $\\rightarrow$ 혼합기"
  - "RF 증폭기 $\\rightarrow$ IF 증폭기 $\\rightarrow$ 혼합기 $\\rightarrow$ 포락선 검파기"
  - "RF 증폭기 $\\rightarrow$ 혼합기 $\\rightarrow$ IF 증폭기 $\\rightarrow$ 포락선 검파기"
explanation: |
  1단계: 슈퍼헤테로다인 수신기의 신호 처리 흐름 분석
  • 안테나로 수신된 미약한 고주파 신호는 먼저 RF 증폭기를 거쳐 잡음을 억제하며 증폭됩니다.
  • 이후 혼합기(Mixer)에서 국부 발진기(LO) 신호와 합성되어 다루기 쉬운 일정한 주파수인 중간주파수(IF) 신호로 변환(하향 변환)됩니다.
  • 변환된 IF 신호는 IF 증폭기를 통과하면서 수신기의 주된 이득과 선택도를 확보합니다.
  • 마지막으로 검파기(포락선 검파기 등)를 거쳐 반송파 성분을 제거하고 원래의 기저대역 정보 신호를 복원합니다.

  2단계: 통과 순서 정리
  • 따라서 수신 신호의 처리 순서는 RF 증폭기 $\rightarrow$ 혼합기 $\rightarrow$ IF 증폭기 $\rightarrow$ 포락선 검파기입니다.

  최종 결과:
  • 올바른 신호 통과 순서는 ④번입니다.
