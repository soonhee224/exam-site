## 1. AI 기반 엑셀 매크로(VBA) 작성의 필요성

행정 및 기술직 실무를 처리하다 보면 수십 개의 시트를 하나로 병합하거나, 측정 로그 데이터에서 특정 조건의 행만 추출하고 서식을 일괄 변경하는 등 반복적인 엑셀 작업이 빈번하게 발생합니다.

과거에는 이를 자동화하기 위해 VBA(Visual Basic for Applications) 문법을 직접 배워야 했으나, 이제는 생성형 AI(ChatGPT, Claude 등)에게 데이터의 구조와 원하는 결과만 명확히 지시하면 단 1분 만에 실무에 즉시 투입 가능한 매크로 코드를 얻을 수 있습니다.

실무에서 AI 매크로를 도입할 때의 핵심 이점 4가지는 다음과 같습니다.

- **비전공자도 즉시 구현 가능**: 복잡한 프로그래밍 문법이나 객체 모델을 외울 필요 없이 자연어(한국어) 지시만으로 코드가 생성됩니다.
- **단순 반복 업무 시간의 획기적 단축**: 수작업으로 1~2시간 걸리던 취합·분할·서식 정리 작업을 단 몇 초(클릭 한 번)로 줄일 수 있습니다.
- **휴먼 에러(Human Error) 원천 차단**: 복사·붙여넣기 과정에서 발생하는 누락이나 행 밀림 현상 없이 정해진 조건대로 정확하게 데이터를 처리합니다.
- **즉각적인 유지보수 및 수정**: 양식이 바뀌거나 조건이 추가되더라도 에러 메시지나 변경 사항을 AI에게 다시 입력해 코드를 즉시 수정할 수 있습니다.

## 2. 실패 없는 VBA 코드 생성을 위한 프롬프트 4원칙

AI에게 모호하게 지시하면 실행 시 런타임 에러가 발생하는 코드가 출력됩니다. 한 번에 정확히 작동하는 코드를 얻으려면 아래 4가지 요소를 반드시 포함하여 프롬프트를 작성해야 합니다.

| 구성 요소 | 핵심 작성 내용 | 구체적 작성 예시 |
| :--- | :--- | :--- |
| **1. 시트 및 열 구조** | 작업할 시트 이름, 제목 행 위치, 데이터가 들어있는 열 알파벳 명시 | `"현재 활성화된 시트의 1행은 제목 행이고, 실제 데이터는 2행부터 A열~F열까지 입력되어 있어."` |
| **2. 실행 조건 및 동작** | 어떤 조건일 때 어떤 작업(복사, 삭제, 색상 변경 등)을 할지 구체화 | `"C열(직렬)의 값이 '통신직'이고 E열(점수)이 80 이상인 행 전체를 찾아서 복사해 줘."` |
| **3. 출력 방식 및 위치** | 결과물이 저장될 새 시트 이름이나 기존 데이터 처리 방식 지정 | `"'통신직_우수자'라는 새 시트를 만들어서 1행에 제목을 복사하고 2행부터 데이터를 붙여넣어 줘."` |
| **4. 예외 처리 조건** | 빈 셀, 중복 시트 존재, 실행 속도 저하 등을 방지하는 안전장치 요구 | `"만약 '통신직_우수자' 시트가 이미 있다면 기존 내용을 모두 지우고 새로 작성해 줘. 화면 깜빡임 방지 코드도 넣어줘."` |

## 3. 실전 프롬프트 템플릿 및 생성 코드 예시

실무에서 가장 많이 쓰이는 **"특정 조건에 맞는 행만 추출하여 별도 시트로 자동 분류하는 작업"**의 프롬프트와 결과 코드입니다.

### 1) AI에게 입력할 프롬프트 (복사해서 수정 후 사용)

> 아래 조건에 맞는 엑셀 VBA 매크로 코드를 작성해 줘.
> 1. 대상 시트: 현재 활성화된 시트 (1행은 헤더, 데이터는 2행부터 시작하며 A열~E열까지 존재)
> 2. 조건: C열(과목명)의 값이 "전자공학개론"인 행만 모두 찾음
> 3. 동작: "전자공학_추출"이라는 이름의 새 시트를 생성하고, 1행 헤더와 함께 조건에 맞는 행 전체를 순서대로 복사해서 붙여넣기
> 4. 예외 처리: "전자공학_추출" 시트가 이미 존재할 경우 기존 시트의 데이터를 초기화한 뒤 덮어쓰기, 데이터가 많아도 빠르게 작동하도록 화면 업데이트 중지(`ScreenUpdating = False`) 코드 포함

### 2) AI가 생성한 결과 VBA 코드

```vba
Sub ExtractElectronicsData()
    Dim wsSource As Worksheet
    Dim wsTarget As Worksheet
    Dim lastRow As Long, i As Long, targetRow As Long
    Dim sheetName As String
    
    ' 속도 향상을 위한 화면 업데이트 및 경고창 중지
    Application.ScreenUpdating = False
    Application.DisplayAlerts = False
    
    Set wsSource = ActiveSheet
    sheetName = "전자공학_추출"
    
    ' 대상 시트가 이미 있으면 삭제 후 재생성
    On Error Resume Next
    Set wsTarget = Worksheets(sheetName)
    On Error GoTo 0
    
    If Not wsTarget Is Nothing Then
        wsTarget.Delete
    End If
    
    Set wsTarget = Worksheets.Add(After:= Worksheets(Worksheets.Count))
    wsTarget.Name = sheetName
    
    ' 1행 헤더(제목 행) 복사
    wsSource.Rows(1).Copy Destination:=wsTarget.Rows(1)
    targetRow = 2
    
    ' 원본 시트의 마지막 행 찾기 (A열 기준)
    lastRow = wsSource.Cells(wsSource.Rows.Count, "A").End(xlUp).Row
    
    ' 2행부터 마지막 행까지 조건 검사 및 복사
    For i = 2 To lastRow
        If Trim(wsSource.Cells(i, "C").Value) = "전자공학개론" Then
            wsSource.Rows(i).Copy Destination:=wsTarget.Rows(targetRow)
            targetRow = targetRow + 1
        End If
    Next i
    
    ' 열 너비 자동 맞춤
    wsTarget.Columns("A:E").AutoFit
    
    ' 설정 원상 복구
    Application.DisplayAlerts = True
    Application.ScreenUpdating = True
    
    MsgBox "데이터 추출이 완료되었습니다! (총 " & (targetRow - 2) & "건)", vbInformation, "작업 완료"
End Sub
```

## 4. 생성된 VBA 코드를 엑셀에 적용하는 4단계 절차

AI로부터 받은 코드를 실제 엑셀 파일에 삽입하고 실행하는 과정입니다.

### 1단계: 개발 도구 탭 활성화 (최초 1회)
- 엑셀 상단 메뉴에서 **[파일]** → **[옵션]** → **[리본 사용자 지정]**으로 이동합니다.
- 우측 '리본 메뉴 사용자 지정' 목록에서 **[개발 도구]** 체크박스를 선택한 뒤 [확인]을 누릅니다.

### 2단계: VBA 편집기 열기 및 모듈 삽입
- 엑셀 화면에서 단축키 **`Alt + F11`**을 눌러 Microsoft Visual Basic for Applications 편집 창을 엽니다.
- 편집기 상단 메뉴에서 **[삽입(I)]** → **[모듈(M)]**을 클릭합니다.

### 3단계: 코드 붙여넣기 및 매크로 실행
- 새로 열린 하얀색 모듈 입력 창에 AI가 만들어준 VBA 코드를 그대로 붙여넣고 창을 닫습니다 (`Alt + Q`).
- 엑셀 화면으로 돌아와 단축키 **`Alt + F8`**을 누른 뒤, 목록에서 방금 만든 매크로(`ExtractElectronicsData`)를 선택하고 **[실행]**을 클릭합니다.

### 4단계: 매크로 전용 파일 형식(.xlsm)으로 저장
- 일반 엑셀 통합 문서(`.xlsx`)로 저장하면 작성한 매크로 코드가 모두 삭제됩니다.
- 반드시 **[다른 이름으로 저장 (`F12`)]**을 누르고 파일 형식을 **Excel 매크로 사용 통합 문서 (*.xlsm)**로 변경하여 저장해야 다음에도 그대로 사용할 수 있습니다.

## 5. 실무 트러블슈팅 및 핵심 주의사항

### 팁 1: 매크로에는 '실행 취소(Ctrl + Z)'가 작동하지 않습니다
VBA 매크로로 변경되거나 삭제된 데이터는 **`Ctrl + Z`로 되돌릴 수 없습니다.** 매크로를 처음 테스트할 때는 반드시 **원본 파일을 복사(백업)**해 두고 사본 파일에서 먼저 실행해 보는 습관을 들여야 합니다.

### 팁 2: 런타임 에러 발생 시 대처법
코드 실행 중 `'런타임 오류가 발생했습니다 (오류 번호: 9 또는 1004 등)'`라는 팝업이 뜨면 당황하지 말고 **[디버그(D)]** 버튼을 누릅니다. 노란색으로 하이라이트된 코드 줄과 오류 메시지를 그대로 복사하여 AI에게 다음과 같이 질문하면 즉시 해결됩니다.

> "네가 짜준 코드를 실행했더니 `[노란색으로 표시된 코드 줄]` 부분에서 `[오류 메시지 내용]` 에러가 발생해. 원인이 뭔지 설명해 주고 수정된 전체 코드를 다시 작성해 줘."

### 팁 3: 자주 쓰는 매크로는 '도형 버튼'에 연결하기
매번 `Alt + F8`을 누르기 번거롭다면 엑셀 시트 상단에 **[삽입]** → **[도형]**으로 네모난 버튼을 하나 만든 뒤, 도형을 우클릭하여 **[매크로 지정]**을 선택하고 방금 만든 함수를 연결해 두세요. 이후부터는 도형만 클릭하면 즉시 매크로가 실행됩니다.
