## 1. BJT 공통 증폭기 기본 개요

바이폴라 접합 트랜지스터(BJT)는 베이스(B), 컬렉터(C), 이미터(E) 세 개의 단자를 가집니다. 2단자 입력과 2단자 출력을 갖는 4단자 증폭기 회로를 구성하기 위해서는 세 단자 중 하나를 입력과 출력이 공통(교류 접지)으로 공유해야 합니다.

어느 단자를 교류 접지로 두느냐에 따라 증폭기의 성격이 완전히 달라지며, 다음과 같이 세 가지 구성으로 나뉩니다.

* 공통 이미터 증폭기(Common-Emitter, CE): 이미터를 공통 접지로 사용. 전압 이득과 전류 이득이 모두 커서 가장 널리 사용되는 기본 전압 증폭기.
* 공통 컬렉터 증폭기(Common-Collector, CC): 컬렉터를 교류 접지로 사용. 전압 이득은 1에 가깝고 입력 임피던스가 매우 크며 출력 임피던스가 작아 완충기(Buffer) 또는 임피던스 매칭용으로 사용. 이미터 팔로워(Emitter Follower)라고도 부름.
* 공통 베이스 증폭기(Common-Base, CB): 베이스를 교류 접지로 사용. 입력 임피던스가 매우 작고 전류 이득이 1에 가까우며, 밀러 효과가 없어 고주파 특성이 매우 우수함.

## 2. 소신호 파라미터 기초

소신호 해석을 진행하기 전, 직류 바이어스 해석을 통해 결정되는 3대 핵심 소신호 파라미터를 반드시 계산해야 합니다. (열전압 $V_T \approx 25\text{ mV} \sim 26\text{ mV}$)

### ① 트랜스컨덕턴스 ($g_m$)
베이스-이미터 전압 변화에 따른 컬렉터 전류의 변화율입니다.
$$g_m = \frac{I_C}{V_T}$$

### ② 베이스 소신호 입력 저항 ($r_\pi$)
하이브리드-$\pi$ 모델에서 베이스 단자에서 들여다본 저항입니다.
$$r_\pi = \frac{V_T}{I_B} = \frac{\beta}{g_m} = (\beta + 1)r_e$$

### ③ 이미터 소신호 저항 ($r_e$)
T-모델에서 이미터 단자에서 들여다본 저항입니다.
$$r_e = \frac{V_T}{I_E} = \frac{\alpha}{g_m} \approx \frac{1}{g_m}$$

## 3. 3대 증폭기 핵심 특성 비교

공무원 시험에서 가장 많이 출제되는 3대 구성의 성능 지표 비교입니다.

| 특성 항목 | 공통 이미터 (CE) | 공통 컬렉터 (CC, 이미터 팔로워) | 공통 베이스 (CB) |
| :--- | :--- | :--- | :--- |
| 교류 접지 단자 | 이미터 (E) | 컬렉터 (C) | 베이스 (B) |
| 입력 단자 | 베이스 (B) | 베이스 (B) | 이미터 (E) |
| 출력 단자 | 컬렉터 (C) | 이미터 (E) | 컬렉터 (C) |
| 전압 이득 ($A_v$) | 높음 (반전, 음수) | $\approx 1$ ($1$보다 약간 작음, 동위상) | 높음 (비반전, 양수) |
| 전류 이득 ($A_i$) | 높음 ($\approx \beta$) | 높음 ($\approx \beta + 1$) | $\approx 1$ ($\alpha < 1$) |
| 전력 이득 | 매우 높음 (최대) | 중간 | 중간 |
| 입력 저항 ($R_{in}$) | 중간 ($r_\pi$ 수준, 수 $\text{k}\Omega$) | 매우 높음 ($r_\pi + (\beta+1)R_E$) | 매우 낮음 ($r_e \approx 1/g_m$, 수십 $\Omega$) |
| 출력 저항 ($R_{out}$) | 높음 ($R_C \parallel r_o$) | 매우 낮음 ($R_E \parallel (r_e + R_s/(\beta+1))$) | 높음 ($R_C \parallel r_o$) |
| 입출력 위상차 | 180도 위상 반전 | 0도 (동위상) | 0도 (동위상) |
| 주 사용 목적 | 일반 전압 및 전력 증폭 | 임피던스 정합, 버퍼(Buffer) | 고주파 RF 증폭, 전류 버퍼 |

---

## 4. 세부 회로 해석 및 공식 유도

얼리 효과($r_o \rightarrow \infty$)를 무시할 때의 핵심 계산 공식입니다.

### 1) 공통 이미터 증폭기 (CE)

#### 바이패스 커패시터($C_E$)가 있는 경우
이미터 저항 $R_E$ 양단에 바이패스 커패시터가 병렬 연결되어 교류 신호가 이미터에서 접지로 바로 빠져나가는 경우입니다.
* 전압 이득:
  $$A_v = \frac{v_o}{v_i} = -g_m (R_C \parallel R_L) = -\frac{R_C \parallel R_L}{r_e}$$
  (마이너스 부호는 180도 위상 반전을 의미)
* 입력 저항:
  $$R_{in} = R_B \parallel r_\pi \quad (R_B = R_1 \parallel R_2)$$
* 출력 저항:
  $$R_{out} = R_C$$

#### 바이패스 커패시터($C_E$)가 없는 경우 (이미터 저항 $R_E$ 퇴화)
교류 관점에서도 $R_E$가 그대로 남아 부궤환(Negative Feedback)이 걸리는 경우입니다. 이득은 감소하지만 왜곡이 줄고 대역폭과 입력 저항이 증가합니다.
* 전압 이득:
  $$A_v \approx -\frac{R_C \parallel R_L}{r_e + R_E} \approx -\frac{R_C \parallel R_L}{R_E} \quad (\text{단, } R_E \gg r_e\text{ 일 때})$$
* 입력 저항:
  $$R_{in} = R_B \parallel [r_\pi + (\beta + 1)R_E]$$

---

### 2) 공통 컬렉터 증폭기 (CC / Emitter Follower)

출력이 이미터 단자에서 인출되며, 출력 전압이 입력 베이스 전압을 그대로 따라가므로 이미터 팔로워라고 부릅니다.
* 전압 이득:
  $$A_v = \frac{R_E \parallel R_L}{r_e + (R_E \parallel R_L)} \approx 1 \quad (A_v < 1)$$
* 입력 저항:
  $$R_{in} = R_B \parallel [r_\pi + (\beta + 1)(R_E \parallel R_L)]$$
* 출력 저항 (신호원 저항 $R_s$ 포함 시):
  $$R_{out} = R_E \parallel \left( r_e + \frac{R_s \parallel R_B}{\beta + 1} \right)$$

---

### 3) 공통 베이스 증폭기 (CB)

입력이 이미터로 들어가고 출력이 컬렉터로 인출됩니다.
* 전압 이득:
  $$A_v = +g_m (R_C \parallel R_L) = +\frac{R_C \parallel R_L}{r_e}$$
  (CE 증폭기와 크기는 같으나 부호가 양수이므로 위상 반전이 없음)
* 입력 저항:
  $$R_{in} = R_E \parallel r_e \approx r_e = \frac{1}{g_m}$$
* 출력 저항:
  $$R_{out} = R_C$$

---

## 5. 시험에 자주 나오는 계산 팁 및 함정

### 팁 1: 전압 이득 암산 테크닉 (T-모델 분압법)
CE, CB, CC 증폭기의 전압 이득은 복잡한 KCL 연립방정식을 세우지 않고도 이미터 회로 경로의 합성 저항과 컬렉터 회로 부하 저항의 비로 즉시 구할 수 있습니다.
* 전압 이득의 크기 = (컬렉터 측 교류 부하 저항) / (이미터 측 교류 총 저항)
  * CE (바이패스 있음): $|A_v| = \frac{R_C}{r_e}$
  * CE (바이패스 없음): $|A_v| = \frac{R_C}{r_e + R_E}$
  * CB: $|A_v| = \frac{R_C}{r_e}$

### 팁 2: 이미터-베이스 간 임피던스 반사 규칙 (Resistance Reflection Rule)
* 베이스에서 이미터 쪽을 들여다볼 때: 이미터에 달린 저항은 베이스 측에서 $(\beta + 1)$배 커져서 보입니다 ($(\beta + 1)R_E$).
* 이미터에서 베이스 쪽을 들여다볼 때: 베이스에 달린 저항은 이미터 측에서 $(\beta + 1)$배 작아져서 보입니다 ($\frac{R_B}{\beta + 1}$).
