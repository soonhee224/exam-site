## 1. 이상적인 OP-Amp의 4대 기본 특성

연산증폭기(Operational Amplifier, OP-Amp) 회로를 해석할 때 부궤환(Negative Feedback)이 걸려 있다면, 다음의 **이상적인 연산증폭기 기본 가정**을 적용하여 복잡한 트랜지스터 내부 구조를 생략하고 단순화하여 해석합니다.

1. **무한대 전압 이득 ($A_{OL} \rightarrow \infty$)**: 개루프 전압 이득이 무한대이므로 출력 전압이 유한한 값을 갖기 위해서는 두 입력 단자 사이의 전압차가 거의 0이어야 합니다.
   $$v_+ - v_- = \frac{v_o}{A_{OL}} \approx 0 \implies v_+ \approx v_-$$
   이를 **가상 단락(Virtual Short)**이라고 합니다.
2. **무한대 입력 저항 ($R_{in} \rightarrow \infty$)**: 반전 입력 단자($-$)와 비반전 입력 단자($+$) 내부로 흘러 들어가는 전류는 0입니다.
   $$i_+ = i_- = 0$$
3. **영(0) 출력 저항 ($R_{out} \rightarrow 0$)**: 출력단은 이상적인 전압원처럼 동작하여 후단 부하 저항($R_L$)의 크기에 관계없이 일정한 출력 전압을 유지합니다.
4. **무한대 대역폭 ($BW \rightarrow \infty$) 및 무한대 동상신호제거비 ($\text{CMRR} \rightarrow \infty$)**: 직류부터 초고주파까지 주파수에 관계없이 동일한 이득을 유지하며, 두 입력 단자에 동시에 인가된 공통 모드 잡음을 완전히 제거합니다.

## 2. 반전 증폭기 (Inverting Amplifier)

입력 신호가 반전 입력 단자($-$)로 들어가고, 비반전 입력 단자($+$)는 접지(Ground)에 연결된 기본 증폭 회로입니다. 출력 전압의 위상이 입력 전압에 대해 $180^\circ$ 반전됩니다.

### 1) 회로 해석 및 전압 이득 유도
* 비반전 단자($+$)가 접지($0\text{ V}$)에 연결되어 있으므로, 가상 단락에 의해 반전 단자($-$)의 전위 역시 접지와 동일한 $0\text{ V}$가 됩니다. 이를 **가상 접지(Virtual Ground)**라고 부릅니다.
  $$v_- = v_+ = 0\text{ V}$$
* 반전 단자($-$) 노드에서 키르히호프의 전류 법칙(KCL)을 적용합니다. (단자 내부로 들어가는 전류 $i_- = 0$)
  $$\frac{v_i - v_-}{R_1} = \frac{v_- - v_o}{R_f}$$
* $v_- = 0\text{ V}$를 대입하여 정리하면:
  $$\frac{v_i}{R_1} = -\frac{v_o}{R_f} \implies A_v = \frac{v_o}{v_i} = -\frac{R_f}{R_1}$$

### 2) 특징 및 한계
* **전압 이득**: $A_v = -\frac{R_f}{R_1}$ (마이너스 부호는 $180^\circ$ 위상 반전을 의미하며, 저항비에 따라 $|A_v| < 1$, $|A_v| = 1$, $|A_v| > 1$ 모두 자유롭게 설정 가능)
* **입력 저항**: $R_{in} = R_1$ (신호원에서 바라본 저항이 입력 저항 $R_1$ 자체로 제한되므로, 신호원에 로딩 효과(Loading Effect)를 유발할 수 있음)
* **출력 저항**: $R_{out} \approx 0$

## 3. 비반전 증폭기 (Non-inverting Amplifier)

입력 신호가 비반전 입력 단자($+$)로 직접 들어가고, 반전 입력 단자($-$) 쪽에 저항 분배 궤환망이 연결된 회로입니다. 출력 전압과 입력 전압의 위상이 서로 동일(동위상, $0^\circ$)합니다.

### 1) 회로 해석 및 전압 이득 유도
* 입력 신호 $v_i$가 비반전 단자($+$)에 직접 인가되므로, 가상 단락에 의해 반전 단자($-$)의 전위도 $v_i$가 됩니다.
  $$v_- = v_+ = v_i$$
* 반전 단자($-$) 노드에서 KCL을 적용합니다. (단자 내부 유입 전류 $i_- = 0$)
  $$\frac{0 - v_-}{R_1} + \frac{v_o - v_-}{R_f} = 0 \iff \frac{v_-}{R_1} = \frac{v_o - v_-}{R_f}$$
* $v_- = v_i$를 대입하여 정리하면:
  $$\frac{v_i}{R_1} = \frac{v_o}{R_f} - \frac{v_i}{R_f} \implies v_o = v_i \left(1 + \frac{R_f}{R_1}\right)$$
  $$A_v = \frac{v_o}{v_i} = 1 + \frac{R_f}{R_1}$$

### 2) 특징
* **전압 이득**: $A_v = 1 + \frac{R_f}{R_1} \ge 1$ (이득이 항상 1 이상이며 부호가 양수이므로 위상 반전이 없음)
* **입력 저항**: $R_{in} \rightarrow \infty$ (입력 신호가 OP-Amp 단자 내부로 직접 인가되므로 신호원을 전혀 감쇠시키지 않음)
* **출력 저항**: $R_{out} \approx 0$

---

## 4. 특수 형태: 전압 팔로워 (Voltage Follower / 단위 이득 버퍼)

비반전 증폭기에서 $R_f = 0$ (도선 단락)으로 두고 $R_1 \rightarrow \infty$ (개방)로 둔 특수한 구성입니다.

$$A_v = 1 + \frac{0}{\infty} = 1 \implies v_o = v_i$$

* **전압 이득**: $A_v = 1$ (입력 전압 크기와 위상이 그대로 출력에 나타남)
* **입력 저항**: $R_{in} \approx \infty$ (신호원에 전류를 요구하지 않음)
* **출력 저항**: $R_{out} \approx 0$ (부하에 강한 전류 구동력 제공)
* **주요 용도**: 출력 임피던스가 높은 센서나 신호원과 낮은 부하 저항 사이에서 신호 감쇠를 완벽히 막아주는 **임피던스 버퍼(Buffer)** 또는 **완충 증폭기**로 사용.

## 5. 반전 vs 비반전 증폭기 핵심 특성 비교

| 비교 항목 | 반전 증폭기 (Inverting) | 비반전 증폭기 (Non-inverting) | 전압 팔로워 (Buffer) |
| :--- | :--- | :--- | :--- |
| **신호 입력 단자** | 반전 단자 ($-$) | 비반전 단자 ($+$) | 비반전 단자 ($+$) |
| **전압 이득 ($A_v$)** | $-\frac{R_f}{R_1}$ | $1 + \frac{R_f}{R_1}$ | $1$ |
| **이득의 크기 범위** | $0 \le |A_v| < \infty$ (감쇠 및 증폭 모두 가능) | $1 \le A_v < \infty$ (항상 1 이상) | $A_v = 1$ (단위 이득) |
| **입출력 위상차** | $180^\circ$ (위상 반전) | $0^\circ$ (동위상) | $0^\circ$ (동위상) |
| **가상 접지 여부** | 존재함 ($v_- = 0\text{ V}$) | 없음 ($v_- = v_i \neq 0\text{ V}$) | 없음 ($v_- = v_i$) |
| **입력 임피던스 ($R_{in}$)** | 중간 ($R_1$에 의해 결정) | 매우 높음 (이론상 $\infty$) | 매우 높음 (이론상 $\infty$) |
| **출력 임피던스 ($R_{out}$)** | 거의 0 ($0\,\Omega$) | 거의 0 ($0\,\Omega$) | 거의 0 ($0\,\Omega$) |
| **주요 장점** | 회로 확장이 쉬움 (가산기, 적분기) | 입력 저항이 커서 신호 손실이 없음 | 최상의 완충(버퍼) 성능 |

## 6. 시험에 자주 나오는 핵심 문제 풀이 팁

### 팁 1: 전원 전압($\pm V_{CC}$)에 의한 출력 포화(Saturation) 주의
* OP-Amp의 실제 출력 전압은 공급 전원 전압의 크기를 초과할 수 없습니다.
  $$-V_{EE} \le v_o \le +V_{CC}$$
* 문제에서 $R_f/R_1$ 계산 결과 $v_o = -15\text{ V}$가 나왔더라도, 전원 전압이 $\pm 10\text{ V}$로 주어져 있다면 실제 출력은 **$-10\text{ V}$로 포화(Clipping)**됩니다. (단골 함정)

### 팁 2: 반전 가산기(Inverting Summing Amplifier)의 빠른 계산
반전 단자에 여러 입력 저항($R_1, R_2, R_3$)을 통해 전압($v_1, v_2, v_3$)이 인가될 때의 출력 전압:
$$v_o = -\left( \frac{R_f}{R_1}v_1 + \frac{R_f}{R_2}v_2 + \frac{R_f}{R_3}v_3 \right)$$

### 팁 3: 유한한 개루프 이득($A$)을 고려할 때의 실제 전압 이득
이상적이지 않고 유한한 개루프 이득 $A$가 문제에 명시된 경우:
* 반전 증폭기: $A_v = \frac{-R_f/R_1}{1 + \frac{1 + R_f/R_1}{A}}$
* 비반전 증폭기: $A_v = \frac{1 + R_f/R_1}{1 + \frac{1 + R_f/R_1}{A}}$
